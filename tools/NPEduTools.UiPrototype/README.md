# 工作台与自习中心：WPF 交互原型

基于 v1.1.2 的独立工具，不挂接生产 App 启动入口，不修改 Host、协议、排程、管理权限或全屏展示。所有班级、设备、读数、校准与报告均为内存中的演示数据；关闭后丢弃。不连接学校、仪表、麦克风、摄像头，不登记守护或任务。

## 预览路径

1. **立即开始**：主页 → 开始手动自习 → 开始自习。开始后配置区变为会话摘要，主按钮变为“结束自习”。结束后到报告页查看示例统计。
2. **预约**：自习 → 手动自习 → 指定时间。开始与结束按选择展开；有效预约的主按钮变为“取消预约”。结束时间早于开始、无效时间或超过三小时，显示原位错误。未来预约在此原型中不根据真实时间执行。
3. **学校定时**：自习 → 学校定时自习。查看应用安排、采集和展示状态、座位表及提醒时点。顶部演示场景切换至“学校自习进行中”后，新手动会话不可开始；全屏界面仍沿用现有版本，本原型只演示管理页。
4. **联机校准**：设备与连接 → 联机校准 (Beta)。原型口令 **123456**；不要输入真实学校口令。验证后收起口令区，显示仪表与校准方式。每段演示采样加速到三秒，模拟断线会撤回结果并要求重新验证；退出采样页也不会继续保存。最后必须勾选确认才能保存演示参考，麦克风变化后参考失效。
5. **时间恢复**：演示场景 → 学校时间失效 → 主页“检查时间连接” → 重新检查。只恢复演示时钟，不结束已有手动会话。演示场景选择用于重置测试场景，后续交互会标明“当前操作状态”。

## 本地运行

在仓库根目录使用兼容的 .NET 10 Windows SDK：

```powershell
./scripts/dotnet.ps1 build tools/NPEduTools.UiPrototype -c Release
./scripts/dotnet.ps1 tools/NPEduTools.UiPrototype/bin/Release/net10.0-windows/NPEduTools.UiPrototype.dll
```

正式业务项目与解决方案没有引用这个工具。日期、密码和选择框直接复用现有 WPF 样式，窗口工作区限制复用 `DesktopWindowBounds`；其余原型控件仅属于此工具。

## 隔离验证

```powershell
./scripts/dotnet.ps1 tools/NPEduTools.UiPrototype/bin/Release/net10.0-windows/NPEduTools.UiPrototype.dll --verify .artifacts/ui-prototype
```

验证实际 WPF 按钮、页面切换、错误反馈、断线与离页恢复、显式确认、参考失效及底部操作可达性，并输出截图和 `result.json`。逻辑窗口大小覆盖 1280×680 至 760×520，帮助检查高缩放下的紧凑空间；不宣称已经在真实 200% 缩放的一体机通过触控验收。
