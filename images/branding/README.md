# NPEduTools 图标资产

以 `../logoorigin.png` 为依据，使用手工设定的三次贝塞尔曲线，在 Adobe Illustrator 2026（30.7）内构建原生路径并导出。原图保留，不修改程序代码、资源引用或安装配置。

## 文件与用途

| 文件 | 用途 |
| --- | --- |
| `npedutools-logo.ai` | RGB 可编辑母版，4 个 1024×1024 画板：standard、small、mono、mono-light。每个版本有命名图层和命名路径；保存 PDF 兼容数据。 |
| `npedutools-logo.svg` | 标准版：4 条闭合路径、28 个锚点。主窗口、较大尺寸图标、品牌展示。 |
| `npedutools-logo-small.svg` | 简化版：3 条闭合路径、22 个锚点。托盘、任务栏、侧边栏和小尺寸入口。 |
| `npedutools-logo-mono.svg` | 深色单色版：2 条路径、20 个锚点，默认 `#202E35`，使用 `currentColor`。内联 SVG 时可通过根元素的 `color` 调色；外链 `<img>` 不继承宿主文字色。 |
| `npedutools-logo-mono-light.svg` | 白色单色版，用于深色背景；白色是标志本身的填充，留白仍然透明。 |
| `png/npedutools-{尺寸}.png` | 透明 RGBA PNG：1024、256 使用标准版；64、48、32、24、16 使用简化版。 |
| `png/npedutools-small-256.png` | 简化结构的大尺寸对照。 |
| `png/npedutools-mono[-light]-{尺寸}.png` | 深、浅两套单色 PNG：256、64、48、32、24、16。深色背景下的极小托盘图标优先使用白色单色版。 |
| `npedutools.ico` | 真正多帧 Windows ICO，包含 16、24、32、48、64、256。前五帧为简化版 32 位 BGRA DIB，含透明度及 AND 掩码；256 帧为标准版 PNG。 |
| `npedutools-preview.png` | 由实际交付 PNG 合成的预览，包含深浅背景与实像素小图。以图片查看器 100% 显示查看实像素区。 |
| `preview.html` | 本地查看 SVG 和按标称 CSS 像素显示的 PNG；浏览器缩放设为 100%。系统显示缩放仍会影响物理像素。 |
| `source/` | 贝塞尔控制点、生成脚本、Illustrator 原始导出及验证记录，便于后续维护。 |

## 相比原图的调整

- 保留抽象 n 的主体轮廓、舒展弧线、书页交叠和叶片联想；手工概括为少量曲线，未使用自动描摹产生的碎路径。
- 去掉原图浅色底和细微材质变化，采用三个纯色色面，不增加投影、厚度或写实效果。原图的中央留白和上方细缝完全由路径间隙形成，没有白色遮挡形状。
- 原图约 64% 的纵向主体占比提高到约 87%，保留约 6.5% 的上下安全边距；所有版本使用同一构图和画布。
- 简化版去掉深绿折面。左上边界的细缝扩大为约 57 个原图坐标单位的开口，中央两竖部间距从约 139 扩大到 168，改善 16–32 像素辨识。
- 单色版将相接的上方书页和右侧飘带合为一条外轮廓，避免同色拼接边缘的抗锯齿细线。
- 16–64 PNG 从 Illustrator 中的简化／单色矢量以各目标尺寸的 4 倍独立导出，再进行带透明度的 Lanczos 缩采样；清理不超过 4/255 的低透明度振铃。并非直接缩小标准版大图。

## 验证

- Illustrator 原生母版：4 个画板、11 条可编辑路径、90 个锚点、0 个栅格对象、0 个置入对象。
- 已重新打开保存的 AI 核对上述对象数；四份 SVG 均已重新导入 Illustrator，256 像素渲染结果与相应母版导出逐像素一致。详见 `source/illustrator-verification.txt`。
- SVG：真实 `path` 与三次贝塞尔曲线；无 `image`、位图数据、背景矩形、白色遮挡、蒙版或滤镜。
- 透明 PNG 和 ICO：外侧透明，中央开口透明；每帧有 0–255 的 alpha 范围。
- ICO 已重新解码，六个尺寸分别与交付 PNG 的 RGBA 像素逐字节一致。详情见 `source/validation.json`。
- 预览已检查标准版、简化版和单色版的视觉一致性，以及 16、24、32、48、64 像素在深浅背景中的辨识度。极小彩色图标在深色背景上对比度较低，已提供白色单色版本。
- 标准 SVG 与小尺寸 SVG 均可无限放大，放大时仍由曲线渲染；PNG 本身是定尺寸栅格资产。

## 维护与范围

`source/build_vectors.py` 保存手工绘制的几何定义，输出 SVG、几何 JSON 和 Illustrator JSX；在 Illustrator 运行 `source/build-illustrator.jsx` 可重新构建母版并导出，再用 Pillow 运行 `source/finish_assets.py` 生成 PNG、ICO 和预览。重建脚本会覆盖本套交付文件，修改前请另存版本。

本次要求的图标资产均已交付。没有接入 NPEduTools 程序或发布到外部平台；应用内实际集成效果留待资源接入后检查，不属于本次范围。
