## 执行顺序

先短录后整课；在有条件保存原始结果的试验安排下进行故障测试。首轮建议 720p / 8 fps，随后按文字清晰度验证 1080p / 8 fps；不要把切换配置与排查故障混在同一次记录中。

| 场景 | 要检查的内容 | 结果 / 视频 / 执行记录 |
| --- | --- | --- |
| 完整解压后启动 | 没有开发 SDK 也能启动；主窗、侧栏、设备检测正常 | 待填 |
