## 已修复问题

1. **手动自习在学校定时时段以外一直没有作业。** 当前起点的取数条件只接受学校定时准备/运行阶段和有效学校时钟；手动自习缺少独立的取数上下文。Host 现使用手动会话的准备/运行状态与 Windows 日期请求当天作业，所有分块携带 `purpose=Manual`。KV 仍核验有效绑定、运行上下文、当前配置版本、15 秒内的 APPLIED 回执、已启用的学校作业来源和北京时间当天日期，不允许设备指定来源班级。此扩展只读取作业，不授予排程、采集或照片权限。
2. **手动会话运行中改变学校作业来源，旧来源正文仍可能保留到轮换。** 手动会话版本与学校配置版本不同，原页面清理键只有会话版本。现在把作业配置版本纳入清理键；配置变更立即清除旧页和旧请求结果，同一配置内的正文更新仍等待当前阅读周期。独立 WPF 反例在移除该清理条件时失败，恢复后通过。

手动作业需要桌面与配套 KV 同时支持。旧 KV 会严格拒绝新增字段；客户端不会伪造学校定时状态回退。本次不涉及数据库模型、迁移或生产操作。
