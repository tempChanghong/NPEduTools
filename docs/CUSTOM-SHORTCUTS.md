# 自定义快捷启动

日期：2026-09-06。

## 使用

主窗口左侧进入“快捷启动”，点击“添加”，选择类型并填写名称和目标：

| 类型 | 输入 | 打开方式 |
| --- | --- | --- |
| 应用 | `.exe` 程序或已有 `.lnk` 快捷方式 | 使用 Windows 打开；快捷方式保留其自身设置 |
| 文件 | 完整文件路径，可通过选择器填写 | 使用 Windows 默认文件关联 |
| 网址 | `https://` 或 `http://` 开头的完整网址 | 使用 Windows 默认浏览器 |

名称最多 40 个字符，列表最多 24 项。选择列表中的项目后可以编辑、上移、下移或移除。移除只删除入口，原文件和程序保留；可撤销最近一次移除，下一次编辑或重启后撤销记录失效。

常用工具主页的“我的快捷”卡片和贴边面板使用同一份列表及顺序。贴边面板新增“课堂工具 / 我的快捷”切换，收起再展开保留本次选中的页面；重新启动默认显示课堂工具。面板底部可以打开管理页。

长名称显示省略号，鼠标悬停可查看完整名称和目标。管理页始终提供目标路径；项目较多时可以滚动。

## 执行与反馈

保存入口不启动目标。每次明确点击“打开”或入口卡片后才执行，主页面与贴边面板共用打开流程。处理期间禁用重复点击，完成后短暂合并连续轻点，避免同一次触摸双击启动两遍。

打开前重新校验类型、路径或网址，并检查文件存在且可访问。路径失效时显示“编辑此项”，贴边面板可以直接进入对应编辑器重新选择。文件没有默认关联、权限不足或取消系统授权时显示结果，不自动重试或改用其他命令。

调用 [Windows shell 的默认打开方式](https://learn.microsoft.com/en-us/dotnet/fundamentals/runtime-libraries/system-diagnostics-processstartinfo-useshellexecute)，使用单独 STA 线程处理，窗口不会因默认应用启动等待而阻塞。路径和网址作为完整目标传递，不拼接到命令解释器，不提供额外命令行参数。快捷方式可用于保留用户已配置的应用参数。

成功反馈为“已交给 Windows 打开”，仅表示系统接受打开请求，不宣称文档已加载或网站已成功访问。打开目标后可按系统行为切换焦点，NPEduTools 不关闭外部应用、文件或浏览器标签。

## 存储与异常

使用 `%LocalAppData%\NPEduTools\ui\<端点散列>.shortcuts.json`，与贴边位置、启动偏好各自保存。格式版本为 1，使用稳定项目 ID 保存名称、类型和目标，数组顺序即展示顺序。保存通过临时文件替换完成，失败时界面保留原列表。

加载只校验结构与目标格式，不自动运行内容；文件暂时不存在也保留项目，直到用户打开时提示。损坏、过大或不支持版本的配置保留原文件并停止编辑，修复后可点击“重新读取”。私有测试端点不会覆盖用户的快捷列表。
