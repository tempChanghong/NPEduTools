| 任务卡 | 内容 |

## 职责与进入条件

学校保存规则 → NPEduTools 按 ClassIsland 时间执行 → KV 接收实际状态 → NPClassworks 进入展示。

NPEP 原生模式下，网页不能因为「已经到点」「保存了排程」「发送开始命令成功」就声称正在监测。建议自动进入以新鲜回传为依据：

- 当前是对应绑定的大屏界面，服务端选择 `provider=native`。
- 两个原生接口均在线；0.7 的 `owner=Schedule`，有本次 `window`、有效 `sessionId`。
- 0.6 的实际 `status.state=Active`，且 `sessionId` 与 0.7 相同。两次请求并非原子读取，不匹配时等待下次回传，不发送纠正命令。
- 不处于考试、临时退出、管理页面或编辑草稿的操作中。被草稿阻挡时先显示「定时监测已开始」入口，操作结束再进入。

`applied=false` 只说明桌面尚未确认服务端最新规则；仍须单独显示实际运行状态，不把规则待应用误标成采集已停止。若页面实现需要考试状态而现有网页没有可靠字段，先复用已有考试接口，不扩大噪音协议。

NPEP 学校授权开启、设备配对、服务端选择原生提供商是不同事实。未配对及旧网页模式依照服务端提供商选择处理；一旦原生接管，断线不回退网页麦克风。未启用原生时，同一展示组件可读取现有浏览器 `noiseMonitoringState`，只在定时有效且实际采集 `active` 时进入；手动会话不强制进入。

## 展示布局建议

```text
高二 1 班   自习监测                    年级排程 · 桌面已连接
本次 19:00—19:45                       学校时间 19:12:08

                    请保持安静
                    剩余 32:52

           最近一分钟趋势 · 采样有效／具体异常
           信号电平 -57.0 dBFS · 麦克风名称

返回作业板                 查看详情          结束本次监测
```

采用低干扰、清晰对齐的纯色背景，大字号自习提示和倒计时作为视觉中心；趋势与技术信息降低层级。沿用 NPClassworks 的品牌及明暗主题。不给未校准 dBFS 配置「安静／吵闹」红黄绿评分，缺样、全零信号和陈旧读数不能显示采样正常。详细报告与排程管理留在详情中。

这是浏览器视口内的独立展示，不自动请求操作系统全屏，不保证浏览器最小化时能抢回前台。

## 返回、结束及异常

- 返回作业板：只退出展示，采集继续；本次窗口内记住返回选择，后续轮询、页面刷新和断线重连不反复抢屏。下次独立时段可再次自动进入。
- 结束本次监测：确认后沿用 0.6 STOP，显示等待桌面回执；实际停止确认后展示结束／报告待上传状态。NPEduTools 现有停止路径会记录本次跳过，不在同一时段立即自动重启。
- 时段自然结束：以实际停止与排程回传确认，短暂结束提示后返回原作业板上下文。报告仍在上传不能显示上传成功。
- 离线／两份状态不一致：已打开的页面保留上下文、隐藏陈旧电平，显示「连接中断，当前状态未知」；暂停倒计时外推，保留返回入口。采集可能仍由桌面继续。
- 倒计时：从桌面 `schoolNow` 与 `window.end` 计算；两次有效观测间最多使用单调时间短暂外推。学校时钟无效或状态陈旧时不继续外推，不使用浏览器墙钟代替学校时钟。倒计时归零不等于停止已确认。
- 手动会话、失败、考试暂停分别显示真实状态，不冒充定时运行。考试优先；监测页面不得挡住学校通知或恢复已退出的考试界面。

## 当前源码证据与协作接口

- `Host/NoiseScheduleService.cs` 的 `Observe()` 已提供 `owner/reason/window/next/sessionId/schoolNow/clockReady/dateNeedsReview`。
- `Integrations.Npep/NpepRuntime.NoiseSchedules.cs` 约每 3 秒交换 0.7；0.6 状态含实际会话、采样质量与电平，没有趋势数组。网页只积累已接收的有效样本形成短时走势，不能跨会话拼接。
- KV `/screen/noise-schedule` 提供 `online/applied/receivedAt/status`；与 `/screen/noise` 通过采集 `sessionId` 对应。学校时间为无时区的日历字段，不作八小时转换。
- NPClassworks `App.vue` 常驻 `NoiseScheduleManager`，已在全局轮询；新增视图不要创建第二份轮询或调用采集启动。真实路由切换还需处理通知、作业板宿主及草稿生命周期，优先保留宿主的独立展示模式。

## 统一验证入口

在 NPEduTools 根目录执行（兼容 Windows PowerShell 5.1）：

```powershell
.\scripts\test-npep-noise-schedules.ps1 -Display
# 再选择网页浏览器交互：既有排程 + 新展示
.\scripts\test-npep-noise-schedules.ps1 -Display -Browser
```

入口执行桌面噪音、学校时钟与排程测试，KV 既有规则／状态接口测试，网页排程及展示状态测试，并把桌面真实服务配合合成采集器生成的快照送入网页生产判定函数。每次生成独立目录，避免旧快照掩盖漏跑。没有请求真实麦克风，不访问生产服务，不使用 Docker。`-Database` 是另行选择的隔离数据库测试。

七种桌面快照：正在启动、定时采集、网页停止、显式恢复、手动采集、自然结束、采集故障。重点核对毫秒学校日历、相同会话、待应用规则、跨午夜、自然结束后当前窗口为空，以及故障不冒充正常结束。合成测试与真人／真实大屏验收分开记录。
