本轮在 NPClassworksKV 增加独立只读 `device-overview` 接口，沿用学校管理员的有效会话与部署代际检查；不迁移数据库。NPClassworks 在既有互联管理页呈现概览，老后端缺少此接口时保留原设备列表并说明不支持概览。

“待检查”只包含仍在授权中的设备：失联／尚未上报、模式未知／未配置／未完成、录制状态未知，以及当前模式对应桥接未连接。日常模式下 ExamAware 断开、考试模式下 ClassIsland 断开不单独算异常。撤销、过期、绑定变化等另列为非授权登记，不混入运行问题。

学校汇总与每页列表使用一次查询得到的同一观测切面；下一页可能在稍晚时刻读取，不承诺跨页事务快照。刷新失败保留上次结果并禁用远控；超过一分钟的页面快照明确标记需刷新。
