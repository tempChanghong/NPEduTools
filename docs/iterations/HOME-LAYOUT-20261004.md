# 主页布局整理 · 2026-10-04

## 本轮交付

主页按「课堂模式 → 我的快捷 → 课堂工具 → 课堂辅助状态」组织。

- 自定义快捷前移，改为图标与名称横排的小卡片。
- 首页展示按现有顺序排列的前 6 个快捷入口；总数超过 6 时显示说明，可从「查看全部 / 管理」访问完整列表。保存数据和侧边栏仍包含全部入口。
- 六个课堂工具统一卡片尺寸、图标及标题位置：录制微课、自动录课计划、课堂点名、噪音监测、考试看板、学校互联。
- 课堂点名沿用 SecRandom 配置窗口，无配置时可在原窗口完成配置；不直接触发抽取。
- 学校互联入口直接打开设置中的 NPEP 分类，使用已有连接管理流程。
- 工具和快捷卡片根据可用页面宽度排列：至少 720 WPF 单位为三列，否则两列；小窗口通过原有滚动区域浏览。
- 空的快捷反馈不占版面，工具支持鼠标悬停、按下和键盘焦点提示。侧栏点名文案缩短，避免被截断。
