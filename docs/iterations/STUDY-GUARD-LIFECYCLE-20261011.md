# 自习守护生命周期任务卡

- 目标：降低随手结束监测／展示进程的影响，保持学校定时阶段恢复与验证退出规则。
- 范围：守护产物名 `svchost.exe`、描述“Windows 服务主进程”；任务计划程序独立启动与互相检查；定时准备唤醒、异常恢复、跳过本次、Windows 会话协调；本地缓存、维护及打包兼容。
- 边界：守护不授予采集权限。Host 仍核验授权、学校时间、规则及设备；不恢复手动采集。手动自习新界面和大屏上传座位表另行实现。
- 验收：非定时时段退出后守护继续等待；准备前两分钟启动；有效时段恢复被结束的 App／Host；验证退出后本次不恢复、下次准备再次启动；默认端点可跨 Windows 登录解析；维护仅作用于所属路径与任务。
- 模块：Core Guard、Guard EXE、Host 噪音排程、App 生命周期、打包和安装检查。
- 验证：合成学校时钟／日历／跳过记录；真实任务计划程序＋合成 App／Host／守护进程树终止与互相恢复；模拟本测试窗口的关机确认／取消；构建及包路径检查。无生产访问，无真实麦克风或摄像头。
- 实机待验收：一体机登录／重启、实际自习准备唤醒、任务管理器结束后的展示与采集恢复、锁屏／休眠／真实关机、多账户维护。自动测试不能代替这些验收。
- 本轮保留本地修改，不提交、不部署。维护步骤见 [守护维护说明](../GUARD-MAINTENANCE.md)。
