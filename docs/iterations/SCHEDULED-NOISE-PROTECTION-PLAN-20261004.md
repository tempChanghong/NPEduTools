## 使用规则

| 操作 | 实际行为 |
| --- | --- |
| 返回作业板 | 无需 PIN；采集继续。默认 10 分钟，学校后台可设置年级规则和班级覆盖，提供 5／10 分钟快捷值，可设置 1–60 分钟。 |
| 恢复展示 | 只在当前绑定、当前时段仍有新鲜匹配的实际定时采集时恢复；编辑器／通知优先，不抢焦点。 |
| 刷新、重连、重复返回 | KV 保留同一时段已登记期限；同一时段换采集会话也不续期。恢复展示后再次主动返回才开始新期限。 |
| 网页停止定时监测 | 两个入口均输入本大屏学校 PIN；KV 核验后创建 STOP，Host 执行前再向学校服务核验当前命令、会话与时段。 |
| 桌面停止／正常退出后台 | 使用预先配置的本机管理口令。关闭管理／噪音窗口只隐藏，不停止采集。 |
| 本地暂停互联、撤销配对、切换课堂环境等间接停用 | Host 同样核验本机管理授权，防止绕过停止按钮。授权操作会先结束并持久化跳过本时段，再尝试其后续管理操作；后续操作失败不撤销该次跳过。 |
| 学校考试指令、到点、规则／学校时间失效、采集故障 | 保留原有授权与安全停止路径。管理保护不阻碍释放麦克风。 |
| 手动监测 | 保持原启停与时长规则，不应用定时保护及强制恢复展示。 |

## 时间与授权边界

- ClassIsland 时间决定定时采集窗口；临时返回使用经过时长。当前页面以单调时钟计时，服务端保存期限；系统校时不会让当前页面一直延期。
- 在线已登记的返回，在后台改配置后仍沿用该次期限。未登记的离线返回会缓存原开始时间与分钟数；重连只能沿用或按当前配置缩短，不能延长。刷新后时间回拨造成缓存不可信时丢弃缓存并重新核对服务端。
- 本机管理口令与学校 PIN 分开：首次配置必须在没有受保护定时采集时进行；若尚未配置，可先从大屏网页验证学校 PIN 结束监测，再配置。
- Host 保存加盐 PBKDF2 摘要，错误尝试有节流。本机票据绑定实例、会话、操作及请求 ID，60 秒有效、单次消费，重启失效；更改口令需原口令并撤销旧票据。
- 授权正常停止先落盘本次跳过。保存失败时拒绝正常停止；验证取消或失败不会先关闭自动录课。后台退出先预约当前操作，防止验证后立即启动新定时会话。
- 学校停止使用独立 **0.8 管理能力**；统计 0.6、排程 0.7 不增加隐式字段。旧服务可继续统计；受保护 STOP 缺少学校授权、会话变化、响应损坏或接口不支持时不放行。
- 保护正常操作入口，不能对抗 Windows 管理员结束进程、修改文件或关机。浏览器关闭后采集继续，但网页展示恢复只在页面运行时生效。
