# 自动录课页面整理

日期：2026-10-03。目标：让用户能直接找到实际录制开关、安排课程和查看视频结果，把可选的模拟操作独立出来。

## 使用流程

1. 点击顶部“录制设置”，选择屏幕、声音、保存目录并保存。
2. 在“录课计划”左侧保存每周安排；右侧选择日期，检查课程和录制时间。
3. 某天需要临时改动，选中课程后点“这天录制”或“这天不录”；“取消这天的手动安排”恢复原计划判断。
4. 不按课程录制时，展开“另加一次录课（指定时间段）”，保存所选日期的完整开始和结束时间。
5. 点击顶部“开启自动录课”。顶部直接显示后台返回的实际状态，包括等待下一项、正在录制和暂停原因。
6. 在“录制记录”查看实际执行结果与视频位置。收起窗口仍在后台运行；完整退出并重开软件后需重新开启自动录课。

## 试运行是什么

“试运行（高级）”是原来的预演，仅在学校时间到点时模拟开始和结束，不会加速时间，不采集屏幕和声音，也不生成视频。日常录课无需先试运行。

试运行开关、跳过、记录与真实录制独立。模拟状态只在高级页显示，不再覆盖日常课程清单中的计划说明。高级页仍能查看所选日期的课程；只有学校当天能模拟执行，未来课表到当天重新核对。

## 本轮范围与验证

- 页面分为录课计划、录制记录、试运行三个页签，默认打开录课计划。
- 实际状态和总开关移到顶部；录制设置入口复用主窗口已有的录制窗口，不创建第二套录制客户端。
- 保留每周规则、指定日期安排、科目排除、暂停、冲突、学校时钟、执行记录和去重逻辑；不改 Host、Core、录制器、协议或配置文件格式。
- 小窗口中编辑区可滚动，单次时间段默认收起；录制记录没有内容时显示说明。
- 原有 UI 验收脚本同步窗口标题和页签路径，没有改变真实录制或预演的断言含义。
