## 自动验收入口

Windows PowerShell 5.1 与 PowerShell 7：

```powershell
./scripts/test-desktop-delivery.ps1
./scripts/test-desktop-delivery.ps1 -PackageResultPath '<打包入口返回的 result.json>'
```

第一条检查模拟安装包、隔离安装／升级／卸载、开发组件的合成媒体；`candidateChecked=false`，不能证明最新候选可交付。第二条先验证同一次完整构建的 ZIP、安装 EXE、元数据和载荷，之后使用包内录制组件执行测试，不启动正式应用或真实采集。

结果位于 `.artifacts/desktop-delivery/<ID>/result.json`，包括每项退出码、日志、子报告和人工／大屏待验收标记。失败或中断不算通过。Python 仅用于维护者的合成媒体验证，用户安装后不需要 Python。

安装器回归采用独立 HKCU 测试登记和随机目录；不会安装正式 NPEduTools 或更改真实登录启动。程序仍需管理员权限；本轮不自动处理 UAC。

## 人工接手：按顺序走一次

1. 先在测试 Windows 环境试装候选，核对目录、开始菜单入口、管理员启动和 OOBE。ClassIsland／ExamAware2 本体及插件仍需按引导配置。
2. 用同一 Windows 账户短录并回放，确认两音源、保存路径、学校连接、学校时间、麦克风和自动录课计划。
3. 保存并完整退出应用后覆盖升级，确认配置、配对、计划和视频保留；升级后重新核对外部软件路径及插件连接。
4. 关闭该安装位置的登录启动再卸载，确认用户文件保留；重新安装并核对原配置。
5. 最后在单台班级大屏做长期录课、定时监测及重启／休眠／锁屏验收。开发电脑通过不能替代此步。

旧候选／历史报告不证明当前源码。安装与升级细则见 [安装说明](../INSTALLER.md)，现有隔离回归见 [安装器任务卡](WINDOWS-INSTALLER-20261003.md)。
