# 自习监测与联机校准的局部调整

v1.1.2 侧重稳定性，沿用现有配色、控件和全屏展示。本次只整理两个管理页面，不改变采集、学校排程、双阈值或参考算法。

## 自习监测

首屏查看当前阶段、下一次定时自习、采集与展示状态，直接打开实时监测、手动自习、自习座位表和校准。

展开“麦克风与摄像头”后使用原有设备选择、保存与学校解锁功能。折叠时显示设备配置摘要；摘要不代表设备正在采集。时间来源与运行规则放在说明区。

## 联机校准 (Beta)

1. 关闭 SoundLab2，插入仪表，输入管理口令，点击“验证口令并查找仪表”。选择设备后进入同期采样；单次读取保留在连接诊断中，不作为校准数据。
2. 在“设置”步骤核对仪表时间加权。现场模式使用已有默认门槛；高级参数与严格模式仍可使用。点击“下一步：准备采样”仅创建草稿。
3. 在“采样”步骤明确开始采样；现场模式自动完成两段。采样中可以取消，关闭拥有采样的窗口也会执行原有取消流程。采样记录与诊断可展开查看。
4. 完成后进入“结果”。复核警告仍须明确确认，结果不自动保存；需要重新采样时点击“返回采样”。已保存参考与清除入口保留在说明区。

顶部的口令验证／刷新在每一步可见。后台连接失效时可以回到设置；陈旧状态不能保存，也不会自动重开采样。设备与输入设置变化后的参考失效规则保持不变。

布局使用现有窗口尺寸适配和垂直滚动。隔离验证覆盖私有 Pipe、模拟 HID、合成信号和 2K／200% 可用空间；这些不代替一体机、真实 USB 与声学校准验收。
