# M1：ClassIsland 启动、路径配置与结果持久化

日期：2026-09-06。

## 交付范围

WPF 新增程序路径、文件选择、保存、重新读取、启动按钮和最近一次启动结果。Host 校验本机绝对路径、支持的文件名、可执行文件头与 ClassIsland 产品元数据，使用明确的可执行文件路径启动，不接受任意命令或自定义参数。

已有实例时核对进程路径和会话，只验证课程接口；其他路径/会话或无法核实的实例会阻止启动。新进程启动后，Host 最多等待 20 秒读取课程状态，成功才记录“已就绪”。只读监听保持自己的重连逻辑，不因启动失败退出。

界面关闭不取消 Host 已受理的操作；重开界面读取最新记录。“停止后台并退出”取消就绪验证，将未确定结果记为 Unknown，不关闭 ClassIsland。Host 重启时把遗留 Running 记录改为 Unknown，不重放启动。

进程匹配使用路径、会话及上游实例锁作保守检查；读取就绪状态沿用既有官方 IPC 契约。此版本没有给上游固定命名管道增加独立的服务端认证，也不据此开放关闭或修改档案等操作。

## 配置与执行记录

默认文件：`%LocalAppData%/NPEduTools/config/classisland.json`。

- SchemaVersion 为 1，配置使用 Revision 拒绝覆盖其他窗口更新的设置。
- 单一 Host 持有数据目录写入锁；其他进程不能同时修改同一存储。
- 同一 JSON 文件保存配置与启动记录，先写同目录临时文件并刷新内容，再替换主文件，保留 `.bak`。
- 先持久化 Running 意图，再启动外部进程；意图写入失败不会启动。
- 结果落盘失败后禁用后续启动，不能以未保存的内存结果报告成功。下次启动将未完成记录标为 Unknown。
- 主文件损坏时保留 `.corrupt-*` 副本，并尝试读取备份供查看。由于备份可能缺少最近一次意图，禁止继续启动或改配置，须先核实数据。无有效备份时保持只读课程功能并显示存储错误。
- 同一启动 RequestId 重试返回已有记录，包括 Host 重启后的重试；窗口的响应不确定时继续使用同一 ID。不同请求遇到进行中的启动会返回 LaunchBusy。
- 普通记录至少保留 30 天；Unknown 记录不自动清理。最多 200 条，达到上限拒绝新启动，避免悄悄丢失去重依据。30 天以外已清理的请求不承诺去重。

自定义 Host 管道默认使用临时目录下按管道名派生的独立存储，避免测试污染用户配置。开发时也可通过 Host 的 `--data-dir` 指定隔离目录，不能通过客户端协议任意更改数据目录。

## 协议

| 能力 | 参数 | 结果 |
| --- | --- | --- |
| `classisland.config.get` | 无 | 当前配置、最近启动记录与存储提示 |
| `classisland.config.set` | ExecutablePath、ExpectedRevision | 保存结果；修订号冲突时不覆盖 |
| `classisland.start` | 稳定 RequestId，无路径或命令参数 | Running 表示意图已落盘并受理，重复请求返回旧记录 |
| `classisland.execution.get` | 可选 OperationId | 指定请求结果，省略时读取最近一次记录 |

启动结果通过 `HostResponse.Launch` 传输。课程状态接口保持现有只读语义。新增可选字段为空时不写入 JSON，以保持原有 ping/status/watch 消息格式；旧 Host 不支持新增能力，需要退出旧后台后使用同版 App 与 Host。
