# NPEduTools Pre 20261001

> 归档记录：正文保留当时的范围、决定与验证结果，不代表当前功能、发布或部署状态。[历史资料索引](../README.md)。

学校互联预览版，汇总 NPEP 通知、完整考试模式、ExamAware 方案投递，以及原生噪音监测、学校排程和统计报告。本次交付三仓源码并合并至主分支，二进制下载包另行提供；旧 InDev 下载包不能代替新版。

> [!CAUTION]
> **Pre 预览版：真实班级大屏与学校排程现场验收尚未完成。**
>
> 已完成隔离自动测试及部分开发电脑人工联调，仍可能存在驱动、权限、时间来源和长期运行问题。此次选择先公开源码，待现场补充验证；没有将未测项目标记为通过。建议先在单台设备试用，保留手动切换及备用方案。

## 新增与完善

- **学校互联**：NPClassworks／KV 与 NPEduTools 配对、上报状态、暂停恢复、撤销和断线恢复；完成配对即授权目前提供的学校控制能力。
- **桌面通知**：学校通知独立置顶展示，采用分等级纯色与大字；普通及以上通知配合变暗遮罩，需手动关闭。支持持久化收件与回执，修复遮罩偶发覆盖通知窗口的问题。
- **完整考试／日常切换**：网页可让单台设备联动软件运行、自启动和自动录课暂停，并可远程返回日常。支持处理中断后的核实与重试；完成回执不等于持续实时状态。
- **ExamAware 方案**：投递、校验和查看方案摘要，明确请求开始放映；不是仅建立连接。配套桥接插件为 `0.4.0`，适配 ExamAware 1.5.2。
- **原生噪音监测**：由 NPEduTools 使用已保存的麦克风，网页负责控制与展示。只上传统计报告，不保存或上传原始录音。原生接管后网页停用旧采集与旧定时功能；失联不自动退回网页采集。
- **学校排程**：学校按年级／班级管理每周监测时段，桌面按 ClassIsland 学校时间执行。手动停止会跳过本次时段，可明确恢复；考试期间暂停自动会话。报告按会话核对排程来源，无法关联时显示未知。
- **开发与发布检查**：Windows 原生 PostgreSQL 与统一启动入口、PowerShell 5.1 跨端验收入口；网页生产构建及静态 PWA 校验，排除生成缓存干扰源码检查。

## 开始使用与升级

1. 网页与 KV 使用本版配套源码。KV 按完整 Prisma 迁移链部署，新增考试、方案、噪音与排程表；更新前备份数据库、配置和当前运行版本。保留现有 NPEP 身份及配置卷，不重复首次激活。
2. 桌面按 `global.json` 安装对应 .NET SDK，在 Visual Studio 打开 `NPEduTools.sln` 并运行 `NPEduTools.App`。当前应用标识为 `0.1.0-pre.20261001`／`Pre 20261001`。按需要安装桥接插件、设置程序路径、管理员任务与麦克风，再完成学校配对。
3. 新桌面可能执行已经保存的学校规则。上线前核对年级继承与班级范围，先测试一台设备；尚未完成现场验证时，不直接扩大无人值守使用范围。
4. 录制仍需单独安装 FFmpeg／ffprobe，发行包不附带它们；见[录制工具安装](../../RECORDING-TOOLS-INSTALL.md)。噪音监测不依赖这两个工具。

## 已知限制

- 噪音数值为 dBFS 信号电平，不是校准声压级，不用于班级评分／排名。不支持原音频上传、摄像头或跨班批量考试控制。
- 自动排程需要可靠的 ClassIsland 学校时间；失效时等待／停止，不改用系统时间。已确认规则可在当前 Host 内离线运行，租期最长 24 小时；服务器禁用／撤销无法瞬间通知离线设备，需要立即停止时请本机操作。
- N3 编辑器退出协商仍有已知问题：切换前先保存并关闭编辑器。远程返回前请现场正常结束放映，不强制关闭未保存窗口。
- 真实大屏长期运行、学校排程时间／驱动、Windows 重启及休眠等现场项目仍待补测。开发电脑结果不能替代。
- HTTP 地址允许使用且为明文；HTTPS 继续严格验证证书，失败重试不代表绕过验证。
