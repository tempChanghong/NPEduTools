> 归档记录：正文保留当时的范围、决定与验证结果，不代表当前功能、发布或部署状态。[历史资料索引](../README.md)。

Windows x64 自包含试用包，无需另装 .NET。此包包含本次确认的通知样式；主程序基础 InDev 版本号保持不变，以压缩包名称和本说明区分构建。

## 本次修复

修复遮罩可能覆盖通知窗口的问题：每张遮罩明确排在通知窗口之后，在 Windows 应用层级变更前约束遮罩的位置，不依赖延迟激活。保留 r2 确认的视觉样式。

原代码在新增的 Windows 原生层级检查中复现失败；修复后，重叠独立遮罩、12 轮重新定位/激活/移动、遮罩重建与关闭清理检查通过。这是开发机单屏模拟额外遮罩的验证，不能代替实体多屏及用户现场复测。

## 保留的样式

- 左侧四块色带紧贴并列、贯穿全高，从外侧浅色逐步接近正文主色；最内一格仍保留分界。
- 删除铃铛和图标背景，保持色带连续；右侧以大号编号及中文标注通知等级，01–04 对应次要、普通、重要、紧急。
- 短通知正文区域垂直居中，长通知从顶部滚动；小窗口隐藏右侧重复等级标识，顶部仍保留等级文字。
- 白色实心关闭按钮固定在底部，支持键盘焦点提示。
- 保留次要无遮罩、普通及以上全屏变暗遮罩、置顶手动关闭和短淡入淡出动画。

## 开始测试

1. 完全退出旧 NPEduTools，包括托盘后台。
2. 将 ZIP 完整解压到新文件夹，不要混入旧版本文件。
3. 运行 `Start-NPEduTools.cmd`。同一 Windows 用户可沿用已有学校互联配对，无需重新配对。
4. 在“设置 → 学校互联 → 学校通知”预览四个等级；检查普通及以上遮罩、长正文滚动、手动关闭后桌面恢复，再验证真实通知接收。

不要同时运行两个版本。这个包不会自动启动、发送通知或替换正在运行的程序。通知仍使用约 10 秒 HTTP 轮询，遵循原有网页弹窗选择；此次仅更新桌面端，无需再部署后端。

## 文件作用

- `Start-NPEduTools.cmd`：启动入口；`app/`：主程序、后台和 .NET 运行时，需保持目录完整。
- `ClassIsland-plugin/`、`ExamAware2-plugin/`：其他联动功能使用的桥接插件，学校通知不依赖它们。
- `RELEASE-NOTES.md`：本说明；`README.md`：通用使用指南。
- `Install-Recording-Tools.ps1`、`RECORDING-TOOLS-INSTALL.md`：可选录制工具安装入口与说明，本包不附带 FFmpeg。
- `package-manifest.json`、`verify-portable-package.ps1`：文件清单与校验工具。
- 源码归档、第三方源码、依赖清单与许可证：随包构建及许可材料。
