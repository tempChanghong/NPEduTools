## 一个用例

年级设置周一 19:00–21:00，班级选择继承。学校时间到达 19:00，计算器返回 `Start`；已有排程会话返回 `Keep`；到达 21:00 返回 `Stop`。这些是执行建议，不代表麦克风已经运行，后续 Host 执行器必须根据真实采集结果确认。

若人工提前停止，调用方保留该窗口的 `Skipped` 记录，后续计算返回 `Wait`，直至明确恢复或进入下一窗口。更新为与旧窗口重叠的时段仍尊重跳过。已有手动会话始终由手动流程管理，排程不停止或接管它。

| 规则 | 当前实现 |
| --- | --- |
| 范围 | 班级 `Inherit / Override / Disabled`；年级 `Override / Disabled`。缺失配置用 `null` 表示，不是可保存的政策对象 |
| 窗口 | 星期 1–7 为周一至周日，按开始日计算；`[开始, 结束)`，支持跨午夜、跨周、跨年、闰日 |
| 合并 | 相邻／重叠合并；单条及合并后连续窗口均最多 180 分钟；最多 32 条规则 |
| 学校时间 | C# 使用 ClassIsland 的零偏移日历载体；JS 使用相同日历字段计算，接受其 1–7 位小数秒，不执行加八小时转换。年份支持 2000–9998 |
| 校时 | 未就绪、冻结、失联及异常日期待核实：不启动，停止排程会话；正常午夜保持运行，错过时段不补采 |
| 考试 | 排程等待，已有排程会话停止；返回后仍遵守本次跳过记录 |
| 失败 | 同一窗口及同一麦克风配置的失败不反复启动；更换配置或明确清除失败后可重试 |
| 租期 | 当前 Host、学校／班级／学期范围和有效版本全部匹配，单调计时未超期才有效；最长 24 小时。Host 重启、换绑、版本变化、计时回退均失效 |

租期记录的建立／持久化、真实绑定资格和失败记录维护仍由后续适配器实现；纯计算器不会自行读取网络或确认授权。JSON Schema 校验对象结构、字段和范围，连续时长及周边界合并仍需算法校验，两者不能互相替代。
