## 准备

1. 保留原规则，选一个测试学校／班级；本地 KV 应用现有 Prisma 迁移后，用统一开发入口启动网页和后端。
2. 在 Visual Studio Debug 启动 NPEduTools，核实学校连接、已保存麦克风及 ClassIsland 学校日期时间。也可测试完整解压后的发行 ZIP，但不要同时运行两份桌面程序。
3. 学校后台进入 **学校管理 → 大屏账号 → 打开 NPEP 设备互联 → 学校自习噪音排程**，为测试班级设置覆盖规则：按 ClassIsland 当前星期，约一分钟后开始、持续两分钟。避免与原年级规则或手动会话混淆。

## 只走这一条闭环

| 动作 | 应看到什么 | 结果 |
| --- | --- | --- |
| 保存规则 | 管理页保存成功；大屏“课堂工具 → 噪声监测 → 学校自动监测”随后显示当前版本已应用 | 待测 |
| 等学校时间进入窗口 | 桌面自动开始；网页显示自动会话及学校时间，讲话时读数有变化 | 待测 |
| 网页手动停止 | 麦克风释放，本次窗口跳过；等待十秒仍不会偷偷重启 | 待测 |
| 点击“恢复本次自动监测” | 窗口尚有效时恢复采集，实际状态回传；受理回执不等于已开始 | 待测 |
| 离开噪声页／关闭网页 | 桌面继续执行，直到学校时间到结束边界后停止 | 待测 |
| 重新打开页面与学校报告 | 会话来源、时间、有效采样及覆盖率一致；每个已结束会话只有一份报告 | 待测 |

停止与恢复可能产生不同会话 ID，按各自会话核对去重。dBFS 是信号电平，不是教室声压级，也没有原录音上传。
