## 视觉与交互

使用 Swiss 风格的左对齐网格、清晰字重层级、大留白和细分隔线。左侧独立视觉区由四块等宽、紧贴并列的色带横向排列，铺满左侧区域，没有条间缝隙或左右边距，从窗口顶部延伸到底部，没有上下留白或中间断口。铃铛和底块已移除，避免打断色带的连续性。正文右侧独立一列显示大号通知等级编号及中文名称，形成第二个视觉重点；不再使用原有阶梯色块及标题栏小色块。

四块色带从外侧到正文方向依次使用通知底色混入 70%、48%、28%、12% 白色，越靠近正文越接近主色，但最内一格仍与正文有分界。没有渐变、模糊或循环闪烁。默认左区宽 96 DIP，紧凑布局缩至 64 DIP。右侧编号按次要、普通、重要、紧急分别为 01、02、03、04，配有“通知等级”说明及中文等级，表示级别而非通知数量；紧凑布局隐藏这份重复标识，顶部保留中文级别。短通知的标题和正文作为整体在阅读区域内垂直居中；超过可用高度时自然撑开，从顶部开始滚动。关闭按钮采用白底、通知色文字，最小宽度 196 DIP，并提供独立的键盘焦点外框。

| 级别 | 背景色 | 白字对比度 |
| --- | --- | --- |
| 次要 | `#087F5B` | 5.00:1 |
| 普通 | `#2157B8` | 6.73:1 |
| 重要 | `#947000` | 4.59:1 |
| 紧急 | `#C52B36` | 5.57:1 |

重要级采用较深的黄色，以兼顾白字可读性。通知级别同时用文字标识，不只依赖颜色。

- 默认 1120 × 720 个 WPF 逻辑像素，按显示器工作区约束尺寸。不是全屏锁定界面。
- 标题 44、正文 28；较小窗口使用标题 32、正文 24。长内容滚动，不为塞入全部内容而持续缩小字号。
- `Topmost=true`，不设置自动关闭计时器；关闭按钮固定在底部。可拖动顶部区域。
- 次要通知不主动激活窗口，不加遮罩；普通、重要和紧急通知覆盖各显示器（含任务栏）的暗色遮罩，并激活通知窗口。初始焦点放在正文滚动区域，避免直接聚焦关闭按钮造成误触。
- 遮罩截获鼠标/触摸，点击背景只聚焦通知，不能单独关闭遮罩。通知关闭、程序退出或通知失效后手动关闭时一起移除；显示器配置变化时重建遮罩。它是普通桌面窗口，不安装键盘钩子，不拦截 Windows 安全操作，也不能保证覆盖独占全屏程序。
- 入场淡入 180 ms，内容向上平移 12 DIP；关闭时淡出 120 ms。遵循 Windows 的客户端区域动画设置，高对比度模式也关闭这些动画。没有循环或闪烁动画。
- 手动关闭不等于“老师已读”。正式通知只有实际渲染后记录 DISPLAYED，明确手动关闭才记录 DISMISSED；程序退出不能伪造手动关闭。关闭状态先在 Host 落盘，失败时保留窗口并允许重试。
- 内容只通过文本绑定展示，不执行 HTML、脚本、富文本或远程 UI 定义。
- 正式通知一次一个窗口，待显示队列按紧急、重要、普通、次要排序，同级按发布时间排序。新消息不自动关闭当前窗口。次要静默通知仅进入列表，手动打开才记录展示。预览与真实收件箱独立，但不同时打开两个窗口/遮罩组；预览关闭后继续处理真实队列。
- 通知撤回、修订、过期或授权停用时隐藏旧正文，保留状态窗口让用户手动关闭；后续有效通知继续排队。连接无法核实时不启动新弹窗。

### 2026-09-25 r3 遮罩层级修复

用户报告偶发遮罩盖住通知本身。原实现每次 Place 使用 HWND_TOPMOST 将遮罩提升至置顶组前端，只有当前显示器的遮罩是通知的 owner，不能约束其他遮罩，也依赖初始化与激活顺序。新实现把每张遮罩的 hwndInsertAfter 明确指定为通知 HWND，并在自身 WM_WINDOWPOSCHANGING 中约束后续的层级请求，保留 NOACTIVATE / NOOWNERZORDER；关闭时移除 HwndSource hook。不使用计时重试或反复抢焦点。

回归检查直接遍历 Windows 原生 Z-order：在单屏开发机叠加一张独立遮罩模拟跨屏重叠，原实现失败，修复后通过。另覆盖 12 轮置顶请求、定位、激活及移动、遮罩重建，以及原有四级/小窗/保存失败/退出清理检查。实体混合 DPI 多屏与用户现场问题仍需复测。

依据：[Microsoft SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos)。打包版本为 NPEP-N2-preview-20260925-r3，保留 r2 视觉样式。
