# 自动录课：今日计划与预演

更新：2026-09-19。现有预演已全面采用 ClassIsland 学校时间；实施、协议、测试证据和限制见 [第二步报告](CLASSISLAND-SCHOOL-CLOCK-PREVIEW.md)。**预演只记录应开始、应停止，不采集屏幕或声音，不生成视频。** 独立手动录制继续使用原入口。

## 使用方法

1. 在 ClassIsland 2.1.0.1 中启用 `npedutools.recordingbridge` 只读桥接插件并重启。开发目录与打包方式见 [P0 报告](CLASSISLAND-RECORDING-BRIDGE-P0.md)；缺少插件时预演等待，不使用系统时间代替。
2. 运行 `./scripts/start-app.ps1`，点击主窗口“自动录课计划”或侧边栏“今日计划与预演”。
3. 核对顶部 ClassIsland 日期时间、学校日期、生效课表和计划窗口。
4. 配置星期、科目、节次、课前提前量和课后余量，点击“应用并保存规则”。节次留空表示全部，也可输入 `1,3,5`；各筛选条件同时满足才入选。
5. 点击“启动预演”，查看应开始、应停止的记录。

当前仍是单条跟课表规则：默认所有星期、科目、节次，提前 2 分钟、延后 5 分钟。前后余量分别可选 0～5 分钟，课后不能超过 5 分钟。用户提出的周期/指定日期多条计划、任意固定时间段和 17 项默认排除尚未实现，不能把当前“全部科目”理解为已经排除了这些课程。

科目按 ID 保存。列表来自学校今天的课表；已选择但今天没有出现的 ID 仍保留。“二分钟铃”目前指正式上课前固定两分钟，不监听铃声，也不跟随 ClassIsland 自定义提醒。

| 操作 | 结果 |
| --- | --- |
| 跳过 / 结束选中节 | 未开始则跳过；正在预演则结束；本次课程不会重复开始 |
| 今天不再预演 | 结束本节，暂停学校日期当天的新任务；时间失效时不可操作 |
| 恢复今日预演 | 恢复当天未处理课程，已预演/已跳过的课程不重开 |
| 停止预演 | 关闭开关，结束当前模拟会话 |
| 关闭计划窗口 | 隐藏窗口，已启用预演继续检查 |
| 完整退出应用 | 停止预演，下次启动保留规则和记录，开关默认关闭 |

## 时间窗口与异常

10:00–10:40 的课默认预演窗口为学校时间 09:58–10:45。收到健康时间样本已经进入窗口才开始；课中可以补开始，只有课后余量则不补开。

学校时间用于日期、星期和业务窗口。本地单调经过时长用于新鲜度和活动预演剩余上限，不读取 Windows 日历来替代学校时间。

| 情况 | 当前行为 |
| --- | --- |
| 断线、缓存达到 3 秒或学校时间疑似冻结 | 不开始新任务；活动预演按原剩余上限结束 |
| 时间回拨 | 重新校验，不延长原期限、不清除去重记录 |
| 时间前调越过结束 | 下一次检查结束活动预演 |
| 日期发生跳变 | 要求核对学校日期后重新启动；自然午夜跨日不要求确认 |
| 课表停用、档案切换或本节不再符合规则 | 健康快照证实后结束当前预演 |
| 课时改长/缩短 | 不延长原截止；更早的终点可以收紧截止 |
| 相邻课程窗口重叠 | 缩短上一节课后余量；无法让开的正式课时/提前窗口冲突不启动 |
| 临时课表换 ID 或科目 | 同档案中正式时段重叠的课程沿用去重标记 |
| 休眠/唤醒 | 收到电源事件后停止预演，需要重新核对启用；物理休眠仍待实机验收 |

计划窗口约每 500 ms 检查一次，不承诺毫秒级触发。WPF 卡住时只能恢复后记录结束；正式采集必须另行使用 Host/录制工作进程约束。跨午夜的单节课程暂不支持。

## 日程来源

链路：ClassIsland 有效时间/生效课表 → P0 只读插件 → Host 常驻桥接进程 → 学校时间缓存 → 客户端健康校验 → 今日计划与预演。

插件在 ClassIsland UI 线程发布同一版本的学校时间与日程，客户端不重新实现单双周或临时层选择。每份日程最多 64 节，响应最多 64 KiB。新任务需要至少三个有效前进样本完成预热，以及同日、启用、有效的课表。

旧 `classisland.schedule` 接口仍供诊断使用，但不再用于本窗口；旧的系统时间/倒计时比较不是新预演的后备路径。无课表和课程计时暂停时仍可显示学校时间，跟课表的预演不可开始。

## 本地保存

位置：`%LocalAppData%/NPEduTools/ui/<Host 管道哈希>.recording-preview.json`，格式 v2，最多 512 个课程发生标记、200 条事件，读取上限 512 KiB。

旧 v1 文件先备份为 `.v1.bak`，只迁移规则；原系统日期的事件和跳过记录留在备份中，不转换成学校日期。迁移后开关关闭，需要重新核对。损坏/未知格式保留原文件并禁止修改及预演；保存失败会停止预演。

应开始时立即生成去重标记并保存。重启后未完成会话记录为中断；没有新鲜学校时间的停止记录显示“学校时间未知”。预演标记不是录制成功凭据，未来真实录制账本必须独立。
