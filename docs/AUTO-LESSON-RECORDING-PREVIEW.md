# 自动录课：计划与预演使用说明

更新：2026-09-19。已实现学校时钟、未来日期查询与周期/指定日期计划，实施与验证见 [P2 报告](AUTO-RECORDING-PLANS.md)。现已增加独立的真实录制开关，操作和截止保护见 [P3 报告](AUTO-RECORDING-EXECUTION.md)。**预演只记录应开始、应停止，不采集屏幕或声音，不生成视频；真实录制由“启用自动录制”控制。** 手动录制继续使用原入口。

## 使用方法

1. 在 ClassIsland 2.1.0.1 中启用 `npedutools.recordingbridge` 0.2.0.0 桥接插件并重启。配套包见 [本轮报告](AUTO-RECORDING-PLANS.md)；缺少插件时预演等待，不使用系统时间代替。
2. 运行 `./scripts/start-app.ps1`，点击主窗口或侧边栏“自动录课计划”。
3. 核对顶部 ClassIsland 日期时间、学校日期、生效课表和计划窗口。
4. 左侧“周期规则”可以新建多条规则，选择“跟随课表”或“固定时间段”，配置星期与可选生效日期范围。新建规则默认停用，配置后勾选启用并保存。课程规则可筛选科目及节次，节次留空为全部；各条件同时满足才入选。
5. 右侧选今天、明天、后天或明确日期。选中课程后点击“本日录制／本日不录／恢复继承”；下方可以增加单日固定时段。未来课表仅为预计，不替换正在运行的今日预演。
6. 左侧“科目与暂停”可修改排除名单、为选中课程的科目设置长期例外，或暂停到指定学校日期（包含该日）。
7. 点击“启动预演”，到“预演记录”查看应开始、应停止的记录。浏览哪一天都只运行学校今天的任务。

全新配置自带一条默认课程规则：所有星期与节次、提前 2 分钟、延后 5 分钟，同时排除约定的 17 项科目。前后余量分别可选 0～5 分钟，课后不能超过 5 分钟。固定时段填写完整起止时间，不叠加余量、不按科目排除。周期与单日时段都不能跨午夜。

默认排除：心理、体育、书法、体育(室内)、选修课、班会、技术、艺术、美术、音乐、物理(实验)、化学(实验)、生物(实验)、晨测、早读、午自习、报告厅活动。中英文括号及括号周围空格统一后按完整名称匹配，普通“物理”不会误排除。单日明确录制可以覆盖默认排除，不能绕过停用课表、冲突、时间源异常和已预演/已跳过记录。

科目按档案内 ID 保存。列表来自右侧所选日期的课表；已选择但当前课表没有出现的 ID 仍保留。“二分钟铃”目前指正式上课前固定两分钟，不监听铃声，也不跟随 ClassIsland 自定义提醒。

| 操作 | 结果 |
| --- | --- |
| 预演：跳过 / 结束选中节 | 未开始则跳过；正在预演则结束；本次课程不会重复开始 |
| 今天不再预演 | 结束本节，暂停学校日期当天的新任务；时间失效时不可操作 |
| 恢复今日预演 | 恢复当天未处理课程，已预演/已跳过的课程不重开 |
| 停止预演 | 关闭开关，结束当前模拟会话 |
| 关闭计划窗口 | 隐藏窗口，已启用预演继续检查 |
| 完整退出应用 | 停止预演，下次启动保留规则和记录，开关默认关闭 |

## 时间窗口与异常

10:00–10:40 的课默认预演窗口为学校时间 09:58–10:45。收到健康时间样本已经进入窗口才开始；课中可以补开始，只有课后余量则不补开。

学校时间用于日期、星期和业务窗口。本地单调经过时长用于新鲜度和活动预演剩余上限，不读取 Windows 日历来替代学校时间。

| 情况 | 当前行为 |
| --- | --- |
| 断线、缓存达到 3 秒或学校时间疑似冻结 | 不开始新任务；活动预演按原剩余上限结束 |
| 时间回拨 | 重新校验，不延长原期限、不清除去重记录 |
| 时间前调越过结束 | 下一次检查结束活动预演 |
| 日期发生跳变 | 要求核对学校日期后重新启动；自然午夜跨日不要求确认 |
| 课表停用、档案切换或本节不再符合规则 | 健康快照证实后结束当前预演 |
| 课时改长/缩短 | 不延长原截止；更早的终点可以收紧截止 |
| 相邻课程窗口重叠 | 缩短上一节课后余量；无法让开的正式课时/提前窗口冲突不启动 |
| 临时课表换 ID 或科目 | 同档案中正式时段重叠的课程沿用去重标记 |
| 休眠/唤醒 | 收到电源事件后停止预演，需要重新核对启用；物理休眠仍待实机验收 |

预演窗口约每 500 ms 检查一次，不承诺毫秒级触发。WPF 卡住时预演只能恢复后记录结束；真实采集已经由 Host 和录制工作进程独立约束，详见 P3 报告。跨午夜的单节课程暂不支持。

## 日程来源

链路：ClassIsland 有效时间/生效课表 → P0 只读插件 → Host 常驻桥接进程 → 学校时间缓存 → 客户端健康校验 → 今日计划与预演。

插件在 ClassIsland UI 线程发布同一版本的学校时间与日程，客户端不重新实现单双周或临时层选择。每份日程最多 64 节，响应最多 64 KiB。新任务需要至少三个有效前进样本完成预热；课表型任务还需要同日、启用、有效的课表。固定时段不要求有课表，但仍必须有健康的学校时钟。

预计课表可查询学校今天至第 30 天，采用本体 `GetClassPlanByDate`，不会切换当前课表。进入当天后使用实时生效课表重新合并规则。未来课表不会自动连续轮询；需要重新获取时点击“刷新日程”，连接实例或学校日期变化后会失效重读。

旧 `classisland.schedule` 接口仍供诊断使用，但不再用于本窗口；旧的系统时间/倒计时比较不是新预演的后备路径。无课表和课程计时暂停时仍可显示学校时间，跟课表的预演不可开始。

## 本地保存

位置：`%LocalAppData%/NPEduTools/ui/<Host 管道哈希>.recording-preview.json`，格式 v2，最多 512 个课程发生标记、200 条事件，读取上限 512 KiB。

新增同目录 `.recording-plans.json`，格式 v1，保存周期、单日、覆盖、排除与暂停设置。旧预演规则迁为一条停用草稿，迁移前另存 `.recording-preview.json.pre-plan-book.bak`；旧筛选不暗中套入新的 17 项排除，核对后再启用。默认自动开关保持关闭。计划文件损坏或未知版本同样保留原文件并停用预演。

旧 v1 文件先备份为 `.v1.bak`，只迁移规则；原系统日期的事件和跳过记录留在备份中，不转换成学校日期。迁移后开关关闭，需要重新核对。损坏/未知格式保留原文件并禁止修改及预演；保存失败会停止预演。

应开始时立即生成预演去重标记并保存。重启后未完成模拟会话记录为中断；没有新鲜学校时间的停止记录显示“学校时间未知”。预演标记不是录制成功凭据，现有真实录制账本与其完全独立。
