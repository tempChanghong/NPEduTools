# 主页：当前任务与后续安排

主页首屏分为“当前任务”和“接下来的安排”。自习与录课各自占一行，状态刷新只更新文字和按钮，不重建页面、改变两项任务的排列或自动切页。

- 自习按钮根据后台上下文进入学校自习或手动自习。准备、预约、启动、结束与状态未知分别展示；只有学校执行回执确认新鲜采样时才显示采样已确认。
- 录课按钮在空闲时进入立即录制，在进行／暂停／保存阶段进入会话管理，已保存或未完成时进入结果页。未知状态显示检查入口，不能当作已经停止。
- 学校自习沿用后台的下一时段和时间来源。手动预约使用 Windows 时间；考试模式学校自习也明确标注 Windows 时间。自动录课使用 ClassIsland 学校时间。不同来源的时间不混排、不自行换算。
- 自动录课新增只读 `Next` 和 `NextState` 摘要，由 Host 的现有排程循环产生，仅表示当天已启用、尚未处理的下一项。关闭、暂停、今日跳过、时钟失效、计划已处理或等待计算时，摘要不继续显示旧时间。关闭录课时不会为了预览重新执行排程或启用录制。
- 旧 Host 未提供结构化摘要时，主页说明时间未确认，并保留查看安排入口；不解析后台说明句子冒充确定的排程数据。
- 课堂模式、快捷启动、点名、考试看板和学校互联入口保留。设备准备与课堂辅助放到展开区；模式出现新的异常时主动展开说明，同一异常后续刷新尊重用户收起的选择。

更新不改变自习保护、完整退出、录课租约、摄像头策略、校准、排程配置和全屏展示。更新需要使用同一版本的 App 与 Host；新增摘要字段向后兼容。

## 验证

`scripts/test-desktop-field-fixes.ps1` 已包含 `--home-workspace`。主页测试使用正式 WPF 页面、合成状态与隔离录课客户端，检查并行任务、预约、时钟与连接失效、恢复、完成后路由、模式异常展开和紧凑布局。既有录课工作区的私有 Pipe 测试还验证主页管理入口不提交开始、停止或停用请求。

原生测试直接覆盖 Host 只读摘要的暂停、时钟、跳过与禁用边界，验证学校墙钟显示不被当成 UTC 转换。逻辑 1280×700、1024×540、760×520 覆盖高缩放下的空间；真实一体机 200% 触控仍需验收。

测试不调用真实采集，不操作学校配置。本轮保留本地功能分支，不发版。
