# 主工作台与自习中心

本轮基于 v1.1.2，改动正式 App 操作界面；版本号与全屏自习展示保持现有版本。`tools/NPEduTools.UiPrototype` 是独立的模拟原型，不参与发布依赖或正式启动。

## 使用路径

- 主页先显示当前任务、下一次学校自习和设备准备。状态来自现有 Host 查询；设备已选择、摄像头策略开启均不代表正在采集。未确认时显示待确认。
- 统一“自习”入口：手动自习、学校定时自习、报告。原快捷侧栏、全屏展示的管理回调也进入对应页签。
- 手动默认立即开始、主动结束；选择指定日期后才展开时间输入。预约或执行期间收起新建表单，底部按钮分别为取消预约或结束自习。关闭设置或切页不停止监测；学校定时优先与会话标识校验仍在 Host 执行。
- “设备与校准”展开共享设备设置；快速校准、手动输入参考、自习座位表入口保留。联机校准 (Beta) 在主窗口连续进入连接验证、同期采样、复核结果，使用现有真实管理权限和参考接口。
- 口令验证成功后收起口令区；采样和保存仍由 Host 再次核对。Host 实例、权限来源或口令版本变化后，恢复输入并清除旧口令，不把 UI 验证标记当成权限。
- 离开联机校准页沿用参考控制器的关闭流程，只取消本页已确认拥有的草稿/采样版本。设备占用的 Host 硬时限与定时优先保护保留，不发送无会话归属的停止命令。
- USB 开始请求尚未回执时切页，先等待有界请求结束，再按 Accepted 回执确认的归属取消；拒绝或未确认的回执不能用于停止其他窗口的采样，不自动续采。隐去旧界面后可立即操作其他页面。
- 报告页读取本机最近的手动与学校结果，分开展示 dBFS 与估算 dB(A)。不声称上传成功；学校历史报告、照片、管理记录仍在学校后台查看。失败或旧请求回执不能替换当前页。
- 主导航可折叠为图标；窄窗口自动使用紧凑导航。录课、课堂模式、快捷启动等入口保留。主窗口密度适配继续负责嵌入页，不叠加独立对话框缩放。

## 实现边界

`WorkspacePanel` 承载现有窗口的内容与控制器，避免再弹出一个操作窗口。控制器的命名控件、命令、状态序号、管理验证、关闭取消路径保持共用；独立窗口入口仍可用于回归或其他既有调用。每个工作台仅保留一份手动与学校控制器；隐藏时暂停界面查询，Host 会话独立运行。校准控制器离页关闭，敏感输入在关闭时清除。

不得将原型的场景、日期、示例密码、加速采样或模拟成功状态接入正式业务。本轮不变更 Host 排程、传感器、摄像头、守护、数据库、学校设置及全屏显示策略。

## 隔离验证

构建 `tests/NPEduTools.Onboarding.UiTests` 后使用 `UiTests <输出目录> --study-workspace`。测试不启动生产 App 或 Host，使用随机私有 Named Pipe、隔离管理配置、模拟 HID 与参考麦克风；禁止正式采集。覆盖真实预约/取消、同页校准、权限拒绝、离页释放、紧凑操作可达性、报告失败和跨页覆盖。

`scripts/test-desktop-field-fixes.ps1` 包含此回归。另需执行 `--noise-status`、`--manual-study`、`--usb-reference`、`--study-devices`、`--desktop-window-bounds`、`--study-report` 与 `--study-display`。单客户端传输夹具同时应答噪音与手动会话状态，管理对话框反射参数与当前构造函数一致。

`--study-workspace-races` 使用持续合成监测、延迟 USB 受理/拒绝、未完成报告查询验证切页边界。返回手动和学校页先撤下旧执行状态、重新确认；离页或再次刷新报告会取消前一查询。界面状态作废不停止后台监测。测试还确认切页期间会话不变、合成帧统计继续增长，以及迟到拒绝不会误停另一窗口拥有的参考采样。

自动 WPF 渲染及模拟 200% 工作区只证明该层；真实一体机触控、USB、声学、学校账号和线上验收需另行进行。
