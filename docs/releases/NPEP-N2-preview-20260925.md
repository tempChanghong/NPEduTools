# NPEduTools NPEP N2 通知视觉更新（2026-09-25）

这是 Windows x64 试用构建。包名与本文件用于区分构建，主程序基础 InDev 版本号保持不变。

## 本次变化

- 次要通知仍为绿色置顶弹窗，不加遮罩、不主动激活窗口。
- 普通、重要、紧急通知增加约 62% 黑色的全屏遮罩，覆盖每个显示器及任务栏；点击或触摸背景只返回通知，不关闭通知。初始键盘焦点在正文，用户需要手动关闭。
- 入场 180 ms 淡入，正文区域向上平移 12 DIP；关闭时 120 ms 淡出。Windows 关闭客户端区域动画或启用高对比度时跳过动画。
- 增加四阶同色系硬边色块。没有连续渐变，装饰不叠在正文上；小窗口收起右侧大色块。
- 程序退出、通知关闭均释放遮罩。回执保存失败时保留窗口和遮罩，允许重试；撤回等导致通知失效后，用户关闭状态窗口时释放遮罩。
- 预览与真实通知不会同时打开两组遮罩。

## 使用

退出旧 NPEduTools（包括后台），将本包完整解压到新目录，运行 `Start-NPEduTools.cmd`。同一 Windows 用户可沿用已有学校互联配对。进入“设置 → 学校互联 → 学校通知”查看通知或试用四种样式。

N2 后端已于 2026-09-24 23:15 完成生产部署；网页新增回执界面尚未发布。本次视觉变化只在桌面端，不需要再次更新后端或重新配对。接收逻辑仍为约 10 秒 HTTP 轮询；网页设置关闭弹窗的次要通知只进入通知列表。

## 文件

- `Start-NPEduTools.cmd`：启动入口；`app/`：完整程序、后台及 .NET 运行时，无需另装 .NET，不要单独移动 EXE。
- `ClassIsland-plugin/` 和 `ExamAware2-plugin/`：其他功能使用的桥接插件；学校通知不依赖它们。
- `RELEASE-NOTES.md`：本说明；`README.md`：通用使用指南。
- `RECORDING-TOOLS-INSTALL.md` 和 `Install-Recording-Tools.ps1`：可选录制工具安装；不附带 FFmpeg。
- 源码归档、依赖清单和许可证：随包组件的构建与许可材料。

## 验证边界

在一台 2560×1600 开发机上使用主程序同样的 PerMonitorV2 DPI 配置验证四级样式、遮罩物理边界、背景拦截、手动关闭清理、回执保存失败、失效与退出清理，以及小窗长正文。

多显示器和显示器热插拔已有处理逻辑，但尚未进行实体多显示器/热插拔验收。遮罩是普通桌面窗口，不阻止 Windows 安全操作，不承诺覆盖独占全屏程序。试用包不含生产凭据，不会自动发通知或替换正在运行的程序。
