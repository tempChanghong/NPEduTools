# NPEduTools v1.1.6 · EVA-02（二号机）

v1.1.6 是一次学校互联与自习稳定性更新，代号保持 **EVA-02（二号机）**。重点解决学校连接停止重试、短暂失联使自习展示消失，以及课堂模式操作缺少结果反馈的问题。保留 v1.1.5 的工作台、快捷侧栏与全屏展示风格，兼容 **NPClassworks／NPClassworksKV v1.3.5 · Yamada（山田凉）**。

## 学校互联与持续自习

- **状态上报在真正取得网络队列后取样**。慢配置请求不再把尚未发送的样本拖成过期读数；本机样本过期、网关短暂故障及响应体中断按可恢复情况重试，保留学校配对。真正的撤销授权、身份失效和主动暂停仍按原规则处理。
- **短暂失联保留已经开始的本次定时自习**，继续展示、采集与统计，到原定结束时间结束；恢复连接不先清空本次安排、不重复启动麦克风，也不把已有会话拆成多次自习。慢作业、照片等辅助查询结束后重新核对状态，避免用旧快照反复收起展示。
- 这项持续运行仅适用于已核实且已开始的当前时段。不会在离线状态自行开启后续安排，也不在 Host 重启后凭缓存重新授予离线采集权限。主动暂停、解绑、授权撤回、模式和时间条件变化仍接受各自校验；照片权限另行核实，不能把噪音持续采集等同于持续拍照授权。
- **座位表传输可恢复有限的中断分段**，身份、修订、体积与完整性检查保持不变；本次会话失联期间保留已经下载并核实的自习座位表及当天作业。上传超时明确提示结果待核对，不自动重放不确定的覆盖操作。
- 学校安排页区分没有排程、正在同步、连接恢复和时间来源未确认，避免统一显示“待安排”。全屏自习及座位表页增加小型学校连接状态标识，不遮挡大时钟、作业和进度环。

## 模式、设备与校准

- 修复完整安装包中 Host 查找管理员辅助组件的路径，课堂模式切换增加与请求绑定的完成／失败反馈。核验失败的事项继续显示；未完成模式切换不再无反馈消失，也不会宣称已经完成。
- 修复麦克风与摄像头设置刷新后无法恢复的状态；设备清单限制总大小，同时保留实际选中的设备，按完整、新鲜的清单确认选择。学校设备回执规范化名称和大小，避免异常清单阻断状态同步。
- 校准查询独立于学校排程执行；读取校准摘要不会再运行调度或控制采集。仪表请求超时给出明确结果，不因一次超时断开整个 Host 管道。
- 在自习、噪音、设备及校准页面显示 **未校准、已快速校准、已参考校准、已联机校准（Beta）**等状态。保存的参考与当前设备实际可用的参考分别表达；失联、输入变化、校准上下文过期时撤回旧的“已应用”结论，恢复查询后才确认。
- 手动页读取迟到时撤回陈旧电平、趋势和校准标识，避免把旧数值当成实时数据。下一次自习准备阶段不会沿用上一会话的估算采集结束状态。

## 报告、照片与诊断

- 保留短暂配置丢失或采集替换前的终段统计；结束报告按本次会话汇总已收集的片段，避免只显示最后一段。真实采集缺口仍如实显示，不把失联时长补成有效数据。
- 照片补传遇到临时授权续约故障时保留仍允许上传的队列，读取队列恢复不抹去未解决的限频故障。退出验证与恢复警告在记录前核验当前会话，迟到结果不能套到新自习上。
- 新增有界、脱敏的本机学校连接历史，诊断导出保留过期样本等具体错误，并记录队列等待、请求耗时及恢复情况。记录不包含学校口令、访问凭据、完整请求正文或媒体。配套 KV 部署增加有界的错误／慢请求诊断，本次不新增数据库迁移。

## 保留的设置与边界

- 新配置默认 **北京时间 19:15–21:30**；已有自定义排程、阈值、学校身份与设备设置不被升级覆盖。
- 校准、USB 波动／复核门槛、录课宽限、照片策略与保护规则不因本次更新放宽。继续区分 **dBFS** 与 **估算 dB(A)**，估算双阈值新配置默认 **50／65**，管理员可修改。快速校准是相对电平参考，不能直接称为实际声压级；设备或输入设置变化后参考失效。
- **USB 联机校准（Beta）**与 **ClassIsland IPC 修复（Beta）**保留标识。源码和隔离反例验证可以证明修复路径，不能把未留存错误码的现场故障全部归结为同一个原因。

## 下载、安装与回退

普通用户下载 **`NPEduTools-v1.1.6-win-x64-setup.exe`**；便携部署下载 **`NPEduTools-v1.1.6-win-x64.zip`**。完整包包含 App、Host、独立 Guard、管理工具、摄像头组件、两处录课组件、FFmpeg／ffprobe、自包含 .NET 运行时、桥接插件及许可资料，不需要安装开发 SDK。

本版附件共 **13 项**：完整 EXE／ZIP、`NPEduTools.ClassIsland.Bridge.cipx`、`npedutools-examaware-bridge-0.4.0.ea2x`、本版说明、源码 ZIP、第三方源码与许可 ZIP、`SHA256SUMS.txt`，以及沿用上一版已发布字节的五项 ClassIsland IPC Beta 附件：

- `ClassIsland.IpcStabilityPatch.cipx`
- `ClassIsland-2.1.0.1-ipc-hotfix-Beta-win-x64.zip`
- `ClassIsland-IPC-Beta-INSTALL.md`
- `ClassIsland-IPC-Beta-sources-and-validation.zip`
- `ClassIsland-IPC-Beta-SHA256SUMS.txt`

独立桥接插件与本版完整包内文件一致；IPC Beta 文件属于独立的既有 ClassIsland 修复，不是本次重新构建的 NPEduTools。已安装且工作正常的 IPC 补丁无需重复安装，备用本体热修复只适用于所标明的 ClassIsland 版本，具体安装、验证与回退见附件说明。

1. 备份 `%LocalAppData%\NPEduTools` 和自选录课目录，保存并停止录制／监测，通过托盘停止后台并退出。
2. 使用完整安装包升级；安装器只维护本安装的独立守护，不按进程名称批量结束 Windows 服务。便携目录迁移按[守护维护说明](https://github.com/tempChanghong/NPEduTools/blob/v1.1.6/docs/GUARD-MAINTENANCE.md)操作。
3. 升级后核对关于页版本、学校连接、ClassIsland 时间、下一项安排、默认设备和校准状态。先检查模式切换反馈，再观察一次完整自习及结束报告；遇到连接故障先导出脱敏诊断，再手动重连。
4. 需要回退时停止当前任务与本安装守护，备份最新数据后使用上一版本完整包。升级／卸载不自动删除用户配置和录课文件；回退不等于回退学校服务或数据库，旧版本可能不识别新诊断字段。

## 验证范围

发布以本版源码的 CI 和精确三仓组合检查通过为前提；交付使用本次完整候选 `result.json` 验证 ZIP／安装器一致性、组件路径、隔离安装生命周期及合成媒体。附件按同次候选组装并核对 SHA-256，既有 IPC Beta 附件单独核对上一版公开摘要。

自动化检查不代表真实 2202 USB、麦克风／摄像头、声学、触控或一体机整晚运行已经验收。统计不用于班级评分或排名；不向服务器上传原音频，学校策略照片不向星火动力云端上传。
