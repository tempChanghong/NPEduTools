# NPEduTools v1.1.7 · EVA-02（二号机）

v1.1.7 是一次稳定性更新，代号保持 **EVA-02（二号机）**。重点处理覆盖安装时守护维护失败、自习统计和报告边界，以及多个入口连续操作录课时的回执错乱。保留 v1.1.6 的工作台、快捷侧栏、全屏自习展示和校准流程，兼容 **NPClassworks／NPClassworksKV v1.3.5 · Yamada（山田凉）**。

## 更新和卸载

- **修复默认 Host 任务参数校验**。Windows 任务计划程序保存空参数时可能省略 `Arguments` 节点；现在按等价空参数处理，避免合法登记被误判为参数错误、阻止完整安装器覆盖升级。
- 维护按实际通信实例核对常驻守护，同账户、同目录下的其他闲置实例不会在回滚时额外启动。任务归属、文件路径和必需参数仍须匹配，不按进程名称批量结束 Windows 服务。
- 修复维护与恢复中的中断边界：先保存恢复记录再创建维护标记，先保存恢复完成状态再解除标记；启动请求失败时保留事务，允许核对原事务后重试。文件完整性核验包含隐藏文件与隐藏目录。
- 已完成维护的本地收尾不再额外依赖任务计划程序服务。准备和恢复任务仍要求服务可用；身份、登记、写盘等真正失败不会被忽略。
- 失败诊断保留发生阶段及对应任务名。准备、恢复和完成分别写入结果，避免恢复后的 `OK` 覆盖最初失败原因；显式守护维护失败也返回非零退出码。

## 自习与噪音监测

- 排队上传自习座位表时也会返回超时结果，不再因等待上传队列而一直挂起。超时表示结果待核对，不自动重放可能覆盖远端图片的操作。
- 修复不同会话观察者互相重置超限持续时间的问题。手动自习退到后台或没有展示窗口时，仍按本次有效策略收集双阈值统计。
- 麦克风异常按实际采集设备归属记录，避免在设置已切换时，把旧设备故障记到新设备上。
- 学校时钟短暂失效时，保留此前已经收集的同一时段报告片段；恢复后仅在学校身份、规则、模式和时段仍匹配时继续汇总。时钟无效期间不借此新增采集，真实缺口继续反映在覆盖率中。
- 结束状态迟到时，在原有展示期限内提供报告，不重新延长报告展示时间。故障处理只读取既有执行状态，不因一次查询失败额外启动、接管或抢占采集。

## 日常录课操作

- 多个入口的录课修改操作统一按顺序提交，防止较早的延迟回执覆盖刚确认的“关闭自动录课”。状态查询与租约续期继续运行，不因等待回执而停止后台录制。
- 自动操作等待回执时，手动“暂停／停止”会等待前一项完成，不再静默忽略。重复点击仍合并；执行前核对原会话，课节已更换时给出提示，不误停新录制。
- 退出客户端会取消尚未发送的排队操作。回执丢失时显示状态未确认，通过后续查询核对结果，不自动重放不确定的修改。

## 保留的配置与数据边界

- 新配置默认自习时段仍为 **北京时间 19:15–21:30**。升级不覆盖已有自定义排程、设备、阈值、学校配对和校准数据。
- 继续区分 **dBFS** 与 **估算 dB(A)**。估算双阈值的新配置默认 **50／65**，管理员可修改；设备或输入设置变化后参考失效。**USB 联机校准（Beta）**保留标识。
- 本版不改变录课宽限、照片触发与保留策略，也不新增原音频上传、摄像头录像、班级评分或排名。
- 卸载不自动删除用户配置和自选录课目录。请在升级、回退或手动清理前自行备份。

- `v1.1.7.md`、`NPEduTools-v1.1.7-source.zip`、`NPEduTools-v1.1.7-third-party-sources.zip`、`SHA256SUMS.txt`。

ClassIsland IPC Beta 修复是独立的既有附件，本次未重新构建。已正常使用插件补丁的设备无需重复安装；备用本体热修复仅适用于注明的 ClassIsland 版本。安装、验证与回退以附件说明为准。

## 升级与回退

1. 备份 `%LocalAppData%\NPEduTools` 和自选录课目录，保存并停止当前录课／监测，通过托盘停止后台并退出。
2. 运行本版完整安装器覆盖升级。安装器维护失败时保留弹窗所示诊断目录，查看 `Prepare-result.txt`，不要把后续恢复的 `OK` 当作准备成功，也不要删除用户配置。
3. 必要的手工维护使用实际安装中的 **`app\Guard\svchost.exe`**。默认路径与完整操作见[守护维护说明](https://github.com/tempChanghong/NPEduTools/blob/v1.1.7/docs/GUARD-MAINTENANCE.md)。不要用另一目录的守护替代原实例，也不要按进程名批量结束系统进程。
4. 升级后确认关于页为 v1.1.7，核对学校互联、ClassIsland 时间、下一次自习、默认设备和校准状态，再观察一次完整任务与结束报告。
5. 回退前保存并停止任务，维护本安装守护，备份最新数据后使用上一版本完整包。应用回退不会回退学校服务或数据库。

## 验证范围

发版检查包含对应提交的 CI、三仓组合，以及精确候选 `result.json` 所指的 ZIP／安装器一致性、组件路径、隔离安装生命周期与合成媒体验证。独立插件、源码和附件摘要均按候选及既有公开附件核对。

本地整体复查通过了 1449 项底层测试及 183 项界面检查；另有侧栏前台焦点检查在当前测试环境中无法取得原生前台窗口，未计入本地通过数。CI 与打包通过也不能代替真实大屏触控、2202 USB、麦克风／摄像头、声学校准及整晚运行验收。本版不会据此承诺现场断线、覆盖安装或焦点问题已经全部消失。
