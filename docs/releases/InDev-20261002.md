# NPEduTools InDev 20261002

面向 Windows 教室大屏的学校互联预发布版本。基于 InDev 20260920，新增 NPEP 通知、完整考试／日常远程切换、ExamAware 方案投递，以及原生噪音监测、学校排程和统计报告。**本版为 Pre，无代号**；配套 NPClassworks 与 NPClassworksKV **v1.2.0 · Hitori（后藤一里）**。

> [!CAUTION]
> **InDev / Pre 开发预览版**
>
> 已完成隔离自动化测试及部分开发电脑联调，但真实班级大屏、学校排程、长期运行与重启／休眠恢复验收尚未完成，仍可能存在未发现的问题。请先在单台设备试用，保留手动切换与备用方案；完成现场验收前，不应依赖它承担正式考试或无人值守录课。欢迎通过 [GitHub Issues](https://github.com/tempChanghong/NPEduTools/issues) 反馈问题。

## 本版功能

### 学校互联与桌面通知

- **NPEP 学校配对**：与 NPClassworks／KV 建立设备连接，提供状态上报、暂停／恢复、撤销与断线重连。配对即授权当前提供的学校互联控制能力，管理页会明确提示这一含义。
- **独立通知窗口**：无需借助 ClassIsland 通知提供商。次要、普通、重要、紧急通知分别采用绿色、蓝色、黄色、红色背景与大字白色正文；置顶、手动关闭，普通及以上通知使用全屏变暗遮罩，配合轻量动画与并列色条。
- **投递与回执**：HTTP 轮询接收通知，收件和回执持久化，重启或暂时断线后继续处理待办。网页中的“弹窗提示”同时控制网页大屏与已连接的 NPEduTools；次要通知允许关闭弹窗，普通及以上仍须弹窗。
- 修复遮罩偶发盖住通知窗口、使正文也变暗的问题。

### 完整考试模式与 ExamAware 方案

- **网页切入考试、远程返回日常**：学校后台可对单台设备发起完整模式切换，联动当前软件运行、Windows 登录自启动设置及自动录课暂停。考试时准备 ExamAware2、正常退出 ClassIsland；返回日常时正常退出 ExamAware2、恢复 ClassIsland。录课计划保留。
- **核实、重试与部分完成说明**：操作中断或某一步受阻时保留执行证据，区分成功、失败及部分完成，支持后续核实和重试。历史成功回执不代表软件此刻仍在运行。
- **方案投递与放映**：接收方案、验证结构并显示摘要，再按明确的开始请求进入放映，读取结果；不把“桥接已连接”当成“方案已放映”。ExamAware 桥接升级至 **0.4.0**，适配正式版 **1.5.2**。
- **权限与启动检查**：启动时立即请求管理员权限；本机检查核对程序路径、桥接、ClassIsland 管理员登录任务、录制及运行条件，避免把无效配置报告为就绪。

### 原生噪音监测与学校排程

- **桌面采样、网页控制**：NPEduTools 使用本机已保存的麦克风，显示实时 dBFS、最近一分钟曲线及采样质量；班级大屏网页负责开始／停止、查看状态与报告。原生接管后，网页停用重复采集和旧网页定时监测，失联时不自动退回网页采集。
- **仅上传统计**：报告包含有效采样时长、覆盖率、能量平均、峰值、削波比例及设备／算法来源。不保存或上传原始录音；断线后待上传报告可补传，并按会话去重。
- **每周学校排程**：支持年级规则、班级继承／覆盖／停用、预览与修订。桌面使用 **ClassIsland 学校时间**，不以系统时间替代。需要有效配对、已保存麦克风及已确认政策。
- **手动操作与考试的衔接**：手动监测最多三小时；手动停止自动会话会跳过本次时段，可明确恢复。考试期间暂停自动监测，排程不会把正在运行的手动会话认作自己的会话。
- **离线规则与报告来源**：当前 Host 可继续使用尚未过期的已确认规则租期，最长 24 小时；重启后需重新在线确认。报告关联具体会话和排程，无法核对来源时显示未知。

### 开发与可靠性

- Windows 原生 PostgreSQL 与前后端统一启动流程；跨端验收入口兼容 Windows PowerShell 5.1，并补充契约、数据库及浏览器检查。
- 学校地址允许 HTTP；HTTPS 仍严格验证证书，TLS 失败持续重试，不通过跳过验证来连接。
- 保留原有侧边栏、管理窗口、独立录制、自动录课、PowerPoint 触摸翻页等功能。录制仍需单独安装 FFmpeg／ffprobe。

## 开始使用与升级

1. 建议先升级 **NPClassworksKV v1.2.0**，应用完整 Prisma 迁移链，再升级 **NPClassworks v1.2.0**。保留数据库备份与既有 NPEP 身份，不重复首次激活。
2. 便携 ZIP 完整解压到固定目录，保留 `app` 及各子目录，运行 `Start-NPEduTools.cmd`；内含 .NET 运行时，无需安装开发 SDK。启动时核实并允许 Windows UAC。开发者也可按 `global.json` 安装 **.NET SDK 10.0.400**（允许同系列最新补丁），在 Visual Studio 打开 `NPEduTools.sln` 并运行 `NPEduTools.App`。本次发行构建使用 SDK **10.0.401**；应用版本为 `0.1.0-indev.20261002`，显示版本为 `InDev 20261002`。
3. 检查 ClassIsland、ExamAware 的实际程序路径与配套插件。使用考试模式前，在 NPEduTools 中创建并核实当前 ClassIsland 程序的管理员登录自启动任务；远程操作不会擅自新建或覆盖未知任务。
4. 升级 ExamAware 桥接至 0.4.0，再核对连接与考试方案流程。ClassIsland 时间桥接保持 0.2.0.0；当前已适配 API 2.1.0.1。
5. 保存所需麦克风，完成学校配对。已有学校排程可能在满足条件后开始执行，上线前核对年级继承、班级范围和时段，先试一台设备。
6. 需要微课录制时单独安装 FFmpeg／ffprobe，见[录制工具安装](https://github.com/tempChanghong/NPEduTools/blob/codex/release-indev-20261002/docs/RECORDING-TOOLS-INSTALL.md)。不要把它们当作本版附带组件。

## 已知限制

- **ExamAware 编辑器退出问题暂未修复**：切换前先保存并关闭编辑器；返回日常前正常结束放映。遇到阻碍会提示并保留重试，不强行结束未保存窗口。
- 噪音读数是 **dBFS 信号电平**，不是校准声压级；不与旧网页评分混用，也不用于班级排名。没有原音频上传、摄像头捕获或跨班批量考试控制。
- ClassIsland 学校时间失效时，自动排程等待／停止，不改用系统时间。服务器停用或撤销无法立即通知离线设备；需要立刻停止时请在本机操作。
- 真实班级大屏的驱动、DPI、多屏、长时间采样／录制、Windows 重启与休眠恢复等仍待现场补测。本版未进行 Authenticode 签名。
- HTTP 连接为明文，适合可信测试网络；使用 HTTPS 时仍须配置有效证书。
