# NPEduTools InDev 20260920

面向 Windows 教室大屏的开发预览版，提供桌面侧边栏、课堂工具管理、微课录制和日常／考试模式切换。本版本用于试用与反馈，尚未完成目标大屏的整课稳定性验收。

> [!CAUTION]
> **InDev 开发预览版 · 请先验证，再用于日常教学**
>
> 本版本仍处于开发阶段，已完成部分开发机测试，但不同教室大屏、音频设备和软件组合的兼容性尚未全面验证，可能存在未知问题、录制中断或联动失败。
>
> **请勿未经现场验证，就将本版本用于正式考试切换、无人值守录课或不可补录的重要课程。** 建议先在非授课时段试用，备份配置和考试资料，完成短录回放与模式切换检查，并保留手动操作及备用录制方案。
>
> 欢迎通过 [GitHub Issues](https://github.com/tempChanghong/NPEduTools/issues) 反馈问题。请附上版本、复现步骤和脱敏后的错误信息，帮助我们完善稳定性。

## 本版功能

- **侧边栏与管理窗口**：侧边栏提供常用操作，主窗口集中展示状态；支持应用、文件和网址快捷入口，以及首次配置向导。
- **更清晰的主页与设置**：优先显示课堂模式、连接和录制状态；设置分为常规、课堂工具、软件连接。输入框、展开区域、录课标签页和下拉框统一外观。
- **日常／考试模式**：联动 ClassIsland 管理员登录任务与 ExamAware2 登录自启动；考试期间暂停自动录课并保留计划。可选“同时切换当前运行的软件”，默认关闭；失败后提供显式重试和恢复入口。
- **独立微课录制**：支持屏幕、系统声音和麦克风，提供 8／15 fps、720p／1080p 上限、暂停继续和本地 MP4 保存。
- **自动录课计划**：支持每周周期规则、指定日期安排及固定时段；默认排除 17 项非录制科目。按 ClassIsland 学校时间执行，支持预演和执行记录。
- **PowerPoint 触摸辅助**：提供触摸推进、暂停和兼容选项，保留鼠标原有操作方式。

## 下载与开始使用

**普通用户先下载 `NPEduTools-InDev-20260920-win-x64.zip`。** 解压后即可运行，已包含两个桥接插件；**需要录课时，须另外安装 FFmpeg 录制组件**。程序包不附带 FFmpeg，其他附件按需下载。

| 附件文件名 | 作用与适用人群 |
| --- | --- |
| **`NPEduTools-InDev-20260920-win-x64.zip`** | **Windows x64 程序包，首次使用下载此项。** 包含主程序、后台、录制器、所需 .NET 运行时、两个桥接插件及源码和许可材料；FFmpeg 须按包内说明另装。 |
| `NPEduTools.ClassIsland.Bridge.cipx` | ClassIsland 时间与课表桥接插件 0.2.0.0，使 NPEduTools 能读取学校时间和日程。通过 **ClassIsland 的插件管理功能**安装；完整程序包内已有同一文件，单独列出便于安装或更新插件。 |
| `npedutools-examaware-bridge-0.3.0.ea2x` | ExamAware2 桥接插件 0.3.0，用于状态查询、正常退出及登录自启动联动。通过 **ExamAware2 的本地插件安装功能**导入，启用后完成配对；完整程序包内也已包含。 |
| `NPEduTools-InDev-20260920-source.zip` | 本版程序构建时的项目源码快照，供开发、研究和构建追溯使用。**不是可直接运行的程序包，普通用户无需下载。** |
| `NPEduTools-InDev-20260920-third-party-sources.zip` | ClassIsland 契约库及 ExamAware SDK 关联版本的上游源码、构建文件和哈希清单，供开发与许可核对；程序包内已有相同材料，不是安装程序，也不含 FFmpeg。 |
| `InDev-20260920.md` | 本页发版说明的 Markdown 文件，便于离线阅读或留存，不是安装程序。 |
| `SHA256SUMS.txt` | 以上六个附件的 SHA-256 校验值，用于核对下载文件是否完整；无需安装或运行，也不代替数字签名。 |

两个插件均不包含 ClassIsland 或 ExamAware2 本体，也不需要把所有附件逐个下载安装。仅使用快捷启动、PPT 触摸辅助或手动录课时，不必为此安装两个桥接。

将完整程序包解压到固定目录，运行 `Start-NPEduTools.cmd` 或 `app/NPEduTools.App.exe`。保留所有子目录，不要直接在压缩软件中运行。包内置 NPEduTools 所需的 .NET 运行时，无需安装开发 SDK。

**首次录课前**，关闭 NPEduTools，在解压目录按 `RECORDING-TOOLS-INSTALL.md` 运行 `powershell.exe -NoProfile -File .\Install-Recording-Tools.ps1`。脚本直接从 Gyan 上游下载固定的 FFmpeg 9.0.1，校验 ZIP 和可执行文件后安装；无需管理员权限，不改系统 PATH。也支持离线 ZIP 或按文档手动安装。未安装时快捷启动、PPT 辅助与模式管理仍可使用，手动及自动录课暂不可用；启动程序不会自行下载组件。

需要课程时间与自动录课时，在 ClassIsland 中安装 `ClassIsland-plugin/` 下的 `.cipx`；需要考试软件联动时，在 ExamAware2 中安装 `ExamAware2-plugin/` 下的 `.ea2x`，再按说明完成配对。两款软件本体不随包提供。

| 组件 | 本版适配范围 |
| --- | --- |
| NPEduTools | InDev 20260920，Windows x64 |
| ClassIsland | 2.1.0.1 本地构建已验证；时间与课表桥接 0.2.0.0 |
| ExamAware2 | 1.5.2 本地打包程序已验证；桥接 0.3.0，官方 Plugin API V2 |

首次使用请核对学校时间、屏幕、音源、保存目录与录课计划，先短录并回放，再启用自动录制。保存计划、完成向导和启动软件均不会自动开启录制。

## 已知限制

1. **切回日常模式或请求退出 ExamAware2 前，请先保存并关闭考试编辑器、结束放映。** ExamAware2 1.5.2 编辑器仍打开时，官方退出可能提前卸载接口，造成编辑器无法保存且桥接断开。此问题已记录，本版暂不修复；NPEduTools 不会以强制结束进程代替正常退出，也不能保证该故障发生后能够保存内容。
2. **自动录制在重启后默认关闭**，需要重新核对并手动启用。课程录制窗口默认按学校课表的上课前 2 分钟至下课后最多 5 分钟计算，尚未直接订阅自定义“二分钟铃”。固定时段采用用户填写的起止时间。
3. ClassIsland 时间断开或过期时不启动新自动任务，不回退到系统时间；已开始任务按既定截止规则收尾。
4. i7-1065G7 核显大屏整课、连续多节、真实双音源、物理休眠、多屏 DPI 与触摸，以及实际注销／登录启动尚待现场验收。开发机结果不代表这些项目已通过。
5. 当前包未做 Authenticode 签名。校验文件用于检查下载完整性，不是发布者身份签名。

## 更新与回退

先停用自动录制，保存当前录制并完整退出 NPEduTools；备份 `%LocalAppData%\NPEduTools`、视频及异常片段。将新版本解压到新目录，保留旧版，重新核对程序路径和登录启动登记。配套插件应一起更新；ExamAware 桥接 0.1.x 用户需重新配对。

回退前另存新版本生成的数据；不要通过删除执行账本来补录，避免重复采集。详细步骤见包内 `README.md`。
