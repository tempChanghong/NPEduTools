# 下一版本候选：Windows 安装包

公开版本号待定。本文件用于本地候选构建，不能作为已经公开发版的证明。

新增 Windows x64 安装 EXE，保留 ZIP。安装版提供固定安装位置、开始菜单入口和可选桌面快捷方式，配置使用现有 OOBE；检测到 NPEduTools 或录制组件仍在运行时，会提示先保存并完整退出。

升级保留账户设置、录课计划和学校配对；卸载保留用户数据与视频。卸载前先关闭 NPEduTools 登录启动。ClassIsland／ExamAware2 仍单独安装，桥接插件由它们的插件管理功能导入。安装不会自动创建管理员任务或开机启动登记。

候选包内置自行构建的 FFmpeg／ffprobe，并附源码、构建材料和许可证；详情见包内 `FFMPEG-BUNDLED-BUILD.md` 与 `third-party/ffmpeg/`。已发布 InDev 20261002 包仍按其原说明处理。

安装程序与应用启动均按需请求管理员权限。当前未签名；安装包测试已覆盖隔离环境的升级、卸载和文件保留，真实完整包及教室大屏验收仍待完成。请先在测试设备使用并备份配置。

具体操作和限制见包内 `INSTALLER.md`。发版时还需合并本轮其他修改、明确公开版本号、填写真实验收结果并提供下载文件与校验清单。

维护者新增统一交付验收入口 `scripts/test-desktop-delivery.ps1`，可核对 ZIP、安装器和载荷的一致性，并关联隔离安装／升级／卸载及内置录制组件报告。当前候选已包含定时监测守护组件；它的真实关机、休眠与教室验收仍需单独完成。
