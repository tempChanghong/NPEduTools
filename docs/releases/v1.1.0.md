# NPEduTools v1.1.0 · EVA-02（二号机）

## 版本概述

**v1.1.0，代号 EVA-02（二号机）**，是基于 v1.0.0 的自习功能更新。配套 **NPClassworks／NPClassworksKV v1.3.0 · Yamada（山田凉）**。

自习展示和麦克风采集现在由 NPEduTools 原生端承担，学校后台统一配置班级安排、作业来源、设备和照片策略。录课、通知、点名、课堂工具及考试联动继续保留。本版新增的 DLY-2202 联机校准标为 **Beta**；隔离自动化通过不代表真实仪表与教室验收完成。

## 新增功能

### 原生全屏自习展示

- 新增 WPF 全屏自习页面：大时钟、阶段提示、噪音状态与实时趋势、今日作业，以及围绕“本次自习”卡片的进度环。已知结束时间时显示进度；未设置结束时间的手动自习显示已进行时间和三小时上限。
- 定时自习提前 **5 分钟**打开页面并展示本班自习座位表；开始前 **2 分钟**显示 **10 秒**“准备自习”，开始后 **2 分钟**自动收起座位表。准备展示不提前授予麦克风采集或阈值拍照权限。
- 开始提示为红色、结束提示为绿色，均持续 **5 秒**；“注意纪律”使用更深的红色。四种阶段／纪律提示配有提示音，中阈值边缘扩散效果不播音。
- 学校选择展示的行政班作业及适用走班来源，隐藏无作业科目并去重。长作业按内容分页，轮换默认 **60 秒**，后台可调整；更新等待当前页读完，不突然替换阅读内容。
- 自习结束提示后显示本次报告：时段、趋势、均值／峰值、双阈值超限时长、有效采集覆盖率、提醒次数及数据单位。默认 **5 分钟**后退出报告；照片与退出验证记录不向全班展示。

### 学校定时安排与手动自习

- 学校可以独立设置日常、考试模式的自习安排，也可让某个模式不执行定时自习。新配置的默认时段为 **北京时间 19:00–21:30**；保留明确自定义安排。年级继承、班级覆盖／关闭、星期、生效日期和日历例外由学校配置，不把某一学校的开学日期作为所有部署的规则。
- 日常定时自习使用 **ClassIsland 学校时间**；考试模式明确使用 **Windows 时间**，后台和报告标明来源。日常学校时间失效时，不默默改用 Windows 时间继续采集。
- 手动自习可选择开始和结束日期／时间：不填开始时间则立即开始；不填结束时间则主动结束，实际会话最长 **3 小时**。预约开始默认提前 **2 分钟**打开展示，此值可在本机设置调整，到点才采集。
- 手动展示隐藏座位表按钮，左下角保留长按“结束自习”，允许提前结束已有结束时间的会话。临时收起默认 **10 分钟**后返回，也可选择不自动返回；收起不停止后台采集及已获学校策略许可的拍照。
- 手动与定时共享设备和校准，但不能同时采集。学校定时优先，接管时结束手动会话并保存报告，不自动续开；旧手动窗口不能误停新的定时会话。
- ExamAware2 **考试放映器优先**：自习继续后台采集及按策略拍照，暂停自习页面与提示音，过期提示不补播；放映结束后再核对是否需要显示自习页面。

### 双阈值、设备准备与校准

- 学校设置高、中两条阈值线。中阈值显示边缘扩散，高阈值增强视觉效果；连续超限默认 **3 秒**后才满足高阈值触发条件。“注意纪律”默认 **10 分钟**内至多提醒一次，与照片的限频分别处理。
- 初始设置与设备页可选择固定麦克风、摄像头；枚举和保存不会自动开启采集。学校后台接收设备列表，可远程选择并锁定；本机通过学校管理验证解锁后，保持解锁，直到管理员再次锁定。所选设备失联不会自动换用另一台。
- **快速校准**支持管理员选择现场场景采样、检查质量并确认双阈值，无需要求全班配合制造绝对安静。它帮助设置相对信号阈值，不把场景录入当成声压级标定。
- **参考校准**使用外部 A 加权声级计的稳定参考，与本机麦克风统计计算偏移，再以另一电平复核。结果通过确认后用于正式监测、双阈值和报告；设备、输入增益或相关输入设置变化后失效，不能自动沿用未经复核的参考。
- **联机校准（Beta）**面向 DLY-2202：连续读取仪表、与麦克风同期采样、自动计算偏移并复核，处理陈旧读数、断线和输入设置变化。USB 无实物验证已覆盖协议解析与失败路径；真实设备枚举、驱动、读数时序及声学一致性仍待实测。
- 未参考校准时使用 **dBFS**；有效参考下显示 **估算 dB(A)**，报告保留参考来源与原始数字电平。估算值不等于计量级声压级，不与旧网页评分混用，也不用于班级排名。

### 自习座位表、照片与退出记录

- 自习座位表支持学校远程下发，也支持已绑定大屏在设置页或定时展示中上传、替换本班图片，无需额外口令。双方更新按版本检查，冲突时保留草稿并重新确认，不覆盖更新后的远端图片。座位表不参与作业轮换；除定时准备阶段外，仅通过按钮查看。
- 摄像头默认不持续开启。学校另行启用照片策略后，高阈值连续超限、定时退出意图和异常恢复等事件按条件捕获单张 JPEG；共用默认 **30 秒**最小间隔，限制图片尺寸和体积。注意纪律提示不宣称“已拍照”。
- 照片传至学校的 **NPClassworksKV**，默认保留 **30 天**，最长 **180 天**；延长保留需确认风险。仅同校 **OWNER 与第二管理员**可查看，不生成公开图片链接，不上传原始音频或视频片段，不向星火动力云端上传捕获画面。
- 定时阶段点击“停止后台并退出”时先检查拍照条件，再验证管理员身份。一次密码错误或默认 **30 秒**验证超时后，显示 **30 秒**红底白字、不发光的全屏警告，然后返回自习；文字按实际上传及记录状态呈现，不把待上传说成已完成。
- 离线照片与报告保留补传状态，并检查班级、会话、策略和有效期限。过期或授权失效的数据不因重连自动越权上传。服务端到期清理与备份副本的保留期限是不同边界，学校需另行确认备份策略。

### 学校管理与独立守护

- 学校互联支持“大屏填服务地址发起申请，管理员同意并设置口令”，以及“学校预授权并设置口令，大屏填服务地址和口令连接”；保留旧配对兼容入口。NPEP 接管后使用学校班级管理口令，旧本机口令不作为学校管理验证的回退。
- Guard 通过 Windows 任务计划程序独立运行。非定时阶段退出主程序时继续待命；定时准备前唤醒，异常退出后重新核验有效安排、授权、时间及设备，再恢复采集和展示。
- 定时异常恢复新增独立事件，恢复后检查拍照并显示警告，去重且遵守共同限频；通过验证正常退出则跳过本次时段，下一次准备前再启动。手动会话不自动续开，也不套用定时红色警告。
- 常驻侧边栏新增快捷收窄；进入自习展示或考试放映器时完全隐藏，退出后恢复原状态。桥接操作不再挤占 ExamAware2 的主要入口，补齐断开图标并统一设置、日期、口令和设备选择控件样式。

## Bug 修复与稳定性

- 改善 Host 管道访问被拒绝、无效响应和晚到回执的恢复；通知、录课、点名、学校连接及考试状态不再把历史成功当作当前已完成。
- 修复录课指定日期编辑、删除失败后草稿身份、过时预测与清理超时等边界，保留当前设置及未提交内容。
- 修复座位表切班后的旧预览操作、校准失效写盘失败、采样尾段丢失、陈旧电平、报告时钟变化、损坏设备配置和 USB 取消／枚举错误等问题。
- 更新三份服务与隐私协议，并重新确认新增的学校口令、设备管理、照片及退出记录用途；GPL v3 与第三方许可继续独立展示。

## 安装与升级

1. 先备份数据库、NPEP 身份目录和本机 `%LocalAppData%\NPEduTools`、录课及相关配置。升级服务端时应用 **KV v1.3.0 完整迁移链**，核对 `/ready`，再更新网页 v1.3.0 和桌面 v1.1.0；保留现有配对与自定义排程。
2. 更新、换目录或卸载前，正常停止录制／监测并退出 App／Host，随后由维护人员按 [守护维护说明](https://github.com/tempChanghong/NPEduTools/blob/162e2e23d269afea0b25d941683f37b738b1e2c6/docs/GUARD-MAINTENANCE.md)停止本实例的待命守护并撤销任务。普通“停止后台并退出”不会结束守护。
3. 本版守护位于应用目录 **`Guard\svchost.exe`**，文件描述为“Windows 服务主进程”，产品仍为 NPEduTools；它不是 Microsoft 系统服务。维护时核对完整路径和所属任务，**不要按名称批量结束 Windows 的 svchost.exe**。
4. 使用完整发行包，保留 App、Host、Guard、运行时与录课组件；只复制或改名一个 EXE 不能升级。ClassIsland、ExamAware2、SecRandom 本体仍单独准备；桥接插件按本次完整包更新。
5. 在单台大屏核对学校口令、日常／考试时段与时间来源、设备锁定、双阈值、参考有效性、照片访问与上传状态，再扩大范围。新默认时间不覆盖用户明确的旧安排，照片不会仅因更新而自动启用。

## 测试与已知限制

- 已合并 PR [#14](https://github.com/tempChanghong/NPEduTools/pull/14) 的必要 CI 通过，包括 Windows、安装器及固定三仓验收。本地原生测试 **1496 项**、学校互联测试 **295 项**通过，WPF、HTTP 验收及 Probe 构建通过。
- 三仓联合验证包括原生 PostgreSQL 的 HTTP／SQL／备份恢复 **47 项通过、0 跳过**、网页浏览器回归 **183 项通过**，以及隔离的真实网页／KV 配对全栈检查。合成输入不代表真实麦克风、摄像头或仪表已经验收。
- **DLY-2202 实物 USB、目标教室一体机、声学校准、学校时钟、任务管理器终止后的实际恢复与长期运行尚待现场验收。** 联机校准继续标为 Beta；守护不是 Windows kiosk，也不能保证阻止可提权管理员同时停止组件或删除任务。
- 守护缓存用于唤醒，不授予离线采集许可；长时间退出、缓存耗尽或配置发生变化后需重新核验。服务器撤销或改排程无法立即告知离线设备。
- 发布文档与 Release 草稿不代表安装附件已经制作、线上已部署或所有班级已升级。安装包与应用的签名、附件及哈希以最终审核的发行资产为准。
