# NPEduTools v1.1.8 · EVA-02（二号机）

v1.1.8 改善自动录课安排与交接，并继续修复自习、校准和日常入口的异常状态。代号保持 **EVA-02（二号机）**，保留现有工作台、快捷侧栏和全屏自习展示。

## 自动录课

- **课前、课后余量设置前置，范围放宽到 0–10 分钟**，可在本机录课工作区调整。已有安排按保存值继续使用。
- **重叠时优先保证下一节录制**。计划预览和后台执行采用相同边界，明确显示哪一段被缩短或跳过；正式开始时间相同而无法区分先后的冲突仍需调整，不同时启动两份录制。
- 上一段已经结束但录制组件仍在清理时，下一节等待交接，避免被永久误记为“占用而跳过”。收尾耗时计入剩余课时，不因此延长课程。
- 排程重新配置、课节结束时间修改后，按原任务身份处理正在结束的录制，避免旧记录抑制相邻课程，或将最终保存结果遗留为“录制中”。
- 设备重新检测期间锁定相关编辑，保留暂时断开的麦克风／扬声器选择，直到用户明确重选；不会因刷新列表而悄悄切换录制设备。

## 自习与设备

- 修复手动自习双触点操作：按住“临时使用电脑”时，另一触点不能将已累计的长按时间用于“结束自习”。正常提前结束仍需重新长按两秒。
- 手动日期和时间超出可表示范围时显示校验提示，避免页面异常退出；保留立即开始、可选结束时间及最长三小时规则。
- 自习座位表选择损坏或不完整图片时给出错误提示；原图与上传确认流程保留。
- 修复结束报告时长四舍五入的分钟进位、异常恢复次数说明和管理口令来源提示。
- 设备配置文件损坏后，在移除损坏配置并刷新时允许恢复；读取或保存失败不会冒充设备已经配置成功。

## 校准、连接与日常操作

- **USB 联机校准（Beta）**及快速／参考校准处理 Host 超时、协议异常和不完整状态回执，保留重试入口，旧信息不能作为可保存的确认状态。
- 管理口令来源、版本或 Host 实例变化后，旧验证上下文失效。草稿替换、考试桥接等确认操作绑定当时的配置版本，防止确认期间刷新后误操作新的配置。
- 管理员组件收到无法核实的回执时停止本次操作并提示，不自动重放可能已经执行的修改。
- 学校互联诊断可以记录不兼容或无效的后台回复，不因诊断本身再次失败而丢失说明。
- 修复损坏的界面密度偏好导致入口不可用，以及高缩放下通知窗口居中坐标的问题。首次配置如未能保存 SecRandom 设置，会保留失败提示，不将它标记为完成。
- 保持自习与考试放映的提示优先级，防止一次状态读取提前消耗待处理的通知。

## 配置与数据

- 新配置默认自习时段保持 **北京时间 19:15–21:30**；升级不覆盖自定义排程、设备、学校配对、阈值或校准数据。
- 继续区分 **dBFS** 与 **估算 dB(A)**。估算双阈值的新配置默认 **50／65**，管理员可调整；设备或输入设置变化后的参考失效规则保留。
- 录课中断宽限、照片触发与保留策略沿用既有配置。卸载不自动删除用户配置和自选录课目录。

## 下载附件

普通用户下载 **`NPEduTools-v1.1.8-win-x64-setup.exe`**；便携部署下载 **`NPEduTools-v1.1.8-win-x64.zip`**。完整包包含 App、Host、独立 Guard、管理员辅助组件、摄像头组件、两处录课组件、FFmpeg／ffprobe、自包含 .NET 运行时及桥接插件，无需安装开发 SDK。

本版提供 **13 项附件**：

- 完整安装器与便携 ZIP。
- `NPEduTools.ClassIsland.Bridge.cipx`、`npedutools-examaware-bridge-0.4.0.ea2x`，从本版精确候选包提取。
- `v1.1.8.md`、`NPEduTools-v1.1.8-source.zip`、`NPEduTools-v1.1.8-third-party-sources.zip`、`SHA256SUMS.txt`。
- 沿用 v1.1.7 已发布字节的五项 ClassIsland IPC Beta 附件：`ClassIsland.IpcStabilityPatch.cipx`、`ClassIsland-2.1.0.1-ipc-hotfix-Beta-win-x64.zip`、`ClassIsland-IPC-Beta-INSTALL.md`、`ClassIsland-IPC-Beta-sources-and-validation.zip`、`ClassIsland-IPC-Beta-SHA256SUMS.txt`。

ClassIsland IPC Beta 附件本次未重新构建。已正常使用插件补丁的设备无需重复安装；备用本体热修复仅适用于附件说明注明的版本。安装、验证及回退步骤见 `ClassIsland-IPC-Beta-INSTALL.md`。本版总摘要覆盖除 `SHA256SUMS.txt` 自身外的全部 12 项附件。

## 升级与回退

1. 备份 `%LocalAppData%\NPEduTools` 及录课目录，保存并停止任务，通过托盘停止后台并退出，然后运行完整安装器覆盖升级。
2. 若安装器无法完成守护维护，保留提示中的诊断目录及 `Prepare-result.txt`，按[守护维护说明](https://github.com/tempChanghong/NPEduTools/blob/v1.1.8/docs/GUARD-MAINTENANCE.md)处理。默认安装中的守护位于 `C:\Program Files\NPEduTools\app\Guard\svchost.exe`；只维护本安装的实例。
3. 升级后核对关于页 **v1.1.8 · EVA-02（二号机）**、学校连接、ClassIsland 时间、下一次自习、默认设备与校准状态，并观察一次完整任务及报告。
4. 回退前先保存任务、备份最新数据并完成本安装维护，再使用旧版完整包。应用回退不会回退学校服务或数据库。

## 验证范围

发布以对应提交的 CI 与三仓组合检查通过为前提，并核对精确候选 `result.json` 所指的 ZIP、安装器、组件路径、隔离安装生命周期及合成媒体验证。独立插件与源码须和候选包一致，全部上传附件核对大小与 SHA-256。
