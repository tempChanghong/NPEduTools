# NPEduTools v1.1.2 · EVA-02（二号机）

v1.1.2 是一次稳定性更新，代号仍为 **EVA-02（二号机）**。保留现有功能及仿 ExamAware2 的全屏自习展示风格，重点改善一体机高 DPI 布局、自习监测与联机校准的操作恢复，以及更新和卸载流程。

## 修复与改进

- **窗口适配**：普通设置、校准和工具窗口按实际显示工作区限制尺寸，支持 2K 屏幕、200% 缩放、多显示器及窗口位置恢复；改善标题栏的最小化、最大化和关闭按钮超出可用区域的问题。内容超出时可滚动查看，全屏自习展示保持原有风格。
- **自习管理更清楚**：当前阶段、下一次安排、实际采集状态和常用操作优先展示；共享麦克风与摄像头设置收到可展开区域。考试放映优先时说明自习展示暂缓，不把展示状态当作正在采集。
- **临时使用电脑**：定时自习和手动自习按连续无操作时长返回，默认十分钟；新的键盘、鼠标或触控操作会重新计算等待时间。收起展示不会停止后台监测或按策略拍照；手动自习仍可选择不自动返回。
- **USB 联机校准（Beta）**：提供现场校准与严格校准选择，以“准备 → 采样 → 结果”组织操作，将专业参数收到高级设置。现场校准放宽同段电平波动要求，允许两段环境噪声自动采样、计算偏移和独立复核；复核差不超过 3 dB 可确认保存，3–5 dB 必须明确确认警告，超过 5 dB 拒绝保存。这是偏移的一致性复核，不要求教室始终安静。严格校准保留不同电平的复核要求。
- **校准与设备恢复**：USB 断线、陈旧读数、输入设置变化或后台重启时，不沿用旧状态自动续采或保存；丢失的采样草稿可返回准备步骤重新操作。设备保存和解锁超时有明确反馈，取消未确认操作后必须刷新，晚到回执不能覆盖新的选择。
- **自习报告保存**：修复本机报告新增校准说明字段被误带入既有互联协议、导致定时自习统计包校验失败的问题。本机说明继续保留，KV 统计使用协议定义的字段；dBFS 与估算 dB(A) 继续分别记录。
- **安装与卸载**：安装器自动核对并维护本安装的独立守护，升级或卸载不再要求普通用户手工结束守护。维护按完整路径、任务身份、账户和管道识别，不按 `svchost.exe` 文件名批量结束进程；取消或失败时按事务记录恢复。旧安装缺少守护文件时仍可由安装器携带的维护助手处理。
- **默认自习时间**：新建学校自习排程默认 **北京时间 19:15–21:30**；既有 19:00 或其他自定义安排保留，不自动覆盖。日期、星期、适用班级与节假日仍由学校配置。

配套 NPClassworks／NPClassworksKV 保持 **v1.3.0 · Yamada（山田凉）**，本轮仅部署更新，不创建新版 Release。学校后台把双阈值、连续超限时长和提醒间隔等参数收到默认收起的高级设置；仅查看旧配置的考试模式不会产生未保存修改，已有排程和阈值继续保留。

## 下载与升级

普通用户下载 **`NPEduTools-v1.1.2-win-x64-setup.exe`**；需要便携部署时下载 **`NPEduTools-v1.1.2-win-x64.zip`**。完整包包含 App、Host、Guard、管理工具、摄像头组件、两处录课组件、FFmpeg／ffprobe、自包含 .NET 运行时、桥接插件、源码和许可，不需要另装开发 SDK。

核心附件：安装 EXE、完整 ZIP、`NPEduTools.ClassIsland.Bridge.cipx`、`npedutools-examaware-bridge-0.4.0.ea2x`、本版说明、NPEduTools 源码 ZIP、第三方源码与许可 ZIP，以及覆盖全部附件的 `SHA256SUMS.txt`。单独提供的桥接插件与完整包内对应文件一致。

同时保留上一版的五项 **ClassIsland IPC Beta** 附件：

- `ClassIsland.IpcStabilityPatch.cipx`：优先使用的独立 IPC 修复插件。
- `ClassIsland-2.1.0.1-ipc-hotfix-Beta-win-x64.zip`：插件方案不可用时的备用本体热修复。
- `ClassIsland-IPC-Beta-INSTALL.md`：安装、验证和回退步骤。
- `ClassIsland-IPC-Beta-sources-and-validation.zip`：对应源码与隔离验证资料。
- `ClassIsland-IPC-Beta-SHA256SUMS.txt`：这组独立 Beta 附件的原始校验值。

这组 Beta 工件沿用 v1.1.1 已发布文件，不属于本次重新构建的 NPEduTools。时间桥接插件与 IPC 修复插件作用不同；已经安装且工作正常时无需因为升级 NPEduTools 再装一次。热修复仅针对所标明的 ClassIsland 版本，按附件说明核对，避免覆盖不匹配的本体。

1. 先备份 `%LocalAppData%\NPEduTools` 和自行选择的录课目录，保存并停止录制／监测，再通过托盘停止后台并退出。
2. 使用完整安装包覆盖升级。v1.1.2 安装器会维护本安装的守护；不要在任务管理器里按名称批量结束 Windows 的 `svchost.exe`。便携版换目录和旧安装器仍参见[守护维护说明](https://github.com/tempChanghong/NPEduTools/blob/v1.1.2/docs/GUARD-MAINTENANCE.md)。
3. 升级后检查学校连接、管理口令反馈、ClassIsland 时间、默认设备、参考有效性和下一次自习安排，再试一节自习。安装器不会删除用户数据或替学校改写排程、阈值和照片开关。

## 验证与限制

发布前检查固定提交的原生、网页、KV 和三仓组合 CI；完整交付以本次构建返回的 `result.json` 为准，核对 ZIP／安装器、完整组件、录课运行库、源码与独立插件的字节一致性，并执行对应候选包的隔离交付验证。自动测试与真实一体机、USB、摄像头及声学验收分别记录。

- 联机校准保留 **Beta** 标识。dBFS 是数字信号电平；参考后的估算 dB(A) 仍不是计量级声压级，不用于班级排名。设备或输入设置变化后参考失效，需要重新核对。
- ClassIsland IPC 修复保留 **Beta**，不因 NPEduTools 升级自动安装；备用本体热修复与独立插件按各自说明使用和回退。
- 守护维护只处理本安装；仍需先正常停止 App／Host。升级与卸载不清理用户数据，不卸载 ClassIsland、ExamAware2 或由它们管理的插件。
