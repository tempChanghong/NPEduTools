# NPEduTools v1.1.1 · EVA-02（二号机）

v1.1.1 是 v1.1.0 的稳定性更新，代号仍为 **EVA-02（二号机）**。重点修复学校管理口令验证、联机校准状态刷新、高 DPI 显示、PPT 辅助触控和侧边栏，并新增下一次定时自习预告。v1.1.0 的自习展示、独立守护、照片、座位表与校准功能继续保留，详见[上一版说明](https://github.com/tempChanghong/NPEduTools/blob/v1.1.1/docs/releases/v1.1.0.md)。

## 修复与改进

- **校准口令验证**：快速校准、参考校准和联机校准明确标注本机或学校口令来源、学校口令同步版本，以及验证成功、密码错误、限流和配置不可用的结果。NPEP 接管后使用本班学校管理口令，旧本机口令继续停用。验证与校准操作串行处理，旧轮询或晚到失败不能覆盖新的验证和校准结果。
- **联机校准说明**：界面按实际流程说明连续读取 DLY-2202、麦克风同期采样、自动计算偏移、独立复核和管理员确认。断线、陈旧读数、输入变化及参考失效仍阻止沿用旧结果；联机校准保留 **Beta** 标识。
- **高 DPI 布局**：按 Windows 缩放后的可用工作区调整主页、侧边栏和校准窗口，在设置中提供自动、80%、90%、100% 界面大小。改善 2K 屏幕 200% 缩放时窗口和控件过大的情况。
- **ClassIsland 连接诊断**：分别显示插件文件已安装、禁用、待卸载、文件不完整，以及有新鲜运行握手的“已加载并连接”。课程连接成功不再被当作时间桥接已成功。软件连接页显示经过 ClassIsland 偏移的学校时间，Windows 接收时间单独标注，陈旧学校时间不会继续显示为有效时间。
- **PPT 触控性能**：全局输入钩子仅做短路径处理，将窗口命中判断移到工作线程；未放映时不处理辅助手势，减少普通触控与鼠标延迟。补齐输入队列容量、过期事件、重复提升鼠标事件等边界。
- **侧边栏触控**：展开前释放触控捕获，避免面板闪动、打不开及同一触摸误点展开后的按钮。拖动、前台失效和完全隐藏时清理过期操作。
- **下一次定时自习**：主页和自习监测页显示当前模式下一次有效安排的日期、时段和时间来源；跨午夜显示完整结束日期。安排未应用、时间失效、暂停或无后续安排时明确说明，不把预告当作正在执行。
- **隔离验证稳定性**：修复 Named Pipe 测试时序与自定义构建输出目录中校准测试资源缺失的问题，补充口令状态乱序、触控、高 DPI、时钟及下一次安排回归检查。

配套网页与 KV 保持 **v1.3.0 · Yamada（山田凉）**，本轮仅部署更新，不另发新版。学校后台的新估算 dB(A) 策略默认中阈值 **50**、高阈值 **65**，管理员可修改；已有自定义安排、阈值及 dBFS 策略不自动覆盖。有效参考校准是使用估算 dB(A) 的前提。

## 下载与升级

建议普通用户下载 **`NPEduTools-v1.1.1-win-x64-setup.exe`**；需要便携部署时下载 **`NPEduTools-v1.1.1-win-x64.zip`**。两者来自同一份源码和构建，包含 App、Host、Guard、管理工具、摄像头组件、两处录课组件及其 FFmpeg／ffprobe、自包含 .NET 运行时和桥接插件。

本次完整附件共八项：

| 附件 | 用途 |
| --- | --- |
| `NPEduTools-v1.1.1-win-x64-setup.exe` | Windows x64 安装包 |
| `NPEduTools-v1.1.1-win-x64.zip` | 完整便携包 |
| `NPEduTools.ClassIsland.Bridge.cipx` | ClassIsland 时间与课表桥接 0.2.0.0 |
| `npedutools-examaware-bridge-0.4.0.ea2x` | ExamAware2 桥接 0.4.0 |
| `v1.1.1.md` | 本版说明 |
| `NPEduTools-v1.1.1-source.zip` | 与构建一致的 NPEduTools 源码 |
| `NPEduTools-v1.1.1-third-party-sources.zip` | 第三方源码、构建资料与许可 |
| `SHA256SUMS.txt` | 上述七项附件的 SHA-256 校验值 |

1. 备份 `%LocalAppData%\NPEduTools`、NPEP 身份、录课及相关配置。正常停止录制／监测并退出 App 和 Host。
2. 普通退出不会停止独立守护。更新、移动目录或卸载前，由维护人员按[守护维护说明](https://github.com/tempChanghong/NPEduTools/blob/v1.1.1/docs/GUARD-MAINTENANCE.md)停止本实例守护并撤销任务。守护位于应用目录 `Guard\svchost.exe`，不是 Microsoft 系统服务；务必按完整路径识别，不按文件名批量结束系统进程。
3. 更新完整发行包，不单独替换一个 EXE。ClassIsland、ExamAware2 和 SecRandom 本体单独维护；按需要导入本包中的桥接插件。
4. 升级后先核对学校连接、管理口令反馈、时间来源、设备与校准参考有效性，再测试一节自习。升级不重新启用照片，不重写用户自定义排程或阈值。

## 验证与已知限制

发布前执行锁定依赖恢复、Windows 原生与学校互联回归、固定三仓联合验收，以及针对实际 `result.json` 候选包的 ZIP／安装器一致性、模拟安装升级卸载和内置录课组件验证。自动化使用隔离数据和合成输入；真实 USB、麦克风声学、摄像头及学校一体机验收与这些结果分别记录。

- **DLY-2202 联机校准仍为 Beta**，估算 dB(A) 不等于计量级声压级。不要把 dBFS、估算 dB(A) 和旧网页评分混用，也不据此排名班级。
- 用户报告的 **ClassIsland 本体 IPC 广播集合并发修改异常**须通过更新 ClassIsland 本体解决。修复已在独立工作树应用、通过桌面工程编译及隔离反例验证，尚未安装到目标一体机；本版安装包不包含 ClassIsland 本体，更新 NPEduTools 不会自动应用这项修复。
- 守护恢复、2K 触控表现和长期运行仍需在目标一体机复测；无法保证阻止可提权管理员同时结束所有组件或删除任务。
