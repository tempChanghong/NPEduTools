# NPEduTools v1.1.5 · EVA-02（二号机）

v1.1.5 将自习、录课、主页、首次设置和快捷侧栏整理为围绕当前任务的工作台，重点是操作直观、反馈可信和后台任务稳定。代号保持 **EVA-02（二号机）**，配套 **NPClassworks／NPClassworksKV v1.3.5 · Yamada（山田凉）**。

## 工作台与操作流程

- **一个自习入口**：手动自习、学校安排、设备与校准、报告放在同一工作区。常用操作优先显示，复杂参数按需展开；切页不停止后台监测，离开校准时只取消本页拥有的采样。
- **录课工作台**：集中安排、当前录制、控制和历史记录，保留手动／自动录制与计划预演；暂停、停止、跳过下一项各自绑定对应任务，迟到响应不能误操作后来开始的会话。
- **主页显示当前任务与下一项安排**：区分正在执行、等待、未确认和异常，不用旧缓存证明正在录课或监测。
- **首次设置按用途引导**：保留三份独立协议确认、默认麦克风／摄像头和学校连接准备，检查项明确下一步；引导本身不开始采集。
- **软件连接与课堂模式**：先展示实际连接和常用操作，切换前说明影响，切换后分别显示结果和未完成事项，不把操作受理当成切换成功。
- **快捷侧栏**：当前自习与录课优先；顶部把手区分点击和拖动，按钮不承担拖动。主动收起或全屏隐藏释放触控捕获，松手后才展开或恢复原应用焦点。仅空闲小把手约 60% 不透明度，展开内容保持清晰；全屏自习和考试放映完整隐藏，退出后恢复。
- **高 DPI 布局**：常用操作在紧凑窗口中仍可达，保留 2K／200% 缩放适配和原有全屏自习风格；快捷名称可换行，内容过长时滚动查看。

## 稳定性修复

- 修复相邻课时交接：07:30–08:00 被排除后，08:00–08:45 仍能独立进入录制安排；默认不录制科目增加“周测”，已有用户配置保留。
- 音频短暂缺口补偿与提示不再因为累计小缺口直接停录。音频阻塞宽限 **60 秒**、编码帧停滞宽限 **90 秒**，同步调整工作进程租约；帧停滞指编码进度不前进，不是课件画面静止。持续故障仍停止并保留片段。
- 联机校准允许有限 USB 延迟并保持采样节奏，陈旧读数、断线、模式不符和输入变化仍不能形成有效参考。损坏的校准证据、设备配置和不完整回执不自动激活旧状态。
- 修复设备设置保存、学校锁定／解锁及清单上报的恢复边界，保留未解决的错误；请求超时后先核对实际结果，不自动重放不确定的修改。
- 修复手动自习长按结束、收起确认及迟到响应的会话归属，旧窗口不能结束新会话；十分钟无操作返回的回执与实际策略一致。
- 修复报告修订未刷新、关闭一个报告压制后来会话，以及陈旧执行／采样状态仍被显示的问题。报告、照片和退出事件队列恢复前核验身份与内容，不跨班上传或清理。
- 诊断导出保留正式桌面版本和提交标识；关于页区分构建版本与公开发布状态。协议入口摘要与现行 1.1 正文一致，本次不改变协议正文或重新确认规则。

## 保留的规则

- 新配置默认 **北京时间 19:15–21:30**；既有排程、阈值、学校绑定和默认设备不被版本升级批量覆盖。日期、星期、班级与节假日由学校配置。
- 收起展示默认在连续无操作十分钟后返回，后台监测和已启用的照片策略继续；手动自习可选不自动返回。
- 继续区分 **dBFS** 与 **估算 dB(A)**。参考校准后估算双阈值的新配置默认 **50／65**，管理员可修改；设备或输入设置变化后参考失效。
- **USB 联机校准（Beta）**和 **ClassIsland IPC 修复（Beta）**保留标识。自动测试不等于真实 USB、声学校准或一体机触控验收。

## 下载、插件与升级

普通用户使用 **`NPEduTools-v1.1.5-win-x64-setup.exe`**；便携部署使用 **`NPEduTools-v1.1.5-win-x64.zip`**。完整包自包含 App、Host、Guard、管理工具、摄像头组件、两处录课组件、FFmpeg／ffprobe、.NET 运行时、桥接插件及许可资料，不需要另装开发 SDK。

核心附件包括上述 EXE／ZIP、`NPEduTools.ClassIsland.Bridge.cipx`、`npedutools-examaware-bridge-0.4.0.ea2x`、本版说明、源码 ZIP、第三方源码与许可 ZIP、覆盖全部附件的 `SHA256SUMS.txt`。独立桥接插件与本次完整包内文件一致。

另完整保留上一版的五项 IPC Beta 附件：`ClassIsland.IpcStabilityPatch.cipx`、`ClassIsland-2.1.0.1-ipc-hotfix-Beta-win-x64.zip`、`ClassIsland-IPC-Beta-INSTALL.md`、`ClassIsland-IPC-Beta-sources-and-validation.zip`、`ClassIsland-IPC-Beta-SHA256SUMS.txt`。这些文件沿用 v1.1.2 的已发布字节，不属于本次重新构建的 NPEduTools。时间桥接和 IPC 修复插件用途不同；已安装并正常工作时无需重复安装。备用本体热修复只用于所标明的 ClassIsland 版本。

1. 备份 `%LocalAppData%\NPEduTools` 和自选录课目录，保存并停止录制／监测，通过托盘停止后台并退出。
2. 使用完整安装包升级；安装器维护本安装的独立守护，不按名称批量结束 Windows 的 `svchost.exe`。便携目录迁移按[守护维护说明](https://github.com/tempChanghong/NPEduTools/blob/v1.1.5/docs/GUARD-MAINTENANCE.md)操作。
3. 升级后核对学校连接、ClassIsland 时间、默认设备、校准有效性、下一项任务，试用侧栏展开／收起／拖动和切页。升级、卸载不自动删除用户配置或录课文件，不卸载其他软件及其插件。

## 验证与反馈

本轮原生全量 **1756 项通过、0 跳过**，完整桌面隔离套件与三仓精确源码组合 CI 通过。CI 的无声卡环境单独验证三段提示音完整解码、权限与时序，不声称验证了扬声器播放；报告按固定尺寸离屏检查，窗口生命周期仍单独检查。交付以本次候选 `result.json` 核对 ZIP／安装器、全部组件、源码及独立插件一致性，并执行对应候选包的交付验证。
