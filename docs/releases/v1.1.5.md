# NPEduTools v1.1.5 · EVA-02（二号机）

当前源码版本为 **v1.1.5**，代号保持 **EVA-02（二号机）**。配套网页与 KV 源码版本为 **v1.3.5 · Yamada（山田凉）**。本页记录本地源码范围，不代表 GitHub Release、安装器或线上部署已经完成。

## 本版范围

- 统一自习工作台，保留手动、学校定时、设备与校准、报告入口；切页不停止后台任务，校准离页按归属释放采样。
- 主页突出当前自习与录课、下一项任务；录课工作台集中安排、录制控制与记录，保留现有录制和排程功能。
- 初始设置按任务组织，保留三份协议确认及设备、学校连接设置。
- 软件连接先显示状态与常用操作；课堂模式区分切换预览与实际执行结果，未知状态不冒充成功。
- 快捷侧栏优先显示自习与录课，工具区紧凑；快捷名称换行，小把手空闲半透明，保留全屏隐藏与触控捕获边界。
- 保留联机校准 (Beta)、dBFS／估算 dB(A) 区分、已有参考失效条件、学校权限及自定义排程。新配置默认 19:15–21:30，不覆写已有安排。

## 验证与交付边界

本轮按当前源码执行离线构建、隔离 WPF 与自动测试。测试夹具不等于真实一体机、USB 声级计、声学或生产数据库验收；具体结果随对应提交记录。本轮不创建发布包、不推送、不部署，历史发布说明及旧附件保留。
