# NPEduTools NPEP N1 现场试用包（2026-09-24）

这是用于单设备配对与状态上报验收的 Windows x64 试用构建，不是新的正式版本。

## 启动与配对

完整解压后运行 `Start-NPEduTools.cmd`，进入“设置 → 学校互联”。服务地址填写 `https://api.newfires.top`，检查服务、核对后创建配对码。学校管理员在 NPClassworks 的“大屏设备 → NPEP 设备互联”批准后，回到本机核对学校、班级和大屏并确认连接。

本阶段只支持 `device.status`：配对、只读状态上报、暂停、恢复与撤销。尚不支持远程考试模式切换、通知下发或录制控制。生产服务已启用，真实大屏现场验收仍待完成。

## 文件与依赖

- `app` 包含程序及 .NET 运行时，无需另装 .NET；请保留完整目录结构，不要仅复制 EXE。
- 包内保留 ClassIsland、ExamAware2 桥接插件及第三方材料。仅做学校互联配对不要求先安装桥接插件。
- 不附带 FFmpeg；需要录制功能时再按 `RECORDING-TOOLS-INSTALL.md` 安装。
- 不包含任何生产账号、配对码或设备凭据。请使用目标设备的实际 Windows 用户进行配对，不要从别的电脑复制配对凭据。

## 验收范围

依次确认配对审批、本机确认、状态接收时间更新、断网恢复、退出重开以及远端撤销。不要把开发机结果当作真实大屏验收，也不要为配对测试启动录制或切换课堂模式。
