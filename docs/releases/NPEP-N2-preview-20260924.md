# NPEduTools NPEP N2 通知试用包（2026-09-24）

这是 Windows x64 通知联调试用构建，不是新的正式版本。应用的基础 InDev 版本号保持不变，以本说明及包名区分 N2 试用构建。

## 这次增加什么

- 已连接学校互联的设备自动通过 HTTPS 轮询接收学校通知，无需另外申请通知权限，不必为通知重新配对。
- 原生置顶弹窗：次要绿色、普通蓝色、重要深黄色、紧急红色；大字号白字，需要手动关闭。
- 网页发布时的弹窗选择同时作用于桌面。关闭弹窗的次要通知仍进入“设置 → 学校互联 → 学校通知”列表，可主动打开。
- 通知按版本去重，回执本地持久化后重试上传。收到、展示、手动关闭是三个不同阶段，不宣称“老师已读”。
- 暂停互联同时暂停通知和状态上报。通知撤回、过期、修订或授权失效后不再展示旧正文。

## 升级与使用

**需学校服务端具备 N2 通知接口，生产不会因下载这个包自动更新。** 服务未更新时会提示通知接口未就绪，原有状态上报继续运行。此前的 N1 试用包不支持通知。

退出旧 NPEduTools（包括后台），将本包完整解压到新的目录，运行 `Start-NPEduTools.cmd`。使用之前配对的同一个 Windows 用户，既有学校互联配对可继续使用；不要删除数据目录或复制其他电脑的设备凭据。进入“设置 → 学校互联”确认连接与通知状态。

本包仍不实现远程考试模式切换或远程录制控制。通知不依赖 ClassIsland 插件，不会为了显示通知启动 ClassIsland。

## 文件作用

- `Start-NPEduTools.cmd`：启动入口。
- `app/`：主程序、Host 后台、辅助组件和 .NET 运行时；不要只复制 EXE。
- `ClassIsland-plugin/`、`ExamAware2-plugin/`：其他集成功能的桥接插件；学校通知本身不要求安装它们。
- `RELEASE-NOTES.md`：本说明；`README.md`：便携包使用指南。
- `RECORDING-TOOLS-INSTALL.md` 与 `Install-Recording-Tools.ps1`：可选录制工具安装说明与脚本；包内不附带 FFmpeg。
- 许可证、依赖清单及第三方源码材料：用于追溯随包组件与许可。

## 试用边界

开发机上的自动测试、WPF 渲染和隔离服务器验证不能代替班级大屏验收。正式试用前应核对四级通知、静默通知、同版本不重弹、手动关闭、暂停恢复、撤回/修订及断线重连。置顶不能保证覆盖 Windows 安全桌面或全部独占全屏程序。

不包含生产账号、令牌、配对码或测试学校数据。本轮未自动安装到目标大屏，也未部署学校服务器。
