# NPEduTools v1.0.0 · EVA-01（初号机）

## 首个正式版本

**v1.0.0 是 NPEduTools 的首个正式版本，代号 EVA-01（初号机）。** 从常驻侧边栏、独立录课到学校互联，桌面端负责网页难以完成的本机工作，主窗口统一管理设置。配套 **NPClassworks／NPClassworksKV v1.2.5 · Hitori（后藤一里）**。

相较 InDev 20261002，本版增加 SecRandom V3 点名、预授权配对、定时监测保护与恢复、关于页面和协议确认；提供 Windows 安装 EXE，录课组件随包附带。原有通知、考试／日常切换、考试方案、学校排程及噪音报告继续保留。

正式版不意味着所有教室硬件和无人值守场景已经实测。驱动、学校时间、插件和长期运行的适配范围见本文末尾；学校上线建议先在一台设备核对。

## 本版更新

### 课堂工作台与 SecRandom 点名

- 重新整理主页的课堂工具、关联软件、录课及学校互联入口，保留“侧边栏快速使用、主窗口集中管理”。增加关于页面、官网、许可证、鸣谢及可复制的版本信息。
- 接入 **SecRandom V3** 的本机接口，可打开点名页、管理浮窗，并用侧边栏 **“抽”** 按钮闪抽一人。未配置时进入配置提示，不发送抽取请求。
- 配置程序位置后核对接口和名单。遇到抽取结果不确定时先查看 SecRandom 历史，再决定是否重试，避免把连接重试变成重复抽取。SecRandom 本体和名单仍单独准备，无需额外安装本项目的桥接插件。

### 录课：组件随包附带、计划更易理解

- 安装版和便携 ZIP **内置自行构建的 FFmpeg／ffprobe**，无需再单独下载录课组件。随包提供对应源码、构建材料、许可证与锁定哈希，旧 InDev 下载包保持原样。
- 保留独立手动录制、暂停／继续和本机保存；自动录课支持每周重复或指定日期安排，也可跟随 ClassIsland 课表。
- 整理自动录课页面，明确“保存计划”“试运行”“开启自动录课”的区别。**试运行只模拟，不生成视频；保存计划不会自动打开总开关。**
- 自动录课及学校自动排程仍采用 ClassIsland 学校时间，不因接口失效而改用系统时间；考试期间保留计划并暂停日常自动录制。

### 学校配对与通知、考试联动

- 学校可预先对班级、年级或全校现有大屏开放配对；被授权的 NPClassworks 大屏网页生成 **8 位、10 分钟有效的一次性码**，NPEduTools 输入后端 API 地址和码后确认归属。管理员不必同时在线，原审批流程继续保留。
- 首次设置提供学校服务地址及配对入口，解释前端／API 分离部署、非默认端口和管理授权的实际影响。
- 保留 HTTP 轮询通知与持久化回执；独立纯色大字通知窗口保持置顶，普通及以上使用变暗遮罩、手动关闭。通知不依赖 ClassIsland 通知提供商。
- 保留完整考试／日常远程切换、软件运行与登录自启动联动、考试方案投递及明确的放映请求；操作失败或部分完成时保留证据，支持核实和重试。配对不是任意远程命令或任意文件读取授权。
- HTTPS 继续验证证书；网络与 TLS 错误可持续重试，不跳过证书校验。HTTP 可用于可信测试网络，正式部署建议配置可信 HTTPS。

### 学校定时监测保护与恢复

- 与网页的专用定时监测页面配合，展示实际会话和采样质量；网页心跳不新鲜时保留宽限，再显示桌面备用画面，不把未知状态当作网页已关闭或采集已恢复。
- 可以暂时返回作业板，**采集继续**；学校配置返回时长，默认 **10 分钟**，范围 **1–60 分钟**。网页与桌面共享返回期限，离线返回恢复后补登记，不重新计时。
- 定时会话的停止与完整退出受管理验证保护，本机需准备管理口令；网页使用学校管理 PIN。手动监测不套用这些定时保护。
- 新增独立守护组件，在符合条件时恢复异常退出的后台。恢复后重新核对学校连接、时间、麦克风、规则及会话，不能因为进程重新出现就声称已经恢复采集。
- 原生噪音在本机处理声音，仅上传统计，不保存或上传原始录音。dBFS 是信号电平，不是教室实际声压级，也不用于班级排名。

### 首次设置、协议与开源许可

- 引导增加 SecRandom 配置，并补充考试、学校互联和定时监测保护；可按用途选择、明确跳过，保留已有设置与引导进度。
- 首次启动分别阅读并确认《NPEduTools服务协议》《NOVARK POWER EDUCATION PLUS计划服务协议》《NOVARK POWER EDUCATION PLUS计划隐私协议》，生效日期均为 **2026年10月4日**。首次不预选，写入失败不继续启动，旧引导完成记录不等于同意新协议。
- 三份协议与 **GPL v3 全文**随应用嵌入，离线可读；关于页面也可再次查看。GPL 独立展示，不增加第四个同意勾选，服务协议不限制开源许可授予的权利。
- NPEduTools、NPClassworks及NPEP不向私有部署云端上传原音频或摄像头采集信息，并永远不向星火动力云端上传这些信息。本机微课录制可以保存含声音的视频，属于另一项功能。

## 下载文件与作用

面向 **Windows 10／11 x64**，应用启动请求管理员权限。普通用户选择安装 EXE 或便携 ZIP 其中一种即可，均包含 .NET 运行时和录课组件，无需开发 SDK。

| 文件 | 作用 |
| --- | --- |
| `NPEduTools-v1.0.0-win-x64-setup.exe` | Windows 安装程序；固定目录、开始菜单入口和可选桌面快捷方式 |
| `NPEduTools-v1.0.0-win-x64.zip` | 便携完整包；解压后运行 `Start-NPEduTools.cmd`，不要只取出一个 EXE |
| `v1.0.0.md` | 本版功能、升级、许可及限制说明，可离线保存 |
| `NPEduTools-v1.0.0-source.zip` | 本版确切构建源码；用于开发及核对，不是安装程序 |
| `NPEduTools-v1.0.0-third-party-sources.zip` | 对应发行组件的第三方源码、许可及构建材料，含随包录课组件资料 |
| `NPEduTools.ClassIsland.Bridge.cipx` | 安装到 ClassIsland 的时间／课表桥接；清单版本 0.2.0.0，适配 API 2.1.0.1 |
| `npedutools-examaware-bridge-0.4.0.ea2x` | 安装到 ExamAware 1.5.2；提供连接、退出、自启动、方案与放映控制，不是独立应用 |
| `SHA256SUMS.txt` | 核对本次实际附件完整性；不是发布者签名 |
| GitHub `Source code (zip / tar.gz)` | 发布标签对应的仓库源码，GitHub 在正式发布后提供 |

ClassIsland、ExamAware2 和 SecRandom 本体不随包提供。原生手动噪音监测不依赖 FFmpeg 或 ClassIsland；学校自动排程需要可靠的 ClassIsland 学校时间。

## 安装与升级

1. 学校互联建议先更新 KV v1.2.5 的完整迁移链，再更新网页 v1.2.5，最后更新桌面。保留已有部署身份与配对，不重复首次激活。
2. 更新前备份 `%LocalAppData%\NPEduTools`、录课目录及相关配置；保存并正常停止录制／监测，然后完整退出主程序和后台。安装器不会替您强行关闭进程。
3. 安装版默认放入 `C:\Program Files\NPEduTools`，可创建桌面快捷方式；便携版完整解压到固定目录。安装时不会自动创建 ClassIsland 管理员任务、登记登录启动或替您完成学校配对。
4. 从旧 ZIP 迁移到安装版时，先在旧程序关闭 NPEduTools 登录启动，再退出旧程序并安装；以后从新入口运行，按需要重新登记登录启动，避免两份同时运行。不同 Windows 账户的数据目录不同。
5. 首次打开按提示确认三份协议。已有引导及功能设置保留；可重新打开初始设置检查 SecRandom、学校连接和噪音配置，配置过程不会自动试抽或开始采集。
6. 核对关联软件实际程序路径及插件。使用完整考试模式前创建并核实 ClassIsland 管理员登录任务；升级 ExamAware 桥接至 0.4.0，保存并关闭编辑器后再测试模式切换。
7. 定时监测前保存麦克风、设置本机管理口令，核对学校时间、年级继承、班级范围、时段及学校管理 PIN，先用单台设备验证。

安装升级保留用户配置；卸载保留用户数据、视频及关联软件的插件和启动设置。卸载前关闭 NPEduTools 登录启动并完整退出。安装器拒绝覆盖降级；回退请备份后按专门流程处理，不直接恢复旧学校身份或强制覆盖运行中的目录。

## 已知限制

- **ExamAware 编辑器退出协商问题尚未解决**：切换前保存并关闭编辑器，返回日常前正常结束放映。遇到阻碍不强制结束未保存窗口。
- 安装包和应用尚未进行 Authenticode 签名。SHA-256 用于完整性核对，不代替数字签名；不要以关闭安全软件作为正常安装步骤。
- 定时保护不属于 Windows kiosk 或防篡改系统，不能阻止有管理员权限的人终止、卸载或改动软件；进程恢复与实际采样恢复分别核实。
- 服务器停用或撤销不能立即通知离线设备；需要立即停止时在本机处理。学校时间失效时自动任务等待／停止，不使用系统时间替代。
- 真实教室驱动、触摸、DPI、多屏、长时间采样／录课、Windows 重启与休眠恢复仍需现场验证。没有原音频上传、摄像头捕获或跨班批量考试控制。
- 未合并的学校设备诊断比对及运维总览不列为本次正式功能；发布本软件不自动部署网页或后端，也不自动升级班级大屏。
