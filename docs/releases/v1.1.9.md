# NPEduTools v1.1.9 · EVA-02（二号机）

v1.1.9 是针对自习展示和作业同步的小范围修复。相对 v1.1.8，仅包含 `3273cc5` 的自习展示稳定性／分页修复，以及 `d9421d2` 的手动作业同步整合，再加版本和文档更新。代号保持 **EVA-02（二号机）**。

## 修复内容

- **单次状态读取失败不再立即收起已确认的学校自习页。** 手动状态、退出状态等辅助查询失败时，按最近一次有效自习确认与既定时间边界保留原展示，并显示待同步状态。该机制只保留已经存在的窗口，不用旧状态开启新自习，也不推进学校时钟。明确的撤销、停止、考试放映优先和时段结束仍按原规则处理。
- **减少作业被拆成过多页面。** 短作业最多六格；中等篇幅改用三列通高布局，尽量保留整科内容；较长正文才使用两列续页。按字体实测高度分页，保留完整文字，新正文仍等待当前页阅读周期结束。
- **补齐手动自习的当天作业同步。** 手动准备／运行阶段可按 Windows 日期读取当前绑定学校允许的作业来源，不再要求处于学校定时时段或 ClassIsland 时钟在线。仍然只读学校配置的来源，不能由大屏任意指定班级。
- **学校作业来源变化后立即撤下旧内容。** 手动会话版本与学校作业配置版本分别校验；配置变化、禁用或解绑不能被普通正文更新的延后轮换逻辑掩盖。

## 配套服务与范围

手动作业同步需要 NPClassworksKV 同时支持只读请求的可选字段 `purpose=Manual`（配套提交 `385db88547f0a12dd4a848366743a98dab4eaef2`）。旧 KV 会拒绝该字段，此时作业可能仍显示不可用；不会伪造定时状态绕过校验，也不影响手动采集。服务端继续校验绑定、运行上下文、配置版本、有效回执及北京时间当天日期。此配套修改无需新增数据库迁移，桌面安装器不会更新学校服务器。

本版没有接入手写识别，也没有加入其他新功能或更改录课、校准、设备、阈值、摄像头和守护策略。已有配对、自定义排程及用户数据继续保留。新配置的默认自习时段仍为 **19:15–21:30**，继续区分 **dBFS** 与 **估算 dB(A)**。

## 下载附件

普通用户下载 **`NPEduTools-v1.1.9-win-x64-setup.exe`**；便携部署下载 **`NPEduTools-v1.1.9-win-x64.zip`**。完整包包含 App、Host、Guard、管理员辅助组件、摄像头组件、两处录课组件、FFmpeg／ffprobe、自包含 .NET 运行时及桥接插件，无需安装开发 SDK。

- `NPEduTools.ClassIsland.Bridge.cipx`、`npedutools-examaware-bridge-0.4.0.ea2x`，从本版精确候选包提取。
- `NPEduTools-v1.1.9-source.zip`、`NPEduTools-v1.1.9-third-party-sources.zip`、`SHA256SUMS.txt`。
- 原样保留 v1.1.8 的五项 ClassIsland IPC Beta 附件：`ClassIsland.IpcStabilityPatch.cipx`、`ClassIsland-2.1.0.1-ipc-hotfix-Beta-win-x64.zip`、`ClassIsland-IPC-Beta-INSTALL.md`、`ClassIsland-IPC-Beta-sources-and-validation.zip`、`ClassIsland-IPC-Beta-SHA256SUMS.txt`。

IPC Beta 附件未重新构建。已经正常使用插件补丁的设备无需重复安装；备用本体热修复仅适用于附件说明中的版本。安装、验证与回退见 `ClassIsland-IPC-Beta-INSTALL.md`。总摘要覆盖除 `SHA256SUMS.txt` 自身之外的全部 12 项附件。

## 升级与回退

1. 备份 `%LocalAppData%\NPEduTools` 和录课目录，保存正在进行的任务，通过托盘停止后台并退出，再运行完整安装器覆盖升级。
2. 若安装器未能完成守护维护，保留诊断目录及 `Prepare-result.txt`，按[守护维护说明](https://github.com/tempChanghong/NPEduTools/blob/v1.1.9/docs/GUARD-MAINTENANCE.md)操作。默认守护路径为 `C:\Program Files\NPEduTools\app\Guard\svchost.exe`；只处理本安装实例。
3. 升级后核对关于页 **v1.1.9 · EVA-02（二号机）**、学校连接、时间、下一次自习、设备及校准状态；观察一次完整自习、作业更新和报告。
4. 回退前保存任务并另行备份最新数据，完成本安装维护后使用旧版完整包。应用回退不回退学校服务或数据库。
