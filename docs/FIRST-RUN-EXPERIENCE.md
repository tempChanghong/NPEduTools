# NPEduTools 首次使用引导（OOBE）

状态：2026-09-19 已实现并接入 WPF 启动流程。让首次使用者完成需要的功能准备，随后进入“侧边栏使用、主窗口管理”的日常模式。已有用户继续保留原设置。当前更新在开发构建中，先前生成的 P4 便携 ZIP 未重新打包。

## 已实现的流程

| 步骤 | 用户看到的内容 | 完成后的结果 |
| --- | --- | --- |
| 欢迎与用途 | 认识侧边栏和管理窗口，选择需要快捷启动、PPT 触摸翻页、微课录制或自动录课 | 后续只显示相关配置，所有功能可稍后开启 |
| 使用偏好 | 查看已保存的启动偏好，打开既有偏好页设置侧栏位置、登录时的显示方式和可选自启动；快捷用途提供整理入口，PPT 用途显示操作说明 | 切回引导继续；“已查看，使用现有设置”不等同于验证每个功能已经启用 |
| ClassIsland（可跳过） | 检测本体路径、连接及桥接能力，提供 `.cipx` 安装说明；显示学校日期时间供核对 | 手动录制与快捷工具可以先用；自动录课等待学校时间可靠后再配置 |
| 录制准备（按所选用途出现） | 打开既有录制页选择屏幕、画质、音源和保存目录，点击“保存设置”，返回检查 | 枚举设备、核对保存配置、实际检查目录写入；试录需用户主动开始和结束，在录制页回放 |
| 检查与开始使用 | 展示已完成、跳过及尚待处理的项目；自动录课用户进入计划预演，其余进入侧栏 | 完成引导本身不启用自动录课；在计划页核对后主动启用 |

ClassIsland 步骤只在选择自动录课时出现；手动录制可以独立使用。桥接检查分别显示程序路径、本体连接、桥接时间与课表状态。复用 `SchoolClockTracker`，根据持续前进的样本、单调时间计算的新鲜度和日期连续性判断可用性，学校时间不使用系统时间替代。还需本日课表已加载、启用、日期匹配，以及用户勾选“已核对学校日期，时间与铃声一致”。断连、过期、桥接实例/时间纪元改变或日期改变后，重新取消确认。此确认仅属于本次引导，不替代计划页的校验。

程序路径未保存但 ClassIsland 已连接时允许继续；路径用于以后从本软件启动本体，不能用路径存在代替连接成功。未准备好的项目可明确跳过。检查结果在总结中标记为“本次已检查（非持续状态）”，不承诺以后仍健康。

桥接安装说明已对照本地 [ClassIsland Docs：插件](classisland-docs-next/src/app/plugin.md)：“设置 → 插件 → 更多设置 → 从本地安装”，选择发行包 `ClassIsland-plugin/NPEduTools.ClassIsland.Bridge.cipx`，启用后重启 ClassIsland。引导不会替用户安装插件或修改课表。

自动录课的周期规则、单日覆盖、17 项科目排除和执行记录继续在现有计划页管理。首次引导只帮助完成首个计划和预演，不复制整个高级编辑器。

## 首次启动与以后

- 第一次手动启动提供“开始设置”和“稍后设置”，允许返回上一步。稍后设置或关闭时保存用途和所在步骤，下次通过入口续做，不反复自动打扰。
- Windows 登录自动启动时仅在侧栏提示待配置；用户点击后再展开引导。
- 主窗口保留“初始设置 / 重新检查环境”入口，用户随时可重新检查。
- 已有用户只看到可选入口，不清空配置，不因引导升级反复出现整套流程。
- 引导完成状态按本机用户与 Host 端点保存；它与设备的实时健康状态分开。已完成引导不代表今天的设备或学校时间仍有效。
- 引导状态单独版本化，保存阶段进度、明确跳过项及完成状态。磁盘写入失败时说明未保存，不把该步骤显示为已完成。
- 记录损坏或版本不受支持时保留原文件、不自动弹出引导；从入口打开后显示原因。失败时可重试，或明确选择“不保存并关闭引导”，不强制用户困在窗口内。
- 不自动改动 ClassIsland 课表、系统时间或开启麦克风采集；设备探测和实际试录是分开的操作。

## 实现落点

入口仍为 `App.OnStartup` → `MainWindow.Start`。在其他组件有机会建立配置前读取/建立引导标记，避免新用户因后台初始化产生文件而被误认为已有用户。

| 文件 | 职责 |
| --- | --- |
| `src/NPEduTools.App/OnboardingState.cs` | 用途、条件步骤、返回/跳过/完成状态、格式验证和临时文件原子替换 |
| `src/NPEduTools.App/MainWindow.Onboarding.cs` | 区分新老用户，接入启动、主窗口与侧栏，复用既有管理入口 |
| `src/NPEduTools.App/OnboardingWindow.xaml(.cs)` | 引导界面、学校时间检查、录制设备与目录检查 |
| `tests/NPEduTools.Tests/OnboardingTests.cs` | 进度状态和存储边界测试 |
| `scripts/test-onboarding-ui.ps1` | 私有端点上的真实 WPF 交互验收及截图 |

引导进度保存到 `%LocalAppData%/NPEduTools/ui/<端点 SHA-256 前 24 位>.onboarding.json`，版本 1，上限 16 KiB。仅包含用途、当前步骤、已查看/检查项、跳过项、完成和推迟标志；不保存实时健康结果、密码或另一套业务配置。端点隔离方式与现有偏好一致。

录制检查读取已经保存的录制配置，并启动 Recorder 的 `--probe`，不会发送开始录制命令。所选显示器和开启的音源须可枚举；保存目录通过创建随机临时文件、写入/刷新和自动删除检查，磁盘可用空间须至少 512 MiB。进入下一步时重新检查，避免只凭上一次检查通过放行。临时文件以独占创建方式建立，不覆盖已有文件。音源枚举成功不代表收到了声音，短试录与回放仍由用户操作。
