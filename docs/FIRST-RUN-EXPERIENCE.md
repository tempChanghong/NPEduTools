# NPEduTools 首次使用引导（OOBE）建议

状态：方案草稿，尚未接入启动流程。目的：让首次使用者完成需要的功能配置，随后进入“侧边栏使用、主窗口管理”的日常模式。已有用户继续保留原设置。

## 推荐流程

| 步骤 | 用户看到的内容 | 完成后的结果 |
| --- | --- | --- |
| 欢迎与用途 | 认识侧边栏和管理窗口，选择需要快捷启动、PPT 触摸翻页、微课录制或自动录课 | 后续只显示相关配置，所有功能可稍后开启 |
| 使用偏好 | 侧边栏位置、登录后是否仅显示侧栏；登录启动作为明确可选项 | 复用现有偏好设置，不重复保存一套 |
| ClassIsland（可跳过） | 检测本体路径、连接及桥接能力，提供 `.cipx` 安装说明；显示学校日期时间供核对 | 手动录制与快捷工具可以先用；自动录课等待学校时间可靠后再配置 |
| 录制准备（按所选用途出现） | 选择屏幕、画质、麦克风、系统声音与保存目录；显示音源和目录检查结果 | 复用现有录制配置；试录需用户主动开始和结束，可打开视频回放 |
| 检查与开始使用 | 展示已完成、跳过及尚待处理的项目；自动录课用户进入计划预演，其余进入侧栏 | 完成引导本身不启用自动录课；在计划页核对后主动启用 |

桥接检查需分别显示“本体已连接”“桥接可用”“学校时间已校验”，不能只凭进程存在或管道连接成功给出全部通过。学校时间不能被系统时间替代。

自动录课的周期规则、单日覆盖、17 项科目排除和执行记录继续在现有计划页管理。首次引导只帮助完成首个计划和预演，不复制整个高级编辑器。

## 首次启动与以后

- 第一次手动启动提供“开始设置”和“稍后设置”，允许返回上一步，退出后能继续。
- Windows 登录自动启动时仅在侧栏提示待配置；用户点击后再展开引导。
- 主窗口保留“初始设置 / 重新检查环境”入口，用户随时可重新检查。
- 已有用户只看到可选入口，不清空配置，不因引导升级反复出现整套流程。
- 引导完成状态按本机用户与 Host 端点保存；它与设备的实时健康状态分开。已完成引导不代表今天的设备或学校时间仍有效。
- 引导状态单独版本化，保存阶段进度、明确跳过项及完成状态。磁盘写入失败时说明未保存，不把该步骤显示为已完成。
- 不自动改动 ClassIsland 课表、系统时间或开启麦克风采集；设备探测和实际试录是分开的操作。

## 实现落点

现有入口在 `App.OnStartup` 和 `MainWindow.Start`；主窗口已经有侧栏位置、登录启动、ClassIsland 管理、录制设置和计划页。建议增加一个薄的引导窗口，调用这些既有入口与校验结果，业务配置仍由现有存储负责。首次引导状态另存，避免更改原启动偏好格式时影响已有用户。

先实现“可跳过、可续做、可重新打开”的导航及真实检测结果，再接入可选试录和首次计划预演。不要用点击“下一步”替代连接、保存或录制成功的实际确认。

## 验收重点

新用户正常完成；无 ClassIsland 时完成独立功能；插件缺失/时间失效准确提示；中途退出续做；已有配置不被覆盖；保存失败不误报；登录自启动不弹完整引导；跳过后能重开；完成引导不会开启采集或真实自动录制。
