## 协议

- [NPEduTools服务协议](NPEduTools-SERVICE-AGREEMENT.md)：桌面软件使用、本机权限、录制与软件联动。
- [NOVARK POWER EDUCATION PLUS计划服务协议](NPEP-SERVICE-AGREEMENT.md)：学校配对授权、远程操作与组织职责。
- [NOVARK POWER EDUCATION PLUS计划隐私协议](NPEP-PRIVACY-AGREEMENT.md)：信息处理、保存期限与个人信息权利。
- [GNU GPL v3开源许可证](../../LICENSE)：本项目的开源授权全文，与服务协议独立提供。

三份协议分别确认。接受协议不自动开启学校互联、麦克风、录制或登录自启动，不代替学校对受影响师生的告知及依法需要取得的个人或监护人同意。

噪音监测在本机处理声音，只上传统计。NPEduTools、NPClassworks及NPEP计划不向私有部署云端上传原音频或摄像头采集信息，并永远不向星火动力云端上传这些信息。本机微课录制可以保存含声音的视频，属于另一项功能。
