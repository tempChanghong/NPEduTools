# NOVARK POWER EDUCATION PLUS计划服务协议

版本：1.0  
更新日期：2026年10月4日  
生效日期：2026年10月4日

NOVARK POWER EDUCATION PLUS（简称 **NPEP**）由星火动力技术组（NOVARK POWER Technical Group，简称 **NPTG**）开发，是连接 NPClassworks、NPClassworksKV 与 NPEduTools 的教育软件互联计划。本协议说明加入计划后的组织授权、设备控制及服务责任；个人信息处理详见[NPEP计划隐私协议](NPEP-PRIVACY-AGREEMENT.md)。

**配对后的学校控制会影响设备运行、相关软件的登录自启动设置及麦克风使用。请由有权代表学校和管理设备的人员完成配置，并向受影响师生说明用途及停止方式。**

## 一、参与方与服务边界

1. “学校”包括实际组织使用 NPEP 的学校或其他教育机构；“运营者”指实际运行学校所选服务器并负责相应服务的组织或个人；“绑定设备”指完成学校、班级及大屏归属确认的 NPEduTools 设备。
2. NPTG 负责软件开发及本协议制定。学校、私有部署运营者与 NPTG 可以是不同主体。请根据服务地址及学校公告确认实际运营者，不应仅因产品名称推定服务器属于 NPTG。
3. 学校负责管理账号权限、设备归属、教学安排及合法使用；运营者负责其实际服务中的访问控制、数据存储、备份、安全维护及相关告知。NPTG 如实际运营服务或受托处理数据，应按实际角色履行相应义务。
4. NPEP 不是对设备的无限制远程接管，也不是紧急广播或考试秩序的唯一保障。服务只执行软件已经提供、当前环境支持的操作。

## 二、开通、预授权与配对

1. 学校可按班级、年级或全校管理范围配置 NPEP 开通及预授权。符合预授权条件的大屏可通过规定流程生成配对码，由设备端输入并完成绑定；不符合条件时应按实际审批流程处理。
2. 操作者应确认服务地址、学校、班级和设备归属，阅读本协议与隐私协议，并具有管理相应大屏的权限。配对码及凭据只应交给参与配对的有权人员，不应公开展示给无关人员。
3. **完成有效配对，即授权所属学校通过已提供的管理功能向绑定设备发起操作；设备不必对每次同类远程请求再次弹出授权确认。** 该授权仍受账号角色、绑定范围和功能边界约束，并不取消 Windows 自身权限要求或软件对执行结果的检查。
4. 学校可以撤销绑定，设备管理人员也可按本机入口解除配对。撤销后不能继续使用失效凭据发起新的学校控制；离线设备获知撤销以及正在运行任务的处理，受连接与本机状态影响。
5. 学校管理员的设备授权不是教室内所有个人的隐私同意。学校应另行落实对教师、学生及监护人的必要告知和合法处理依据。

## 三、学校可以实施的操作

| 功能 | 对设备的主要影响 |
| --- | --- |
| 日常／考试环境切换 | 按模式要求调整相关软件的 Windows 登录自启动设置，启动或正常退出相应软件，暂停或恢复日常自动录课安排。 |
| 考试配置与放映 | 向已配置的 ExamAware2 及桥接插件提供考试计划，执行受支持的准备、开始或停止操作，并回报结果。 |
| 学校通知 | 向绑定设备投递适用范围内的通知；普通及以上等级可置顶显示、使用全屏变暗遮罩，并要求手动关闭。 |
| 手动噪音监测 | 使用本机已配置的麦克风进行统计，接收开始、停止请求并向学校服务器回报状态和统计报告。 |
| 定时噪音监测 | 按学校配置的适用班级、时间段和保护规则执行监测；网页与本机配合显示状态及处理授权停止。 |
| 状态与记录 | 回报连接、模式、运行阶段、命令结果、噪音采样质量及定时任务状态，供有权管理人员核实。 |

1. 上表不授予任意读取本机文件、执行任意终端命令、隐蔽访问摄像头或监测谈话内容的权限。某项功能尚未配置或环境不支持时，配对本身不能使其自动可用。
2. 远程指令可能因软件未就绪、未保存内容、权限不足、过期、网络中断或设备异常而失败或部分完成。请以完成回执及现场运行状态判断；收到请求不等于完成操作，历史成功记录也不代表此刻状态。
3. 通知的投递、显示或关闭记录用于核对技术处理过程，不能单独证明某个人已经阅读、理解或同意通知内容。

## 四、定时监测、后台运行与保护

1. 启用噪音监测前应在设备端配置麦克风。网页在 NPEduTools 接管监测后不重复采集同一用途的麦克风数据；历史网页记录与原生统计的计量方式可能不同，不能直接混合评分。
2. **关闭网页、返回作业板、隐藏主窗口或暂停学校状态上报，不等于停止正在执行的本机监测。** 定时监测可在后台继续；发生异常退出时，符合已配置保护规则的任务可能由后台保护组件恢复。
3. 定时策略可要求管理密码或学校授权才能停止监测、退出受保护后台。暂时返回作业板不必等同于停止任务，页面可按后台配置的时长返回监测展示。学校应提供教师及有权管理人员可用的停止与故障处理方式，不得利用保护机制阻碍依法行使个人信息权利。
4. 定时任务使用 ClassIsland 提供的学校时间及其有效状态判断执行窗口。离线时，本机可能继续执行仍然有效的缓存策略；在线修改或撤销策略并不保证离线设备立即同步。现场需要停止时，应使用受支持的本机停止入口并核实状态。
5. 噪音统计反映设备输入信号和采样质量，不识别个人，也不属于经过校准的声压级测量。不得将其作为对单个学生处罚、人员健康判断或班级排名的唯一依据。

## 五、内容与数据处理

1. 学校及内容提供者保留对其通知、考试资料及其他内容依法享有的权利。为完成投递、显示、配置和核实，相关软件及运营者仅在必要范围内处理这些内容；本协议不授予将其用于广告、出售或通用模型训练的概括授权。
2. 噪音监测在本机短暂处理麦克风样本，仅上报统计及必要状态，不保存或上传原音频。微课录制属于另一项本机功能，可以保存含声音的视频，但不通过 NPEP 自动上传该文件。
3. **NPEduTools、NPClassworks及NPEP计划不会向学校或其他机构私有部署的云端上传任何原音频数据或摄像头采集信息。NPEduTools、NPClassworks及NPEP计划永远不会向星火动力云端服务器上传任何原音频数据或摄像头采集信息。**
4. 学校及实际运营者应按明确、合理且必要的目的处理组织和个人信息，说明数据接收方、保存期限、访问权限与权利行使渠道，不得因为完成技术配对就推定取得无限制的数据处理授权。
5. 涉及个人信息、敏感个人信息或未成年人信息时，参与方应履行适用的法定义务；依法需要个人同意、单独同意或监护人同意的，应在相应处理前取得。设备权限窗口和配对操作不能代替这些要求。

## 六、安全、运营与停止服务

1. 学校应合理分配管理权限，运营者应保护服务器、账号、凭据、日志及备份。正式部署应采用可信 HTTPS；HTTP 兼容性不意味着传输已加密。
2. 学校需要安排备份、故障处置及人工替代流程。除另有明确约定外，开源软件的提供不包含特定服务可用率、全天候响应或代学校运维的承诺。
3. 对账号冒用、凭据泄露或违法操作，实际运营者可以在必要范围内暂停相应账号或连接、保存必要核查记录并通知相关管理人员；应尽量避免影响无关班级，并在风险解除后提供合理恢复途径。
4. 解除配对、撤销授权或停止服务不当然删除学校服务器的历史记录与备份，也不当然恢复设备原有自启动设置。有关记录的处理和删除请求依隐私协议及法律执行；有权人员应核实本机剩余任务及设置。
5. NPTG、学校和运营者分别对其实际行为承担依法应承担的责任。本协议不免除依法不可排除的责任，不减损个人信息权益，也不要求用户承担与自身无关的全部第三方损失。
