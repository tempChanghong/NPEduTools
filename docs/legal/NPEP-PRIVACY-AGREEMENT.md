# NOVARK POWER EDUCATION PLUS计划隐私协议

版本：1.0  
更新日期：2026年10月4日  
生效日期：2026年10月4日

星火动力技术组（NOVARK POWER Technical Group，简称 **NPTG**）重视师生及设备使用者的隐私。本协议说明 NOVARK POWER EDUCATION PLUS（简称 **NPEP**）互联功能涉及的信息、处理目的、保存方式以及您的权利。

本协议适用于 NPEduTools、NPClassworks 与 NPClassworksKV 在 NPEP 中的配对、状态上报、远程教学操作、通知及噪音监测，不代替学校对其他账号、作业、考勤等业务的完整隐私告知。

## 一、请先了解这四件事

1. **噪音监测会在本机短暂处理麦克风样本，计算统计；不保存原音频、不上传录音、不转写谈话，也不识别说话人。**
2. **NPEduTools、NPClassworks及NPEP计划不会向学校或其他机构私有部署的云端上传任何原音频数据或摄像头采集信息。** 原音频包括录音片段及可还原声音的音频数据；摄像头采集信息包括摄像头采集的图像、视频及相关采集内容。
3. **NPEduTools、NPClassworks及NPEP计划永远不会向星火动力云端服务器上传任何原音频数据或摄像头采集信息。** 普通协议更新不能削弱此承诺。
4. **统计并不当然等于匿名信息。** 设备、班级、时间及管理记录结合后可能与个人相关，应按实际可识别性和使用场景受到保护。技术配对及 Windows 权限授权不等于教室内所有人员同意个人信息处理。

## 二、谁负责处理信息

1. NPTG 是软件开发及本协议制定方。学校通常决定教学管理目的、适用班级、使用时间及可访问人员；实际部署运营者运行您选择的服务器，处理其服务中的数据。实际角色以谁决定处理目的和方式、谁受托处理为准，不能只依产品名称判断。
2. 使用学校私有部署时，信息接收方通常是学校及其指定运营者，**不会仅因使用 NPTG 开发的软件而自动发送一份给 NPTG**。NPTG 不因开发软件而获得该服务器的数据访问权。
3. 学校委托他人托管、运维或备份时，应依法约定处理范围、期限、安全措施和责任，并监督受托处理。NPTG 如实际参与运营、共同处理或受托处理，也应依法承担相应义务。
4. 学校及运营者应在开通、配对和隐私说明中提供实际主体及联系方式，并告知服务器位置、保存期限和其他部署特有的信息。实际部署的信息应在提供服务前明确告知。

## 三、处理哪些信息、为什么处理

| 信息类别 | 主要内容与用途 | 处理位置及接收方 |
| --- | --- | --- |
| 配对与绑定信息 | 您选择的服务地址、设备名称、安装与设备标识、学校／班级／大屏归属、配对码及连接凭据，用于确定归属、认证连接和撤销授权。 | 本机与所选学校服务器；由学校及运营者按权限管理。 |
| 设备运行状态 | NPEduTools 版本、日常／考试模式、切换阶段、自动录课启停与录制阶段、教学软件桥接连接状态，用于判断设备是否可用和操作是否完成。 | 本机产生，并上报学校服务器。状态上报不包含录制文件内容、完整进程列表或本机全部文件。 |
| 远程操作与考试配置 | 必要的考试计划、操作类型、请求标识、发起管理账号、时间、执行步骤、结果及错误原因，用于投递配置、执行和核查管理操作。 | 学校服务器与绑定设备；有权管理人员按角色查看。 |
| 通知与回执 | 通知正文、适用范围、等级、投递及显示／关闭结果，用于显示学校通知和核对投递过程。 | 学校服务器下发至本机，设备回传必要回执。回执不识别实际阅读者。 |
| 噪音状态与统计 | 会话标识、监测起止时间、麦克风名称、信号电平、采样质量、有效时长、覆盖率、能量平均值、峰值、削波比例及算法标识，用于展示状态、生成报告和诊断采样问题。 | 麦克风样本只在本机处理；状态及统计发送至学校服务器，不包含音频或谈话内容。 |
| 定时策略及展示状态 | 适用班级、策略版本、时间段、学校时间有效状态、执行／跳过结果、保护状态、页面在线与返回展示状态，用于执行定时任务和协调网页展示。 | 学校服务器与绑定设备。页面状态用于该功能，不等于收集浏览器完整访问历史。 |
| 连接与安全记录 | 请求时间、网络来源地址、接口访问、认证或运行错误及必要管理记录，用于服务运行、安全排查和追溯。 | 实际运营者的服务器、反向代理及相关日志系统；保存和访问范围由运营者依法说明。 |
| 本机配置与诊断文件 | 程序位置、选定麦克风、显示偏好、必要缓存及您手动导出的诊断信息，用于本机运行与排错。 | 主要保存在本机；导出诊断包不会自动上传，主动分享前应检查文件内容。 |

配对凭据属于安全信息，不应向无关人员公开。学校账号资料可能与操作记录关联；学校应向账号使用者说明相应处理。麦克风名称可能反映设备型号，监测并不因此需要上报本机全部硬件清单。

噪音统计的 dBFS 数值属于数字信号电平，不是校准声压级，不与旧网页评分当然等价，也不应作为个人处分或健康判断的唯一依据。

## 四、麦克风、录制与摄像头的边界

1. 只有在手动监测或适用的定时任务执行时，噪音功能才需要使用已配置的麦克风。原生监测接管后，NPClassworks 网页不为同一监测用途重复采集。尚未使用原生接管的网页监测也在浏览器本地分析声音，不上传原音频。
2. 样本在本机内存中短暂用于计算后不作为录音保存；统计报告和故障恢复所需的统计缓存可以保留。不能将“不保存录音”理解为“麦克风没有工作”。
3. 微课录制是不同功能：可以将屏幕、麦克风或系统声音保存成**本机视频文件**，其中可能含有师生声音和其他个人信息。NPEP 不自动上传这些视频或其中的音频。文件保存目录和后续处置由有权使用者管理，录制前仍应依法告知、取得必要授权或同意。
4. NPEP 不提供摄像头采集上传功能。安装软件、完成配对或使用噪音监测均不构成摄像头访问授权。
5. 定时任务可以在网页关闭或窗口隐藏后继续运行，受保护任务可在异常退出后恢复。需要停止时，应由有权人员通过本机或学校管理入口停止并核实；仅隐藏页面、断网或暂停上报不等于停止麦克风。

## 五、处理依据与未成年人保护

1. 处理信息应具有明确、合理且必要的目的及适用的合法依据。基于同意处理时，应使相关个人充分知情并能够自愿、明确地作出选择；依法需要单独同意或其他形式的同意时，应另行取得。
2. 学校应向受影响教师、学生及其他人员说明监测或录制用途、时间范围、接收方及权利渠道，不得以“管理员已经配对”替代该告知，也不得把设备管理权限视为任意处理个人信息的依据。
3. 处理不满十四周岁未成年人的个人信息时，应依法取得父母或其他监护人同意，并制定专门的处理规则。涉及其他敏感个人信息时，应满足特定目的、充分必要及严格保护等要求。对其他未成年人也应采取与其年龄及场景相适应的保护措施。
4. 软件不以谈话转写、身份识别或个人声音画像为噪音监测目的。学校不得因统计不包含录音，就推定所有相关信息均已匿名化或免除未成年人保护义务。

## 六、保存位置与期限

| 信息 | 保存与清理规则 |
| --- | --- |
| 麦克风原始样本 | 仅在本机计算过程中短暂处理，不作为噪音录音保存，不进入云端统计报告或备份。 |
| 本机待补传噪音统计 | 最多200份；超过结束时间14天的待传报告在队列处理时清理，收到服务器确认后移除已接收报告。不是每日固定时刻立即清除。 |
| 学校服务器噪音报告 | 常规报告保留范围为服务器接收后的最近30天、每设备最多200份；访问或上报处理时清理过期及超限报告。该规则不等于日志和备份同时清除。 |
| 配对凭据与本机配置 | 有效连接期间用于认证和运行；解除配对会清除对应本机连接凭据。其他配置、缓存及文件应按相应功能管理，不能推定全部同时删除。 |
| 本机录制文件及手动导出文件 | 由有权使用者保存和清理；卸载软件不当然删除这些文件。学校应按用途规定必要期限和访问权限。 |
| 学校账号、绑定历史、操作记录、通知及其他服务器缓存 | 由学校和实际运营者根据目的与法定义务确定最短必要期限，并在部署隐私说明中列明；不能将噪音报告的30天规则套用于所有数据。 |
| 服务日志及备份 | 由实际运营者分别说明保存期限、清理周期和访问权限。备份清理可能晚于在线数据；不得因此重新用于日常业务或扩大用途。 |

服务器位置由您选择的服务提供商决定，私有部署不当然意味着服务器位于中国境内。涉及向境外提供个人信息时，实际处理者应履行适用的告知、同意及跨境提供义务，不能依本协议推定已完成。

解除配对、管理员撤销、卸载或关闭网页不会自动删除学校服务器中的全部历史记录。依法应删除的信息应予删除；因法定保存义务或技术原因暂时不能删除时，应依法限制相应处理并采取保护措施。

## 七、共享、委托及可选第三方服务

1. 信息仅应在完成配对、教学管理、统计展示、安全维护及必要支持的范围内，向有权限的学校人员或受托运营、托管、备份人员提供。实际运营者应限制访问和用途，不得将本协议当作出售个人信息、广告画像或通用模型训练的授权。
2. 不因安装或配对就把学校数据发送给 NPTG。访问官网、代码托管平台或第三方教学软件时，相应外部服务可能独立处理访问数据，应同时查阅其规则。
3. 部署方启用可选访问分析、错误监测或外部日志服务前，应说明实际提供方、数据字段、目的、保存期限及服务器位置，履行依法需要的同意或其他手续。**本协议不概括授权任意第三方分析工具，也不允许其突破原音频及摄像头采集信息的上传承诺。**
4. 法律要求提供信息时，实际处理者应核实要求并限于必要范围处理；应依法通知个人的，应履行通知义务。

## 八、安全保护

1. NPEduTools 使用 Windows 用户范围的数据保护机制加密保存本机配对凭据。这不意味着所有配置、视频、统计文件、日志和服务器备份都经过加密。
2. 正式部署应使用可信 HTTPS，并配合账号权限、设备授权、必要日志及服务器保护措施。软件允许 HTTP 连接，但 HTTP 不提供同等传输加密保障，运营者应明确评估并说明相应风险。
3. 学校应保护管理密码和账号，及时撤销过期权限；运营者应采取与风险相适应的访问控制、备份及安全措施。发生个人信息安全事件时，实际处理者应依法采取补救并履行通知、报告等义务。
4. 反馈问题时请勿在公开 Issue 或群聊中发布访问令牌、配对凭据、学生资料或录制内容。手动导出的诊断文件也应先检查，再通过可信的私密渠道提交。

## 九、您的选择与权利

1. 有权设备管理人员可停止手动监测、管理录制安排、暂停学校连接或解除配对；学校管理员可调整策略及撤销设备授权。定时保护可能要求管理验证，学校应提供可用的教师／管理人员处理途径。
2. 暂停连接主要影响后续通信，不当然停止本机任务。解除配对及撤销授权也不等于自动删除既有服务器记录。请根据实际目标分别执行停止、解除或数据权利请求。
3. 您可依法向实际个人信息处理者请求了解、查阅、复制、更正、补充、删除相关个人信息，限制或拒绝相应处理，并请求解释处理规则。基于同意的处理，您可依法撤回同意；撤回不影响此前合法处理的效力。
4. 涉及学校服务器的信息，请联系学校或部署运营者；涉及 NPTG 实际处理的信息，请联系 NPTG。接收方应在必要范围内核验请求身份、及时依法答复并说明处理结果或拒绝理由，不应索取无关个人信息。
5. 若监测或录制涉及您，但您没有设备管理密码，仍可通过学校的隐私联系渠道提出请求。没有设备操作权限不剥夺您的法定个人信息权利；您也可依法向有关主管部门投诉或寻求司法救济。

## 十、更新与联系方式

我们会为本协议更新标明版本及生效日期，对目的、类别、接收方或权利等重大变化作出显著提示。依法需要重新取得同意的，应另行取得，不以继续使用或旧配对自动代替。本协议更新不削弱不向星火动力云端上传原音频及摄像头采集信息的长期承诺。
