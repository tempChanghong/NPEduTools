## 一、协议范围与开源许可

1. NPEduTools 是用于教学大屏及 Windows 设备的教育辅助软件，提供工具启动、教学软件联动、微课录制、噪音监测及学校互联等功能。可用功能以安装版本、实际配置和运行环境为准。
2. NPEduTools 源代码依照 GNU GPL 第三版（GPL-3.0）许可提供。软件包中的第三方组件适用各自的许可证。本协议不限制这些许可证授予的使用、研究、复制、修改和再分发权利；涉及开源授权的冲突，以相应许可证为准。
3. 开源许可不当然授予以 NPTG 名义提供服务、声称获得官方认可或冒用品牌的权利。依法进行事实说明、来源标注及其他合法使用不受本条禁止。
4. 本协议不要求您启用学校互联。启用 NOVARK POWER EDUCATION PLUS（简称 **NPEP**）时，还应阅读[NPEP计划服务协议](NPEP-SERVICE-AGREEMENT.md)及[NPEP计划隐私协议](NPEP-PRIVACY-AGREEMENT.md)。第三方软件、网站及您选择的服务器另有适用规则。

## 二、安装、权限与软件联动

1. 请从可信来源取得软件，并根据设备环境配置程序位置、插件、麦克风和文件保存目录。我们不会因您安装本软件而取得您设备或学校服务器的当然管理权。
2. **软件启动会请求 Windows 管理员权限。** 此权限用于已提供的本机管理功能，包括管理教学软件运行状态、核验和调整相关登录自启动设置。请确认安装来源和 Windows 授权窗口中的程序身份。
3. 配置 ClassIsland、ExamAware2、SecRandom 等联动后，软件可通过其支持的接口执行启动、正常退出或相应教学操作。实际效果受软件版本、插件连接和 Windows 状态影响。
4. **切换日常／考试模式可能改变相关软件随 Windows 登录启动的设置。** 模式切换也可能启动考试软件、退出日常教学软件并暂停自动录课。请在执行前了解所选操作；以实际完成结果和界面提示为准。
5. 不应将“请求已发送”或“设置已保存”视为软件已经运行、放映已经开始或所有设置已经生效。出现部分完成、失败或状态不明时，应核实设备再继续教学活动。

## 三、录制、麦克风与本机数据

1. 微课录制可捕获屏幕及您选择的麦克风、系统声音，并将视频保存到本机目录。文件可能包含授课内容、人员声音、姓名或屏幕中的其他个人信息。启用手动或自动录制前，请确认您有权录制相关内容，并依法向受影响人员告知、取得必要授权或同意。
2. 噪音监测在本机短暂处理麦克风样本，计算信号电平和统计结果；该功能不保存原音频，不转写谈话内容，也不识别说话人的身份。**这与微课录制在本机保存含声音视频是两种不同功能。**
3. 噪音读数属于数字信号电平，不是经过校准的教室实际声压级。请勿仅凭该数值判断某个人的行为、健康状况或责任。
4. **NPEduTools、NPClassworks及NPEP计划不会向学校或其他机构私有部署的云端上传任何原音频数据或摄像头采集信息。NPEduTools、NPClassworks及NPEP计划永远不会向星火动力云端服务器上传任何原音频数据或摄像头采集信息。** 学校互联上传噪音统计并不意味着上传录音；本机录制文件也不通过 NPEP 自动上传。
5. 本机配置、视频及您导出的文件由您管理。自行使用其他工具分享或上传文件前，请核实接收方及相应权限；不要在公开反馈中附上学生个人信息、配对凭据或含私人内容的录制文件。

## 四、学校互联

1. 学校互联连接您选择的服务提供商地址。学校或实际部署运营者负责该服务的组织管理、账号权限和数据处理；NPTG 作为软件开发方，不因提供开源软件而自动成为该部署的运营者。
2. **完成有权管理人员发起或确认的配对，即授权该学校在已提供的功能范围内管理绑定设备。** 授权操作可能包括日常／考试环境切换、考试配置与放映、学校通知、噪音监测及定时策略。具体范围见 NPEP 服务协议，不包含任意远程命令执行或任意文件读取授权。
3. 普通及以上等级的学校通知可使用置顶窗口和全屏变暗遮罩，并需要手动关闭。后台监测、定时保护及远程请求不会因为关闭网页或隐藏主窗口而当然终止。
4. 只有具备组织管理权限的人员才应配对公共大屏、修改学校策略或管理保护密码。配对不能替代对教室内师生的个人信息告知或依法需要取得的同意。
5. 您可通过学校互联入口管理连接；学校管理员可撤销设备授权。暂停上报、断开网络和解除配对的效果不同，不能将其中任一项推定为本机所有任务均已停止。

## 五、合理使用与安全

1. 请在合法且获得授权的范围内使用软件，不得利用软件进行隐蔽录制、侵犯隐私、伪造管理身份、窃取凭据或破坏他人的设备与服务。
2. 学校及设备管理人员应保护管理员账号、配对信息和管理密码，及时撤销离校、转班或更换设备后的不必要授权。合法的软件研究、调试与遵守许可证的修改不属于本协议禁止的行为。
3. 正式部署应使用可信的 HTTPS 服务。软件兼容 HTTP 地址，但 HTTP 不能提供传输加密保护；选择此方式的部署方应评估网络风险，不能将其当作与 HTTPS 等同的安全连接。
4. 学校通知、录课和考试环境控制是辅助功能。重要考试、紧急事项及重要文件应保留现场核实、人工处置和适当备份措施。
