## 1. 当前目标

下一项工作聚焦 Microsoft PowerPoint 放映时的触摸单击辅助。WPS 按用户要求不接入；ClassIsland 自然语言换课、LLM 接入、管理员自启动管理暂缓，通用场景引擎不作为本功能的前置依赖。

用户已确认：目标设备有触摸屏，使用 Microsoft Office 2024，并非当前开发电脑。交互为手指轻点放映画面的非交互区域，推进一次正常放映操作；有逐步动画时先推进动画，动画结束后才换到下一张。鼠标左键保持原行为。不是每次触摸都强制跳到下一张幻灯片。

实现为 NPEduTools 内置的 PresentationAssist 模块，先验证外部辅助方案，不预设需要 ClassIsland 插件、PowerPoint 加载项或 Python 运行环境。

## 2. 本地参考代码的发现

参考：[PowerPoint Touch Assist](PowerPoint-Touch-Assist/README.md)，核心代码为 [func.py](PowerPoint-Touch-Assist/func.py)。本地参考目录含 CC0 1.0 LICENSE；实现时保留来源说明。

其流程为：监听全局鼠标 → 保存按下位置 → 松开时判断位置未变、未命中预设边缘、存在放映标题窗口 → 发送一次空格。

| 源码行为 | 对本项目的影响 |
| --- | --- |
| 只检查是否存在匹配标题的窗口 | 不能证明点击发生在 PowerPoint 上；其他前台程序可能收到空格 |
| 不区分真实鼠标和触摸生成的鼠标事件 | PowerPoint 已处理的点击可能又被补发空格，产生二次推进 |
| 按下和松开坐标必须完全相同 | 轻微手指抖动会漏判；拖动后回到原点又可能误判 |
| 只用主屏尺寸和固定 95 倍缩放的边缘区域 | 无法可靠支持副屏、负坐标、不同 DPI、窗口化和弹出菜单 |
| 使用计数器猜测菜单何时关闭 | 无法可靠识别菜单、超链接、视频控制和书写状态 |
| 配置与入口处于重构中的不一致状态 | 不适合作为可以直接打包运行的完整依赖 |

具体不一致包括：main.py 引用目录中不存在的 conf_file；func.py 使用不存在的 config.dpi_dict，读取 PPT_Title/use_regex，而现有配置使用 program_title 且没有 use_regex。正则分支读取的是 DPI；bool('0') 也不会得到 False。这些是本地快照的发现，不代表上游其他版本的状态。

结论：参考其功能边界，在 C# 中独立实现；不直接包裹运行这份 Python 快照。

## 3. 先验证的两个技术问题

### 输入是否能可靠识别

Windows 文档提供鼠标消息中区分触摸、笔和鼠标的附加信息约定，但它不等于已经证明目标大屏驱动向外部低级鼠标钩子报告了完整触摸流。[微软输入文档](https://learn.microsoft.com/en-us/windows/win32/tablet/system-events-and-mouse-messages)

先以只观察、不拦截、不发送按键的诊断模式，记录触摸来源标记、按下/移动/松开、命中的窗口与放映状态。日志只采集本次测试所需字段，不记录文稿正文或其他应用的键盘输入。

必须确认：真实触摸能否与鼠标区分、是否同时产生 PowerPoint 原生触摸处理和兼容鼠标处理、长按/拖动/多指是否可识别。低级鼠标流本身不足以证明完整多指状态；不能据此承诺多指安全。无法可靠区分的设备应显示不支持，而非将所有鼠标点击当作触摸。

### 如何保证一次触摸只推进一次

不能采用“原始触摸照常传给 PowerPoint，再无条件补发空格”。也不能把低级鼠标钩子吞掉兼容鼠标消息，等同于已经吞掉原生触摸消息。

此外，COM 的 SlideShowView.Next 文档定义为显示下一张幻灯片，不能直接假定它等价于空格的逐步动画行为。GetClickIndex、GetClickCount、GotoClick 可用于研究点击序列，但触发器动画、媒体与自动动画仍需验证。[Next](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.slideshowview.next)、[GetClickIndex](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.slideshowview.getclickindex)、[GotoClick](https://learn.microsoft.com/en-us/office/vba/api/powerpoint.slideshowview.gotoclick)

原型比较以下方案后再确定实现：

1. 外部监听并补偿：只有能证明原生输入未造成放映操作，且能排除交互对象时才可用。仅短暂等待后页码未变不能作为证据，动画可能推进而页码不变。
2. 限定区域内由辅助层接收完整触摸序列，再执行一次经过验证的推进操作。需要验证透明窗口对鼠标、菜单、超链接和书写的影响，不能假定所有输入都能无损转交。
3. 外部方案无法满足一次推进及原交互保留时，再评估 PowerPoint 加载项或明确限定的触控区，并记录功能取舍。

这是本功能的首个实施关卡。未通过前，不把全屏单击辅助作为已可用功能。

## 4. 运行规则

- 默认关闭，由用户开启；界面提供“已关闭 / 等待放映 / 辅助中 / 已暂停（原因）”及随时暂停入口。
- 定位实际 Microsoft PowerPoint 放映窗口，核对进程归属、窗口句柄及命中位置；标题只用于诊断。不会向 WPS 或编辑窗口发送操作。
- 初版限定一个明确的全屏放映目标。双屏演讲者模式只在目标映射已验证时启用，否则暂停并说明原因。
- 触摸按下和松开必须属于同一有效目标；手势期间焦点、窗口、文稿或放映会话变化即取消。
- 轻点识别使用持续时间和整个轨迹的最大位移，位移按目标显示器 DPI 换算；阈值通过实机校准。
- 拖动、长按、书写、菜单、交互对象及无法确定状态时不补发推进；如果原型不能可靠识别，缩小支持范围或暂停辅助。
- 推进前再次检查目标。发生超时或结果不确定时不自动重试、不积压触摸请求，避免恢复连接后连续跳页。
- 不改变 PPT 文件、动画配置、用户的放映设置，不自动启动 PowerPoint 或提权。

## 5. 与现有工程的关系

建议的逻辑分工如下，首个原型不必为每个部分建立单独项目：

| 部分 | 职责 |
| --- | --- |
| PowerPoint 适配层 | 连接已运行的实例，定位放映窗口，读取放映与指针状态，执行已验证的推进操作 |
| 输入观察与轻点识别 | 收集输入来源及轨迹，将其转换为候选轻点；不在回调中调用 Office |
| PresentationAssist | 关联手势与放映目标，检查是否允许推进，处理暂停与取消 |
| Host | 管理辅助模块生命周期、开关与状态；不依赖 ClassIsland 是否在线 |
| App | 提供开关、暂停和简洁状态，课程状态视图继续作为已有调试入口 |

低级鼠标钩子需要消息循环，回调应迅速返回；不能在钩子回调中执行 COM、磁盘操作或等待 IPC。[LowLevelMouseProc 文档](https://learn.microsoft.com/en-us/windows/win32/winmsg/lowlevelmouseproc)

Office 自动化在专用 STA 上执行。由于 COM 阻塞不能靠取消等待强制结束，生产接入优先采用受 Host 管理的独立 PowerPoint 工作进程；超时后只清理自有工作进程，不终止 PowerPoint。沿用现有工作进程生命周期经验，不复用 ClassIsland 的协议或业务模型。

关闭设置窗口后是否继续辅助遵循现有 Host 常驻模式；停止后台时必须停用监听及辅助层。辅助进程异常退出后恢复 PowerPoint 的正常输入路径，不自动重放推进请求。

## 6. 实施顺序与验收

### P0：输入与放映验证原型

先建立只读诊断工具，在开发机验证已运行 PowerPoint 的放映窗口识别，在目标 Office 2024 触摸设备采集真实输入来源。随后使用专门测试文稿，对比空白页、逐步动画、触发器动画、菜单、超链接、视频和书写时的行为。测试文稿与用户日常文稿分开。

产出输入路径、推进方案、支持范围及失败场景记录。此阶段不接 LLM、不改 ClassIsland、不做通用场景引擎。

### P1：最小可用辅助

在 P0 已证明可行的范围内接入开关、状态、暂停与生命周期管理。只增加轻点识别及取消/去重行为的必要自动化测试；真实 PowerPoint 和触屏测试不能被模拟测试替代。

### P2：设备兼容验证

| 验证场景 | 通过标准 |
| --- | --- |
| 连续轻点与正常鼠标点击 | 每次有效触摸只推进一次，普通鼠标不额外推进 |
| 按次动画、自动动画、快速连续轻点 | 不跳过应保留的动画，不重放积压动作 |
| 拖动后回到原点、长按、笔、多指 | 不误推进；无法判断时明确暂停或声明不支持 |
| 工具栏、右键菜单、超链接、视频、书写 | 原操作正常，辅助不额外推进 |
| Alt+Tab、窗口遮挡、退出放映、切换文稿 | 立即取消候选动作，不向其他应用发送输入 |
| 副屏、负坐标、不同 DPI、演讲者视图 | 只在已验证的实际放映区域生效；不支持的组合暂停 |
| 最后一页、黑屏/白屏、自动计时 | 不额外退出、重复跳转或改变原配置 |
| 关闭辅助、停止 Host、工作进程故障 | 输入恢复正常，PowerPoint 保持运行，未完成操作不重试 |
