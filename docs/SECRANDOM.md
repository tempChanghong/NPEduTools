# 课堂点名：SecRandom V3

本功能已包含在 v1.0.0 中。InDev 20261002 已发布附件不包含它；具体文件与限制见[版本说明](releases/README.md)。

## 怎么用

1. 安装 SecRandom V3，并在其中完成首次设置、配置名单及闪抽规则。
2. 从 NPEduTools 主窗口左侧或快捷侧边栏打开 **课堂点名 · SecRandom**。
3. 点击 **从 URL 登记查找**，核对路径后 **保存位置**；也可以浏览选择 `SecRandomLauncher.exe` 或 `SecRandom.Desktop.exe`。这一步只读登记，不修改 Windows 协议。
4. 点击 **打开点名页**。已运行时使用现有实例，未运行时先启动。**检查接口**只检查已经运行的软件，不会自行启动。
5. 按需显示／隐藏浮窗；确认名单正确后点击 **闪抽一人**。这是一次真实抽取，会使用 SecRandom 当前闪抽配置并写入其历史，执行结果区显示回执和抽中的人。

不需要额外桥接插件。打开点名页、浮窗、闪抽等实际命令通过本机管道发送；`secrandom://` 的 Windows 登记仅用来寻找程序位置。检查接口通过无副作用的协议探针完成，不读取名单。

常驻侧栏的设置分隔线上方有 **“抽”** 按钮，无需展开面板即可闪抽。未配置时打开配置页并提示保存位置；配置完毕后，未运行的 SecRandom 会先启动，等待接口就绪后执行一次闪抽。执行期间显示省略号并暂时禁用，成功时由 SecRandom 按自己的通知设置展示结果，按钮提示保留上次抽中的姓名。异常或结果待核实时打开执行记录，不自动补抽。

## 看懂状态

| 提示 | 含义与操作 |
| --- | --- |
| 接口已就绪 | 上次检查时可通信；不是实时订阅，软件退出后需重新检查 |
| 正在执行 | 后台正在等待回执，避免重复点击；关闭此窗口不取消操作 |
| 已完成 | 收到了对应业务成功回执；收到请求不等于抽取完成 |
| 未完成 | 请求没有发送，或 SecRandom 明确拒绝；按提示处理名单、首次设置或授权 |
| 结果待核实 | 请求可能已执行但没有可靠回执；先查看 SecRandom 窗口及历史，再点击“已核实，解除待核实状态” |

解除待核实状态只允许后续新操作，**不会重发旧请求**。自动重试仅用于冷启动期间的只读探针；闪抽和窗口操作不自动重发。

## 数据与范围

SecRandom 维护名单、随机算法和抽取历史。本阶段 NPEduTools 不读取整份名单、不修改 SecRandom 设置，不通过 NPEP 上传抽取结果，也不提供学校远程点名。

NPEduTools 的本地 Host 配置目录中有 `secrandom.json`，保存程序路径、配置修订及最多 32 条操作回执；成功闪抽回执包含编号、姓名和性别。它是本地操作恢复记录，**并非完全不留学生数据**。排错时不要公开原始配置文件；完整历史仍在 SecRandom。

程序位置必须指向本机 V3；连接时会核对管道服务端的用户、Windows 会话和程序路径。管理员 NPEduTools 客户端连接普通权限 SecRandom 已在开发电脑验证；跨用户、UIAccess、班级大屏组合尚未验收。新启动的实例继承 Host 的权限，已运行的实例不被重启或提权。

SecRandom 若要求密码、课程许可或完整性确认，请在其界面正常处理。本接入保留这些保护流程。
