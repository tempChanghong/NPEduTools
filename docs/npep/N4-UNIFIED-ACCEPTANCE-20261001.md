## 操作入口

在 NPEduTools 根目录执行，Windows PowerShell 5.1 可用：

```powershell
# 只检查依赖与契约；加开关也只核对对应工具，不启动它们。
./scripts/test-npep-n4.ps1 -CheckOnly -Browser -Database

# 四组代码测试；不执行浏览器或数据库验收。
./scripts/test-npep-n4.ps1

# 完整自动验收；模拟音频，原生临时 PostgreSQL，不使用 Docker。
./scripts/test-npep-n4.ps1 -Browser -Database
```

默认寻找同级 NPClassworks 和 NPClassworksKV；非同级目录用 `-WebRoot` 和 `-BackendRoot` 指定。不会依赖调用时的 Webstorm／CodeProjects 目录名。旧的 `test-npep-noise.ps1` 和 `test-npep-noise-schedules.ps1` 继续保留，用于只查某一段。

预检核对 Windows、当前 Node/.NET、项目身份与依赖、七组同 SHA-256 的共享契约、三项 N4 迁移文件。选择浏览器时检查已安装 Chromium；选择数据库时检查原生 PostgreSQL 工具。**文件存在不等于迁移已应用**：预检不读取 `.env.debug`／生产配置，也不连接已有数据库。

## 结果如何阅读

每次生成独立的 `.artifacts/npep-n4/<时间与随机编号>/result.json`，同目录有各阶段日志和本次 .NET TRX。

| 状态 | 含义 |
| --- | --- |
| `CHECKED` | 仅预检完成，没有运行测试 |
| `PASSED` | 本次请求的自动阶段通过，不代表设备或发布验收通过 |
| `FAILED` | 预检或阶段失败，后续阶段没有继续执行 |
| `RUNNING` | 未完整结束，可能仍在运行或已中断，不能当作通过 |
| `NOT_REQUESTED` | 未选择对应浏览器／数据库阶段 |
| `NOT_RUN` | 尚未执行，例如只预检或前一阶段失败 |

清单保留三仓 HEAD、工作区是否包含未提交改动、工具版本和契约指纹。HEAD 不包含当前未提交功能，不能据此宣称存在一个可重建的正式发布提交组合。

无论自动阶段结果如何，`releaseReady` 都保持 `false`；人工、生产验收及部署分别为 `NOT_RUN`。它们需要独立记录，不能由脚本测试结果替代。重复测试不会累加成产品质量分数，Node 测试文件在每仓清单内去重。

## 隔离范围

- 子进程只继承系统路径、用户缓存等运行必需项；排除调用者的 DATABASE_URL、PG 连接变量、学校凭据和 VITE 配置，dotenv 指向本次空文件。
- 浏览器复用已有两套隔离页面，不登录实际学校或申请麦克风。
- 数据库阶段复用原生临时集群脚本，只启动本次专有实例；成功后清理，不访问 Windows 开发数据库服务。
- 不构建正常 App／发行包，不修改管理员任务、开机自启动或真实设备配置。

入口代码：`scripts/test-npep-n4.ps1`、`scripts/test-npep-n4.mjs`；入口自身的失败传播、契约不一致和环境隔离回归：`tests/n4AcceptanceRunner.test.mjs`。
