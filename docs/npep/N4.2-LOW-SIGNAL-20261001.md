# N4.2 收尾：低电平与数值下限提示

2026-10-01 · **实现与自动回归完成；用户明确跳过新界面的人工复测。仅本地修改。**

## 任务卡

目标：安静时到达 -160 下限的读数不冒充精确值，有效采样不冒充麦克风输入正常。

包含：桌面、原生网页、网页／后台共用报告组件的显示；对应回归及统一测试入口。排程、声压校准、驱动设置与发布不在本次范围。

验收：极弱非零输入有明确提示；说话恢复后提示消失；全零、缺样与采样异常继续区分；离线不展示旧读数或旧提示；报告平均值与峰值保留下限含义；统计能量计算不受显示规则影响。

## 显示规则

| 条件 | 桌面与网页表现 |
| --- | --- |
| 电平达到数值下限 -160 | `≤ -160.0`，说明更低信号不再显示精确读数 |
| 有效采样且电平 ≤ -100 | “输入接近静音”，建议通过说话确认输入响应；不直接断定降噪或硬件故障 |
| 有效采样且电平 > -100 | “采样有效” |
| 全零采样 | 无数字电平，保留“全零信号，检查静音” |
| 无效帧／缺样／失联 | 保留各自状态，不用低电平代替异常 |
| 已停止／采集结束 | 网页与桌面质量标签显示“已结束” |

- -100 沿用现有趋势图下界，仅用于输入提示，不是教室声压阈值。不会据此丢弃采样或降低覆盖率。
- 报告中的平均／峰值若达到下限，显示 `≤ -160.0 dBFS（数值下限）`。
- 数学计算、0.6 网络协议、数据库与质量枚举保持原语义；`Good` 表示数据可计算，界面结合电平提示输入强弱。历史报告也使用同一格式。
