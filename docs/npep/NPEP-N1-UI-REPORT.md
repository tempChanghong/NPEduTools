# NPEP N1 设置页与后台连接管理

日期：2026-09-21。设备分支：`codex/npep-n1-ui`，基线 `373c5f8`。本轮完成设备设置页、Host 连接管理，并与 NPClassworks 学校管理页协作验收。未推送、合并主分支、发版或部署生产。

## 使用入口

**NPEduTools → 设置 → 学校互联**。

1. 向学校管理员取得 HTTPS 服务地址，点击“检查服务”。检查成功后核对地址及实例信息，再勾选确认。
2. 输入方便辨认的设备名称，点击“创建配对码”。只把短码提供给本校管理员。
3. 管理员进入 **NPClassworks → 学校管理 → 大屏设备 → 打开 NPEP 设备互联**，解析短码并批准对应大屏。
4. NPEduTools 自动读取审批。现场核对学校、班级、大屏及共享内容后，勾选确认并点击“确认连接”。同名归属可展开核对编号与管理员确认。
5. 连接后显示最近一次学校服务接收时间。窗口收起不停止上报；“暂停上报”保留配对并跨重启生效，“恢复上报”恢复连接。
6. “解除绑定”停止上报并清除本机凭据。若显示只完成本机解绑，仍需管理员检查远端登记，不能视作远端撤销成功。

权限仍只有 `device.status`。页面说明共享范围，不上传屏幕、声音、录课文件、科目、完整课表或任意本地路径，也不接收通知、模式切换和录制控制指令。

## 运行方式

凭据由 **Host 独占管理**。WPF 只通过既有当前用户、本会话命名管道读取快照及提交有限操作，不持有 secret，也不自行发云端请求。新增本地请求为 `npep.status` 和 `npep.command`；命令字段经过白名单与类型验证，不接受任意 URL 路径、HTTP body、shell 或控制能力。

长网络操作先在本地返回 Accepted，再由后台完成。页面用 Busy、操作编号与状态修订判断进度；重复请求 ID 不会重复执行，过时修订不能覆盖新状态。状态读取不等待网络请求完成，关闭页面不会丢失已受理的确认操作。

Host 启动时读取 DPAPI 文件：未配对不联网；PENDING 仅轮询管理员审批；APPROVED 等待现场确认；ACTIVE 且未暂停时恢复原授权、建立会话并上报。CREATING/CONFIRMING 提供恢复原操作入口；SUSPENDED 不自动重新配对或抢回会话。停止 Host 会取消在途网络请求、等待任务结束并释放凭据目录锁。

上报与暂停、解绑共用串行执行门。后台请求可被现场操作取消，不会积压旧心跳；下一次发送前重新读取缓存与检查单调采样年龄。状态成功上报后间隔 20 秒，网络失败退避；TLS 安全连接失败显示专门原因并停止自动重试，可在问题解决后手动重连。收到撤销、实例/归属变化或会话取代时遵守前一阶段的停用规则。

暂停表示保留配对但不请求服务；学校侧 ONLINE 有 60 秒观测窗口，不会在本机按下暂停的瞬间凭空变为离线。UI 最近接收时间由服务端回执给出，按本机时区显示；授权和新鲜度不使用 ClassIsland 校准后的学校时间。

真实 Runtime 验收包含：管理员批准后尚不报告；本机确认后自动报告；暂停落盘；释放并重建 Runtime 后暂停状态仍保留且不联网；恢复时建立新 Host 会话；管理员撤销后停止；本机清理如实报告 LOCAL_ONLY。其状态来源为明确标记的隔离缓存夹具，没有改变真实课堂模式或启动录制。

真实网络验收使用专用测试 handler 信任短期测试根，并校验证书链和主机名。正式 Host 和 WPF 没有测试 CA、跳过 TLS 或任意证书开关。生产 WPF 实窗拒绝同一未受信任证书；其最终中文错误文案又经过单元测试和最终构建检查。不能把隔离 Runtime 成功等同于正式 WPF 与真实学校可信 TLS 的人工双端配对已经验收。

学校管理网页由另一任务负责，数字来源为[管理页验收记录](../../../NPClassworks/docs/NPEP-N1-ADMIN-UI.md)，本任务没有重复执行前端全套测试。网页显式打开后加载设备管理，离开后取消旧响应；“在线”与“上次观测”分开解释，不把旧 EXAM 显示为当前已执行考试模式。

对端已本地提交 `NPClassworks/codex/npep-n1-admin-ui` 的 `0d07efb`，工作区干净；KV 保持 `codex/npep-n1-server` / `e03ff22`。本轮测试 HTTPS 已由对端停止，独立 PostgreSQL 与 ignored 夹具保留，未关闭 Docker/WSL 或删除卷。设备 WPF 测试实例也已正常退出。
