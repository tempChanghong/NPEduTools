# 声级计参考校准：实物验收记录

当前状态：用户已下单 DLY-2202，计划 2026-10-12 带到学校；2026-10-11 仍无实物。以下步骤不是已完成的验收，以客服说明书为规格依据。“自习监测 → 联机校准 (Beta)”已提供单次 USB 读数诊断；同期麦克风校准仍使用“外部声级计参考”，联机入口不自动保存参考。

目的：验证固定大屏麦克风链路的估算参考，先确认能稳定复核，再决定是否将估算 dB(A) 应用到正式监测。软件不会改写仪表内部校正参数。实际测试须在管理员明确操作下、有效自习及准备时段之外进行，无需组织学生配合；不保存原音频。

## 记录基本条件

填写日期、操作人、大屏型号、软件版本、麦克风名称／endpoint、输入音量和静音、驱动 AGC／增强设置、麦克风位置、仪表型号／固件、仪表设置与供电状况。记录自习时实际摆放位置，不用“测完换设备／增益”后的结果代替原配置。硬件旋钮或驱动处理状态无法全部由软件发现。

## 手动参考流程

1. 先核对大屏所选麦克风，学校安排当前为时段外。选择仪表 A 加权、与软件一致的 FAST 或 SLOW、非 MAX，量程覆盖当前读数，确认无低电量或超量程提示。
2. 仪表拾音头靠近大屏麦克风，避免遮挡，测同一声场；记录两者位置。不能拿教室另一处的读数当作同一参考位置。
3. 管理员明确填写允许波动和第二点复核差值。界面可填范围不是精度承诺；说明书的仪表精度也不等于整条大屏测量链路精度。先按候选门槛试测并保留结果，不能仅放宽到“通过”为止。
4. 在稳定声场下采第一电平，组件预热后收集 10 秒统计，总过程最多请求 20 秒后停止。检查覆盖、削波、波动和质量；读取该段同一时段稳定的仪表数值，填写参考及可选成对最低／最高，并确认设置与时段一致。扬声器音量百分比不是已知声压级。
5. 改变声场电平，保持相同设备、位置与输入设置，采第二段并填同期读数。两参考电平至少差 6 dB、变化方向一致；若质量或复核不通过，检查声场／增益／AGC／读数口径后重采，不拟合任意斜率。
6. 通过复核后，由管理员显式保存。记录偏移、第二点差值、门槛及两点读数。正式监测会重新核对输入设置，再分别提供 dBFS 和估算 dB(A)；学校后台显式选择阈值单位。保存成功与实际有效估算是不同事实，失效时不自动用 dBFS 冒充 dB(A)，旧报告不补算。
7. 在第三个稳定电平或重复原电平作独立复测，保留原配置及新统计，检查候选偏移能否重复解释参考读数；不要把同一组拟合数据的通过当作独立精度证明。当前界面重采同一角色会替换草稿中的旧点，原确认参考保留；操作前手工记下旧草稿统计。长期漂移和不同声源频谱的误差仍需后续观察。

## 软件保护检查

| 人工操作 | 预期结果 |
|---|---|
| 只打开页面或刷新 | 不开始采集、不连接声级计 |
| 参考采样期间尝试普通监测 | 拒绝另一采集，不抢占当前麦克风 |
| 校准期间有效学校排程到点 | 校准中断，释放后启动自习监测；校准不成为正式报告 |
| 考试／暂停或运行状态不可读时操作校准 | 显示不可操作，保留草稿与确认配置，不启动新采样 |
| 校准期间进入考试／暂停，关闭或停止刷新页面 | Host 自行请求中断并释放；样本不用于确认，不依赖页面轮询 |
| 校准期间暂停后点击取消 | 取消仍可用，只取消当前校准，不影响其他会话 |
| 校准期间拔出麦克风、改变输入音量／静音 | 不确认好样本；提示失效，不切换其他麦克风 |
| 关闭参考窗口 | Host 到期限结束采样，不能无限占用 |
| Host 重启后查看已存参考 | 保留参考，但不宣称输入设置已有近期匹配 |

这些边界已经有合成采集验证，实际大屏仍须人工验收。异常时先记录时间、界面信息及设备状态，保留原配置；不操作真实学校安排来制造测试时段。

## USB 到货验证与联机入口的准入条件

使用“联机校准 (Beta)”只读验证：设置/输入本机管理口令 → 刷新声级计 → 选择设备 → 连接并读取一次。页面加载不枚举、不连接，每次读取后释放连接；读数三秒后撤下，必须显式重读。只读仪表诊断不会开启或停止麦克风，可以在正式监测期间核对连接；麦克风参考采样和配置操作仍须在准备及自习时段之外完成。建议明天在 18:58 准备阶段之前留出时间测试，不能为测试改动真实排程。

- 核对设备身份、VID/PID、HID 输入／输出报告长度；当前适配器候选来自 SoundLab 静态实现，不能称为已确认的实物结果。
- 关闭 SoundLab 后显式选择正确设备路径；验证 A/C、FAST/SLOW、MAX、量程及低电量解析是否与屏幕一致。软件默认不改变仪表设置，不发送仪表校正或历史写入命令。
- 记录查询、接收和仪表屏幕变化，检验实际回复速率、迟到／重复／积压数据及断线重连。Host 收包时间不是仪表采样时间；没有经确认的仪表采样序号或时间戳时，不宣称精确同步。
- 验证错误报告、短包、超量程、超时、取消和独占繁忙均停止使用该次结果，不以缓存数值冒充新数据，不自动切换设备。
- 读取失败时可继续既有 dBFS 监测；需要启用估算阈值时先完成有效参考并明确选择单位。不要为了赶进度把未校准的数字信号改名成声压级。
- 通过通信验证后，再以同位置、同 A/F/S 模式的稳定两电平做同步参考与独立复测。AC 输出不接普通麦克风输入，本轮不验证 AC 路线。

验收结果填写“通过／失败／待验证”，附实际数据和操作条件。没有实物、没有新鲜度证据或没有同期测量时，结论保持“待验证”。正式应用前还需明确估算单位、配置版本与失效条件，贯穿阈值、界面和报告，旧 dBFS 结果不补算成 dB(A)。
