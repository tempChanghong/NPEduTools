# 本机校准状态展示

学校定时页、手动自习页、监测设备设置、工作区准备状态，以及学校／手动全屏展示的噪音模块共用简短校准标识。全屏页在原噪音模块上方增加低对比小标识，不调整时钟、进度、按钮与作业布局。

| 状态 | 含义 |
| --- | --- |
| 未校准 | Host 已确认没有保存快速阈值或外部参考；仍可使用原始 dBFS。 |
| 已快速校准 | 已确认场景样本与本机 dBFS 双阈值，不等于声压级校准。 |
| 已参考校准 | 已保存手动声级计参考，用于估算 dB(A)。 |
| 已联机校准 (Beta) | 已保存 USB 同期声级计参考，用于估算 dB(A)；保留 Beta。 |
| 校准已失效 | 已观察到麦克风、输入设置变化或快速阈值的学校配置上下文变化；须重新校准／确认。 |
| 校准不可用 | 本机校准文件不可用，或本次采集无法支持参考估算；不当作未校准。 |
| 校准状态待确认 | 未获得当前 Host 的兼容、新鲜且匹配实例／噪音修订号的状态。 |

“已校准”表示确认结果存在。详情明确区分 `Saved`（已保存，下次采集核对输入后才应用）与 `Ready`（本次采集输入已核对）。读取状态不启动采集，不能在麦克风闲置时证明 Windows 输入设置未被外部修改。输入变化仍按原正式采集的签名检查与参考失效规则处理。

参考校准优先展示；已失效的外部参考不会以快速阈值状态遮盖。快速校准只改变相对 dBFS 阈值。声级计参考只产生估算 dB(A)，不宣称工业级准确性或已通过实物验收。准备阶段已有参考但尚未开始本次采集时，显示“估算 dB(A) · 等待输入核对”。

## 兼容与运行范围

`NoiseCalibrationStatus` 是小型只读 DTO，不带设备路径、输入签名、校准样本或原始音频。使用显式选择的新本机状态能力：

- `study.status.calibration`：现有学校状态、座位表元数据、照片状态及校准摘要。
- `manual.study.status.calibration`：现有手动状态及校准摘要。
- `noise.status.calibration`、`noise.devices.calibration`：现有噪音状态／设备列表及校准摘要。

原能力响应不增加新字段，避免旧 App 严格 JSON 反序列化失败。新 App 遇到 `UnknownCapability` 会按原能力读取，60 秒内不重复探测该摘要能力，并显示“待确认”。其他错误不触发兼容性重试。摘要随已有查询返回，不新增轮询计时器、不请求 KV、不打开麦克风、USB 或摄像头。

Host 只在实例与噪音修订号一致时附加摘要，避免设备编辑与读取交错后错误归属。全屏沿用本机展示状态的新鲜度；手动页和设备列表读取若被后续请求拖延超过 3.5 秒，不继续显示旧校准标识。收起设备页、断开后台、切页及缺少新字段会撤回已确认标识。

## 验证边界

新增原生测试覆盖未校准、保存、应用、输入／设备上下文变化、损坏文件、只读私有管道、紧凑数据、旧 Host 回退与错误不重复读取。WPF 检查包含学校／手动／准备阶段、USB Beta、失效、新鲜度、修订号不一致、完整展示循环和小窗口布局；全部为隔离模拟，不调用真实采集设备。实际一体机、声学及 2202 联机验收另行进行。
