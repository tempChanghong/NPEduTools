# 自习阶段提示音的持久去重

准备、开始和结束仍按当前 ClassIsland 学校时间、规则版本、展示实例及有效时段检查，再允许声音。准备画面持续至开始，开始和结束各限于原五秒窗口；声音被抑制不取消视觉提示。没有改变原生采样、校历或临时收起期限。

正式 Host 在自己的 `npep/study-stage-reminders.json` 保存已获准事件的 SHA256，事件由绑定范围、时段起止和阶段决定。配置版本不进入去重键，因此相同时段的配置刷新、App 重开、暂时取消展示后恢复、Host 重建均不重复授权。新绑定、新时段及不同阶段独立。不同数据目录不共享记录。

沿用原内存实现的最近 128 条上限，先进先出淘汰；文件限制 16 KiB，重复申请不写盘。不读取 Windows 当前时间，也不依赖进程单调时钟来撤销已记录事件。此上限不是永久历史去重；最旧事件被 128 次新授权淘汰后不再有去重保障。

授权前使用临时文件、刷盘和替换保存。读取损坏或写失败时拒绝阶段声音许可，保留原文件，当前 Host 不自动清空错误。本机 `StudyDisplayState.StageAudioError` 单独显示“阶段提示音暂不可用”；采集、双线红光及独立纪律冷却不因此停止。已有正式 Host 单实例约束仍适用，不支持多个 Host 共写同一目录。

记录的是**许可消费**，不能证明已经听到声音。许可丢失、窗口隐藏或播放器故障可能使已记录的声音没有播出；不据此重试。新 Host 未观察原活动窗口时仍不伪造结束事件，没有持久化展示权限或续播旧通知。
