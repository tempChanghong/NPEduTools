## 本轮已实现：快速校准

入口：NPEduTools → 自习监测 → 打开快速校准。先保存本机麦克风，并配置本机管理口令。

管理员可以选择“相对安静”“正常自习”“少量低声交流”“多人持续聊天”“管理员约三米处正常说话”，再独立标记为可接受、希望视觉提醒或希望纪律提醒。这些只是人工标签，程序不识别语音内容或说话者。每段 15 秒，不必采齐场景，也不要求绝对安静或学生配合。支持分次补采、重新标记、删除和新建草稿。

Host 复用原生 pcm-energy-v1 的 100 ms 能量帧；只保存 P10、中位数、P90、覆盖率、削波率和质量，不保存、上传 PCM 或原音频。每段最多 200 个临时电平值，草稿最多 20 段。完整样本至少覆盖 90% 时长、有效采样至少 13.5 秒，削波超过 0.1%、数字静音、异常、采样不足或中途取消均不作为有效参考。缓存突发帧也不能伪装成 15 秒现场采样。

自动建议使用有效样本的分布边缘：

- 必须有“可接受”和“纪律提醒”的有效样本。没有视觉样本时，两个类别之间至少相隔 6 dB，将空隙三等分，建议视觉线和纪律线，并说明视觉场景尚未验证。
- 三种判断均有样本时，可接受的最大 P90 与视觉的最小 P10、视觉的最大 P90 与纪律的最小 P10 各至少相隔 3 dB，两条建议线取对应空隙中点。
- 以上 3 / 6 dB 是首版建议算法的工程裕量，不是声压级校准精度承诺。重叠时不自动给数值。管理员可以补采、重新标记或手动确认。
- 手动确认仍需要上述两种有效参考样本。范围为 -120 至 0 dBFS，纪律线高于视觉线至少 1 dB。越接近 0，数字信号越强。

确认会保存当前设备的本机阈值，不修改 KV 学校公共配置。实际自习展示的双阈值判定使用本机确认值；学校的启用开关、持续秒数、限频及排程保持学校配置。麦克风 endpoint ID、能量算法、采样格式、Windows endpoint 输入音量与静音状态，以及学校绑定身份和配置版本共同约束适用范围。改用别的设备、输入设置不匹配或学校配置更新时回到学校阈值；Host 重启后须重新取得采集签名才可应用保存值。可点击恢复学校阈值清除本机确认值。

当前签名无法自动察觉麦克风物理移动、所有硬件增益旋钮或驱动内部 AGC/降噪变化；这些改变需要管理员主动重新校准。Windows 音量或格式匹配也不证明系统增强已关闭。学校配置版本变化会保守地使本机值失效，即使变化来自排程或展示设置；后续可以在明确配置继承规则后缩小失效范围。

所有校准写操作由 Host 验证本机管理口令，使用独立 revision 和草稿 ID 拒绝过期、多窗口请求。准备／自习阶段及任何已有采集期间不可开始校准。学校排程启动优先：中断校准、释放麦克风后下一次排程检查启动正式会话；不登记跳过排程。关闭校准页不停止正式监测，当前校准采样最多运行到 15 秒。校准会话不会生成或上传正式噪音报告。

草稿与确认值在 Host 数据目录的 noise-quick-calibration.json 原子保存。只持有一份当前草稿与一份确认配置。保存失败不激活新值；损坏或超限文件原样保留，并停止应用本机阈值。新的 Named Pipe 字段仅在 noise.calibration.* 响应出现，常规旧响应不附加它。

2026-10-11 衔接修正：快速与外部参考采样均不投影为旧协议的正式 `Active` 会话，实际采样、进度与统计通过各自专用能力读取；普通监测页不能据此认定麦克风空闲，Host 仍按实际占用拒绝另一采集。校准不在互联 outbox 建立正式会话检查点，学校定时调度可以中断校准，释放后开始自习监测。结构错误、错误版本及超限文件均返回 `CALIBRATION_STORE_UNAVAILABLE`，保留原文件，不向状态查询传播解码异常。实物验收步骤见 [声级计验收记录](sound-meter-acceptance.md)。

两种校准共用 Host 现有运行保护回调：考试、互联／教室暂停、运行切换或运行标志读取失败时，不开始采样、不写确认或替换草稿；没有校准采集时，页面只读状态为 Busy。同一草稿的取消仍允许，正在采样时直到释放仍展示 Sampling。快速校准还检查学校状态的 `EXAM_PAUSED` 原因。采样中途进入暂停由 Host 自身 250 毫秒巡检请求中断，无需页面轮询；设备释放仍取决于实际驱动清理，未释放前不开始下一采集。此检查只针对校准会话，不自行停止普通手动监测。运行保护检查在麦克风锁之外，打开设备前和开始采样前均再核对；保留原确认配置，将中断样本标为无效。本轮没有改变正式监测的考试／暂停策略。

快速校准结果始终是 **dBFS 阈值**，不生成实际 dB(A)，也不改写历史报告。

## 已实现、仅接入专用参考采集：A 加权与 FAST／SLOW 参考处理

2026-10-10：新增 Core 的 `AWeightingFilter`、`SoundEnergyTimeWeighting`、`ReferenceNoiseMeter`。2026-10-11：显式接入下节的外部参考采样，当前普通监测、快速校准、双阈值、网页协议和历史报告继续使用原有 `pcm-energy-v1`，没有改动计量口径。输出是 **A 加权数字电平（dBFS）**，未经外部参考补偿不能标为实际 dB(A)、SPL 或 LAeq。

滤波依据 ANSI S1.42 的标称模拟 A 曲线，由三段双二阶节逐声道处理，再平均各声道能量；反相声道不会互相抵消。按真实采样率生成系数并在 1 kHz 归一化，为减少低采样率下的高频偏差，使用明确版本化的 8.5 kHz 上端极点修正。该修正是本项目的工程近似，不是标准认证方法。[ANSI 标称曲线与极点](https://webstore.ansi.org/preview-pages/ASA/preview_ANSI%2BASA%2BS1.42-2001%2B(R2016).pdf)，[MathWorks 模拟原型与双线性变换说明](https://www.mathworks.com/help/audio/ref/weightingfilter-system-object.html)

参考处理只接受 44.1–384 kHz、1–32 声道的交错 PCM16／24／32 或 Float32。当前参考验证频段为 31.5–8500 Hz，不保证频段外同等误差，也没有增加带通滤波来消除频段外声音。对 8 种采样率分别扫描 10001 个频点，最坏数值偏差约 0.214 dB（44.1 kHz）；48 kHz 约 0.179 dB。这只是实现相对标称曲线的误差，不包括麦克风、输入增益、系统增强、声场和声级计误差，不承诺仪表等级。未来界面遇到低于 44.1 kHz 的格式需要明确提示或另行验证采样转换，不能静默退回未加权数据并称为 A 加权。

FAST／SLOW 在每个采样时刻对平方后的能量作指数平滑，时间常数为 125 ms／1 s；100 ms 仅是统计输出窗口。每帧分别提供窗口平均能量与末采样时刻的 FAST、SLOW 能量，不能互相冒用。初始状态为零，连续 5 秒有效采样后才标记整帧预热完成，仍需后续稳定声场检查。[NTi 时间权重说明](https://www.nti-audio.com/en/support/know-how/fast-slow-impulse-time-weighting-what-do-they-mean)

组件只保留滤波状态、能量和质量计数，不保留 PCM。数字静音返回空电平而非虚构 0 dB；原始削波率按全部声道样本计算。NaN、无穷或超出归一化范围的样本使当前窗口无效，清除滤波／平滑状态并重新预热，后续有效窗可恢复。参考流程必须拒绝无效、未预热或不满足削波／稳定性要求的片段；目前组件仅提供这些标记，尚未实现参考校准成功判定。停止时可输出实际时长的尾窗，新会话显式重置状态。

新增合成测试覆盖标称频响、真实正弦处理、采样率、时间响应、PCM 格式、反相／静音声道、分包、尾窗、会话重置、异常恢复、DC 抑制及有界分配。所有验证均使用合成 PCM，没有开启真实麦克风、连接仪表或上传音频。资源基准与完整回归记录见本地 `D:\CodeProjects\NPEP-study-20261009\a-weighting-review\REVIEW.md`；这些结果不等于真实大屏或声压级验收。

2026-10-11，入口：NPEduTools → 自习监测 → 外部声级计参考。本轮已接入管理员显式操作的参考采集、手动读数、第二电平复核和本机配置保存，验证仅用合成 PCM 与模拟采集。没有开启真实麦克风，没有仪表实物；现场界面、采集链路、读数稳定性与估算精度仍待验收。

每段保存统计窗口的 Host 时间、实际采样时长、覆盖率、数字平均／最小／最大、削波和质量；这些时间基于 Host 单调计时与起始 UTC，不是声级计内部采样时间证明。有效段须采足 10 秒、覆盖率至少 90%、削波不超过 0.1%、没有异常／数值底限或中断，并满足填写的波动门槛。管理员须确认仪表读数来自该段同一时段，A 加权、时间模式一致、非 MAX 且稳定；这是人工确认，程序不能验证仪表旋钮或读数时刻。可选最低／最高读数须成对填写，只检查波动，不拟合斜率。

候选偏移 = 第一电平的参考 dB(A) − A 加权数字统计 dBFS；保持 dB 对 dB 的单位斜率，第二电平验证该偏移的误差。不通过时不保存新确认配置；通过后仍须管理员点击保存。只存统计、参考、检查门槛、签名和版本，不存管理口令或音频。
