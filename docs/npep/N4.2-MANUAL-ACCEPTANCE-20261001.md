## 已通过

| 用例 | 用户确认的结果 |
| --- | --- |
| 网页开始与停止 | 桌面采集与停止同步；声音输入时读数变化；网页新增结束报告 |

| 学校后台报告一致性 | 对应设备的报告与大屏网页的会话、时间、时长、覆盖率、平均值、峰值及削波一致，无重复 |

## 已知问题与未覆盖项

- 人工联调时安静读数可能落在 -160 下限，极低但非零的输入仍显示“信号正常”。随后已完成 [显示修复与自动回归](N4.2-LOW-SIGNAL-20261001.md)，用户明确跳过新界面的人工复测；此前观察不能确定降噪、噪声门或采样格式的具体影响。
- dBFS 为数字信号电平；本轮不验证校准后的环境声压级、教室噪音阈值或评分。
- 未单独核验浏览器麦克风调用次数、原始音频未落盘或上传；不能把既有自动化证据改写为本轮人工证明。
- 拔麦克风、Host 异常退出及恢复、绑定变更隔离、三小时上限、休眠与 Windows 重启，尚未完成人工故障验收。
- 班级大屏的驱动兼容性、麦克风摆位、声学效果、长期运行及生产环境联调待现场验证。
