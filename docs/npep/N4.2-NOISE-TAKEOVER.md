大屏网页点击开始 → KV 按大屏绑定投递 → NPEduTools 使用已保存的麦克风 → 网页显示实际状态 → 网页停止 → 大屏与学校后台查看统计报告。

| 部分 | 负责什么 |

## 本地怎么验收

1. 本次已向 `127.0.0.1:5432/classworks_debug` 应用新增迁移；没有重置或重新导入调试数据。其他开发机在 KV 目录执行：`node --env-file=deploy/.env.debug node_modules/prisma/build/index.js migrate deploy`。
2. 从 NPClassworks 目录 `pnpm dev` 启动前后端；在 IDE 重新启动 NPEduTools App 与 Host，保持配对到同一本地服务、同一大屏绑定。
3. NPEduTools → 噪音监测 → 选择设备 → **保存麦克风**，此操作不启动采集。
4. NPClassworks 大屏 → 班级工具 → 噪声监测 → **开始监测**。等待“监测中”与新读数，确认浏览器没有请求麦克风权限。
5. 从网页停止，确认桌面释放麦克风；查看本次统计。学校后台 → NPEP 设备互联 → 对应设备 → **噪音报告**。
6. 补测：关闭网页不停止；断网显示未知、恢复后补传；本机停止也生成报告；拔麦报告异常；换绑定不混入旧班数据。

报告是在会话结束后上传。原始采样不落盘；Host 中止时只能恢复最近的统计检查点，标为 `Interrupted`，不伪造缺失区间。

## 关键规则与代码入口

- HTTP 协议 **0.6**：`GET /api/v2/npep/screen/noise`；`POST .../screen/noise/commands`；`POST .../device/noise-exchange`；学校后台 `GET .../schools/:schoolId/devices/:id/noise`。
- 网页使用 `X-Classworks-Screen-Token`，桌面使用设备 Bearer；管理员身份不能替代大屏凭据。复用已有绑定，不新设产品授权开关。
- 桌面与网页约每 3 秒轮询，15 秒以上无新状态视为过期。`ACCEPTED` 只表示桌面受理；运行状态 `Active` 才表示已启动，采样质量另列。
- 开始命令 30 秒失效；Host 实例、修订号与会话 ID 阻止迟到命令影响新会话。会话最多 3 小时，使用单调时钟计时。本轮不随考试模式自动启停噪音。
- 桌面 `noise-outbox.json` 保存统计及有限命令日志，先记账再执行；报告最多 200 份／14 天，超限丢弃最旧记录。KV 每台设备最多 200 份／30 天，页面展示最近 20 份，后台维护清理超期记录。
- 换绑时丢弃旧绑定待传统计；正在结束的旧会话也不得改名上传到新班。存储损坏提示异常，不默默覆盖并重新执行命令。
- 桌面：`Host/NoiseService.cs`、`Host/NoiseTransport.cs`、`Integrations.Npep/NpepRuntime.Noise.cs`。KV：`services/npepNoiseService.js`、`services/npepNoiseRepository.js`。网页：`utils/nativeNoiseController.js`、`v2/NoiseScheduleManager.vue`、`v2/NativeNoisePanel.vue`。
