# 手动自习与定时自习异常恢复

## 手动自习

- 可选开始、结束日期和时间。未指定开始则立即开始；未指定结束则主动结束，实际采集最多三小时。结束必须晚于开始，安排不得超过三小时。
- 使用 Windows 本机时间；预约默认提前两分钟打开展示，设置页可在本机调整为 0–30 分钟，无需管理口令；新预约冻结提前值，到指定时间才采集。准备提示最多十秒，开始即衔接开始提示。未指定结束时显示已进行时间与三小时上限，不以该上限计算进度百分比。
- 复用自习展示、提示音、双阈值、麦克风、摄像头及校准配置。隐藏自习座位表；左下角长按两秒结束，即使指定结束时间也可提前结束。
- 临时使用电脑默认十分钟返回，可选不自动返回。收起期间采集继续。手动后台退出或异常结束不显示定时保护警告，不自动恢复手动采集或预约。
- 学校定时采集优先：结束原手动会话，保存接管原因的报告，释放输入，再启动学校定时采集。旧窗口的结束命令绑定 Host 实例、修订号和会话 ID，不能停止新会话。
- 正常结束提示五秒，随后本机报告展示五分钟。被学校定时接管时只保存手动报告，不弹报告遮住定时展示。
- 本机完整手动报告在数据目录 `manual-study`，最多50份、每次保存清理14天前记录；学校统计通过现有加密报告队列补传，并明确 `sessionKind=Manual`。本机报告与服务器上传回执是不同事实。
- 当学校已绑定、照片策略启用、配置及服务器照片许可新鲜时，手动自习可按阈值拍照；与定时/退出/恢复共用限频。未取得学校许可不会自动拍照或上传。
- 手动照片许可使用当前认证会话声明的实际手动采集时间与信号状态，服务端另核对身份、已应用配置、新鲜度和三小时边界，不伪装成学校定时执行回执。服务端无法仅凭该声明独立证明麦克风物理采集。

## 定时自习异常恢复

1. Guard 在已武装的定时采集期间观察受监控进程消失，写入独立事件：旧进程身份、守护登记代次、时段结束 UTC 和配置上下文摘要。启动准备、正常退出、跳过时段、挂起及 Windows 会话结束不创建异常事件。
2. 拉起后仍由 Host 重新核验学校绑定、有效配置、ClassIsland 学校时间与实际定时采样。进程消失本身不是成功采集、人员身份或故意绕过行为的证据。
3. 恢复到新鲜实际定时采集后，持久化事件处理记录，再尝试一次摄像头捕获。**只在恢复后捕获**，不声称拍到进程被结束的瞬间。需要学校照片策略及新鲜许可，并共享默认30秒间隔。
4. 显示已有深红色、无发光白字警告30秒，然后恢复自习展示。右侧说明使用“异常中断与恢复”，区分拍照中、本机已保存、已上传、受限频抑制、失败和待确认。
5. 同一异常两侧进程恢复及重启重试共用事件 ID；拍照前持久化处理标记。再重启不会重拍或重置30秒提醒。损坏/不可读标记拒绝重新触发，状态返回诊断错误。此策略优先避免重复；标记写入后立即再次崩溃可能没有照片，不补拍冒充成功。
6. 事件与照片各自上传、各自确认。管理后台分辨异常恢复、退出验证失败及手动照片。照片未启用/没有摄像头/离线不妨碍监测恢复，界面按实际结果说明。
7. 经验证结束学校定时后台，仍按原规则跳过本次时段；手动退出不能顺带跳过即将开始的学校时段。守护保留，未来学校准备时段仍可唤醒。维护停止及系统会话结束沿用原规则。

## 验证边界

本轮使用合成音频帧、合成图像、私有测试 Named Pipe、回环 HTTP、独立临时进程和专属测试任务；未开启真实麦克风/摄像头，未操作学校配置、数据库迁移或生产服务，未 Commit/部署。真实大屏时钟桥接、任务管理器结束与恢复、摄像头/网络/服务器存储链路仍需实机验收。USB 联机校准保持 Beta，不属于本轮实物验收。
