# 已开始自习的失联续行

学校连接的同步状态与本机执行状态分别判断。短暂网络故障、限流或配置确认超过十五秒，不再自动撤下已经开始的本次自习展示。

## 续行条件

- Host 已收到本班配置与执行授权，唯一排程执行器已经拥有这次定时采集会话，状态为启动中或采集中。
- 绑定、配置版本、模式和本次时段保持一致；对应时间来源仍通过本机检查。
- 只沿用当前窗口，不重新开始采集、不重置统计、不重复开始提示，不显示缓存的下一次安排。
- 窗口结束以已知结束时间及初次见证时保存的单调期限限制。失联结束后撤销剩余执行许可，防止旧全天租约启动下一次离线自习。结束提示及五分钟本地报告仍可正常展示。

展示标注“学校连接正在恢复 · 本次自习继续”。“正在监测”仍要求真实、当前的采样，不由缓存配置决定。已经完整校验的本班座位表及当天作业在本次失联续行期间保留；图片撤回、配置版本/日期/绑定变化仍使旧内容失效。

恢复原连接不再先清空当前安排。暂停互联、解绑、明确授权失效、跳过本时段或切换模式仍撤销对应任务。配置或授权变化收到后按新结果处理；离线期间无法知道服务器新修改。

## 保留边界

本地续行状态不作为新的学校配置回执上传。仅下载配置而没有实际执行授权，不构成离线开始许可；Host 重启不恢复此内存许可。日常模式仍校验 ClassIsland 时间，考试模式沿用其既有 Windows 时间来源，未放宽时钟失效保护。

摄像头仍遵守独立照片租约及限频。本改动没有把照片许可扩展到整段离线时段；麦克风故障的现有保护也未改成无限自动重试。统计与照片使用既有补传队列，不能把待上传写成已上传。

## 隔离验证

`NoiseScheduleHostTests.OfflineStudy.cs` 用真实 Host/排程/报告服务、合成采样和虚拟时钟验证日常/考试两种模式的 135 分钟窗口，每种包含持续失联和恢复连接两条路径，并各注入 90 次同步失败。检查展示实例、会话、缓存内容、到点结束、报告期限、真实采样缺口及后续离线窗口不启动。没有开启真实硬件。

实际 WPF 私有管道测试另检查慢查询后的新鲜状态复核，不因其他查询耗时反复收起窗口；新回执撤回安排或出现考试放映优先时仍让位。自动测试通过不代替现场网络及一体机验收。
