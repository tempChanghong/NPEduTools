# 日常／考试课堂模式

日期：2026-09-20。实现基于 E4 的 ExamAware 自启动桥接能力。

后续已加入 [可选即时切换与主窗口／侧边栏状态显示](CLASSROOM-RUNTIME-SWITCH.md)，最新行为与验证见该文档。

## 使用方式

重启新版 NPEduTools，在主窗口左侧打开 **课堂模式**。

| 模式 | ClassIsland 管理员登录任务 | ExamAware2 登录自启动登记 | 自动录课 |
| --- | --- | --- | --- |
| 日常 | 启用 | 关闭 | 解除模式暂停，按原配置判断 |
| 考试 | 禁用，但保留任务 | 开启 | 暂停，保留原计划 |

首次使用前：

1. 在 ClassIsland 页面保存当前安装位置，并创建或确认兼容的管理员自启动任务。
2. 在考试看板页面保存 ExamAware2 正式版程序位置，完成配对，安装支持自启动设置的桥接 0.3.0 或兼容版本并授予对应权限。
3. 选择模式，确认列出的变更；涉及 ClassIsland 任务启停时，通过 Windows 的正常管理员授权。
4. 等待页面显示切换完成。可点击“核实实际设置”读取现状；失败时使用“恢复切换前设置”。

设置的是当前 Windows 用户的登录自启动。Windows 任务管理器、计划任务触发器等仍可能单独禁用启动行为；登记成功不等于已经验证了真实重新登录。

为访问桥接，切换时可能启动 ExamAware2。默认不会退出当前软件；勾选新增的“同时切换当前运行的软件”后执行正常退出与目标启动，详见即时切换文档。

## 自动录课语义

- 模式暂停是独立条件，不通过停用录制、跳过今天或删除计划实现。
- 周期性规则、固定日期计划、科目排除、已有执行记录保持原样。
- 切入考试模式时，正在进行的自动录制收到正常停止请求，录制器完成保存；界面继续显示实际保存状态。不会强行终止录制进程。
- 手动录制不因课堂模式停止，仍受原本的管理窗口租约保护。
- 切回日常不强制启用用户已停用的录制，不重置学校日期确认或重新执行已记录的课程。
- 计划判断继续采用 ClassIsland 学校时间；模式操作的超时采用单调时钟，诊断核实时间使用系统时间。
- 已结束的课程不补录。若返回日常时仍在某个原计划的正式时段内，现有调度器可能开始录制剩余时段；已执行或已结束的本节不会重新开始。
- 后台重启后，考试模式暂停从磁盘恢复；自动录制本身沿用已有的“重启后需重新启用”规则。
- 管理窗口失联或学校日期需要确认时，已有录课保护仍然生效。

## 切换流程与失败恢复

1. 验证请求版本、模式枚举、状态修订号和重复请求。
2. 检查两款软件的位置、ClassIsland 兼容任务、ExamAware 桥接能力与当前登记状态。
3. 将切换前状态和录课暂停写入恢复记录，落盘成功后才能执行外部修改。
4. 等待录课管理锁，向当前自动录制发送停止请求。
5. 先开启目标软件的自启动，再关闭另一款的自启动。
6. 重新核实两款软件的配置修订和实际登记；全部符合才提交目标模式。
7. 失败时保留原模式名称、显示“未完成”，保持自动录课暂停，保留恢复入口。

ClassIsland 使用已有管理员组件，新增 enable / disable 白名单操作，保留同用户、同会话、程序路径与任务指纹检查。仅切换现有匹配任务的 Enabled 属性，不删除或重建任务，不替换其他用户或安装位置的任务。

ExamAware 复用 E4 的配对、进程身份核实、带请求标识的自启动设置及读回结果。未收到确认不会当成成功，也不会自动重复发送。

恢复操作重新核实当前配置，然后恢复原来的两项自启动设置和模式暂停值。恢复不负责撤销为连接桥接而启动的软件。程序位置或配对修订改变时阻止恢复到错误对象；需恢复原配置后再处理。

未完成的恢复记录存在时，禁止新模式覆盖它。状态核实发现自启动与模式不符时显示“设置不一致”，不会偷偷覆盖用户的外部更改。状态页注明核实时刻，常规轮询读取缓存，只有主动核实或切换才查询实际任务。

## 持久化与退出

记录位于 Host 配置目录的 classroom-mode.json；默认目录为当前用户 LocalAppData 下的 NPEduTools/config。测试使用独立目录。

写入采用临时文件、Flush(true) 和替换；不完整操作在重启时标记为未完成并保持录课暂停。损坏或不可写的模式记录不会被当成日常模式，也不会被自动清空；页面给出检查提示。

每次外部修改之前先保存恢复点。取消 UAC、通信超时、状态变化和读回不符都不会伪装成整体成功。后台正处理模式操作时拒绝正常停止请求；意外终止由持久化记录覆盖。已受理的操作不依赖打开模式窗口的那条管道连接。
