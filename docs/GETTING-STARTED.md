# NPEduTools 使用指南

[返回项目首页](../README.md)

这里介绍安装和日常操作。构建与调试请看[开发指南](DEVELOPMENT.md)。下载包与仓库源码可能处于不同进度，功能和文件名称以您下载版本的发布说明为准。

## 安装与首次打开

1. 从[GitHub发布页](https://github.com/tempChanghong/NPEduTools/releases)选择Windows x64程序包。`Source code`是源码，不能直接作为软件运行。
2. v1.0.0可下载安装EXE，或完整解压ZIP到固定目录，再运行包内的`Start-NPEduTools.cmd`。不要只取出一个EXE。安装版升级与卸载见[安装说明](INSTALLER.md)。
3. 程序会请求Windows管理员权限。核对来源后允许，阅读并分别确认三份服务与隐私协议，再跟随初始设置引导选择用途。协议页面也提供GPL v3开源许可证全文，支持离线阅读。
4. 暂时不用的功能可以跳过；以后可以从主窗口重新打开初始设置或进入对应功能页配置。已完成旧引导的用户会单独确认新协议，不会清空原配置。

三份协议生效日期为2026年10月4日。可在“关于 → 服务、隐私与开源许可”重新阅读；GPL作为开源许可证独立展示，不另设同意勾选。

Windows程序包自带.NET运行时，无需安装开发SDK。ClassIsland、ExamAware2与SecRandom本体需按需要另行安装。

**v1.0.0程序包内置FFmpeg／ffprobe，录课无需单独下载组件。** 对应源码、构建说明和许可证随包提供。

**InDev 20261002程序包的录课功能需要另外准备FFmpeg／ffprobe**，见[录制组件安装说明](RECORDING-TOOLS-INSTALL.md)。后续版本是否包含这些组件，以对应发布说明为准；现有下载包不会随仓库源码修改而自动更新。

## 侧边栏与主窗口

- **侧边栏**：快速打开课堂工具、我的快捷和设置；配置SecRandom后可用“抽”按钮闪抽。
- **主窗口**：管理关联软件、录课计划、麦克风、学校连接及显示偏好。
- **快捷启动**：添加您常用的应用、文件或网址，之后从主页或侧边栏打开。移除快捷入口不会删除原文件。

关闭或隐藏管理窗口后，后台仍可能运行。要完整退出，请使用托盘中的退出入口；若正在录制或监测，先正常停止。学校定时监测受保护时，需要相应的管理验证。

## 录课

### 手动录课

先选择屏幕、系统声音／麦克风和保存目录，保存设置后开始录制。录制期间可以暂停或继续；停止后等待保存完成，再查看本机视频。首次使用建议先短录一段，检查画面与声音。

### 自动录课

1. 配置ClassIsland及NPEduTools时间桥接插件，确认软件读到的学校时间正确。
2. 设置每周重复的安排，或某个具体日期的计划。可以跟随课表，也可以指定固定时段。
3. 检查科目排除、计划时间及录制设置，再开启自动录课总开关。**保存计划本身不会开始录制。**

“试运行”只模拟计划到点时的开始和结束，不生成视频，也不是开启自动录课的必经步骤。考试模式会暂停日常自动录课，保留已有计划。

## 关联教学软件

| 软件 | 配置后可以做什么 | 需要准备什么 |
| --- | --- | --- |
| ClassIsland | 提供学校时间及课表，参与日常／考试环境切换 | 安装本体及配套桥接插件，保存正确程序路径；模式联动还需按页面提示配置管理员登录任务。 |
| ExamAware2 | 打开考试看板、参与模式切换，配合学校考试配置与放映 | 安装本体及配套桥接插件，保存程序位置并完成本机桥接配对。 |
| SecRandom V3 | 打开点名页、控制浮窗、闪抽一人 | 安装V3并在其中准备名单，再在NPEduTools保存程序位置；无需额外桥接插件。 |

**日常／考试模式会管理相关软件的登录自启动设置，也可切换当前运行的软件。** 执行前请保存并关闭ExamAware编辑器，正常结束正在进行的放映；操作受阻时按提示处理，不要把“请求已收到”当作已经完成。

## 连接学校

1. 确认学校已提供NPClassworks与NPEP服务。
2. 在“设置 → 学校互联”输入学校提供的服务地址。**前端和API分离部署时，填写后端API的根地址**，不要填写某个网页路径；非默认端口需包含端口号。
3. 按学校提供的配对流程完成设备、学校及班级归属确认。服务器版本与预授权设置不同，流程可能有所区别。

配对后，设备可以接收学校通知和管理操作，并上报必要状态。部分通知会置顶显示并使用变暗遮罩，需要手动关闭。

学校互联允许配置HTTP或HTTPS地址；正式部署建议使用可信HTTPS。配对公共大屏应由有权管理人员进行，学校设备管理授权不能替代对受影响师生的隐私告知。

## 噪音监测

先选择并保存麦克风，再开始手动监测。连接学校后，班级网页可以控制已配置的原生监测；学校也可安排定时监测。

- 噪音监测在本机分析声音，**不保存或上传原始录音**；学校互联上传统计及必要状态。
- 显示的**dBFS是麦克风信号电平**，不是校准后的教室声压级，不能直接用于班级排名。
- 关闭网页或返回作业板不会停止本机监测。需要停止时使用网页／本机的停止入口；定时任务可能要求管理授权。
- 微课录制与噪音监测不同：前者可以在本机视频中保存声音。
