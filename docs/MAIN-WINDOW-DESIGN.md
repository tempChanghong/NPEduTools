# NPEduTools 主界面与常驻入口设计

更新：2026-09-17。状态：已实现 WPF 管理窗口与常驻桌面侧边栏。

## 设计决定

日常操作由屏幕边缘的快捷入口承接，主窗口负责完整操作与设置。入口位置由使用者自主选择：设置提供左／右侧单选并显示当前选择，上下位置直接拖动调整，即时生效且重启保留。**右侧偏下仅为首次启动默认值**。点击入口即可操作 PowerPoint 辅助，不需要先找托盘。托盘保留为补充入口。

本轮按“双入口”设计：侧边栏负责日常启动和课堂操作，主窗口负责管理快捷项、查看工具状态和调整设置。交互参考 [Sidebar for Class](https://github.com/PANDAJSR/sidebar-for-class) 的贴边展开和工具组织，以及 [ClassSidebar](https://github.com/tempChanghong/ClassSidebar) 的侧边栏与独立管理界面。继续使用已有 WPF 和 Host，不引入 Electron 运行时。

界面使用浅灰绿底色、白色工具卡与深绿强调色。侧边栏采用紧凑竖条，顶部为 `n` 标记，下面分别是课堂工具、我的快捷和设置。展开面板与工具条并列，工具条始终留在屏幕外侧。主窗口采用浅色左导航，首页并排显示 PowerPoint 与 ClassIsland，再显示自定义快捷项。

## 贴边快捷面板

- 默认位于主屏右侧可用区域约 78% 的高度；支持上下拖动，也可拖到其他显示器。设置中可以切换左侧或右侧。
- 收起窗口为 80×284 DIP，工具条按钮为 52×52 DIP；展开窗口为 440×620 DIP，包含工具条与内容面板。尺寸受当前显示器工作区限制。
- 工具条可以直接进入“课堂工具 / 我的快捷”，面板顶部也保留切换按钮。快捷项按三列显示图标、名称和类型；长名称省略，悬停可查看完整名称和路径。底部可进入管理页。详见 [自定义快捷启动](CUSTOM-SHORTCUTS.md)。
- PowerPoint 区直接提供开启／停止、暂停／继续和后台实际状态；ClassIsland 区提供已有的启动操作。
- 点击外部、按 Esc、点击收起箭头、再次点击 `n` 或关闭面板均收回工具条。收起状态下拖动 `n` 调整位置，拖动保留抓取点相对位置，避免侧边栏跳到指针中心；捕获丢失时终止本次拖动。
- 展开使用 140 毫秒透明度过渡，遵循 Windows 客户区动画设置；没有常驻模糊、循环动画或新增高频轮询。
- 收起入口不抢键盘焦点；主动收起面板时，若面板仍拥有焦点，则尝试回到先前窗口。点击其他窗口后不会重新抢回焦点。
- 位置、屏幕及左右侧保存到 `%LocalAppData%/NPEduTools/ui/`，文件名按本地后台端点散列隔离。此处只保存界面偏好，测试私有端点不覆盖正常使用的位置。
- 按显示器工作区和当前窗口 DPI 定位；显示器移除时回退主屏，面板高度限制在可用区域，长内容可以滚动。

## 主窗口

默认尺寸 1040×760 DIP，最小 840×600 DIP。左侧包含概览、快捷启动、偏好设置、展开侧边栏和明确的完整退出入口。页面有当前导航路径；日期在主窗口激活时刷新。

概览页提供展开侧边栏及管理快捷启动的入口。两个工具卡分别展示 PowerPoint 辅助和 ClassIsland 的真实状态与操作；自定义快捷项显示当前数量和三列图标网格，没有项目时可以直接添加。内容区支持滚动和触摸平移，小窗口不会通过隐藏底部操作来容纳内容。

设置页保留登录启动与触摸辅助启动偏好、入口左右侧、触摸兼容模式、ClassIsland 路径、连接详情和管理员自启动管理。快捷管理保留新增、编辑、排序、移除、撤销与失效路径修复。没有添加尚未接通的音量、截图、白板或录制按钮。

主窗口关闭或最小化后保留屏幕入口和后台；“快捷面板”按钮隐藏主窗口并展开快捷操作。再次启动程序会唤回同一主窗口。主窗口“退出 NPEduTools”和托盘“停止后台并退出”等待辅助与后台清理，然后关闭所有本程序窗口，不关闭外部软件或文稿。

## 状态与执行

主窗口和快捷面板调用同一套操作、读取同一份 Host 状态，不启动第二套辅助引擎。进行中的请求禁用重复操作；开启失败或后台断开显示实际原因，不能只改变按钮就宣称成功。

| 状态 | 主要操作 | 次要操作 |
| --- | --- | --- |
| 已关闭 | 开启辅助 | 无 |
| 正在开启／停止 | 等待，禁用重复请求 | 无 |
| 已开启，等待放映／正在辅助 | 停止辅助 | 暂停 |
| 已暂停 | 停止辅助 | 继续 |
| 正在书写，暂不辅助 | 停止辅助 | 暂停 |
| 无法启用／已中断 | 后台可用后重试 | 简短原因 |

暂停保留会话，停止释放本功能监听和探测进程。完全退出再打开默认关闭辅助；用户可选择启动时自动开启，详见 [登录启动说明](APP-STARTUP.md)。后台恢复不自动重启已经停止的辅助。ClassIsland 不可用不影响 PowerPoint 辅助；独立辅助版和主程序集成版保留互斥检查。

## 验证

本轮使用 Release 构建与实际 WPF 控件自动化验证。脚本为 `scripts/test-app-smoke.ps1 -Configuration Release` 和 `scripts/test-shortcuts-ui.ps1 -Configuration Release`。测试使用私有端点与自有模拟程序，截图和结果保存到 `.artifacts/app-smoke/`、`.artifacts/shortcuts-ui/`。

验收范围包括：

- 实际鼠标拖动入口和短按展开；关闭面板后仍保留入口。
- 快捷面板开启、暂停、停止辅助和打开设置，状态来自真实 Host。
- 隐藏主窗口、单实例唤回、ClassIsland 断连恢复、Host 意外退出与重连、完整退出清理。
- 完整退出后重启，恢复先前保存的入口位置。
- 工具条直接切换课堂工具／我的快捷、打开设置；左右侧展开时内容面板均朝向屏幕内部。
- 快捷项编辑、真实文件关联启动、侧边栏同步、路径修复与重启恢复。

物理指针测试选择左侧入口，避开 Windows 右下角通知区域；该设置仅属于随机测试端点。两侧的展开布局另行验证。实际执行结果及本轮截图路径见下方记录。
