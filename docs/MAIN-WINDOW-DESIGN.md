# NPEduTools 主界面与常驻入口设计

日期：2026-09-06。状态：已实现 WPF 主窗口与贴边快捷面板。

## 设计决定

日常操作由屏幕边缘的快捷入口承接，主窗口负责完整操作与设置。入口位置由使用者自主选择：设置提供左／右侧单选并显示当前选择，上下位置直接拖动调整，即时生效且重启保留。**右侧偏下仅为首次启动默认值**。点击入口即可操作 PowerPoint 辅助，不需要先找托盘。托盘保留为补充入口。

入口是深色圆角柄，使用薄荷绿 `n` 标记。展开后显示白色快捷面板，主要操作使用绿色按钮，PowerPoint 使用珊瑚色图标。主窗口采用深色左侧导航与浅色内容区，统一字体、间距、圆角和按钮状态；删去首页的课程数据与技术信息。

## 贴边快捷面板

- 默认位于主屏右侧可用区域约 78% 的高度；支持上下拖动，也可拖到其他显示器。设置中可以切换左侧或右侧。
- 收起窗口为 64×84 DIP，实际按钮为 52×72 DIP；展开面板为 352×422 DIP。常用操作触控目标至少 48 DIP。
- PowerPoint 区直接提供开启／停止、暂停／继续和后台实际状态；ClassIsland 区提供已有的启动操作。
- 点击外部、按 Esc、点击收起箭头或关闭面板均收回入口。单击入口展开，拖动仅调整位置。
- 收起入口不抢键盘焦点；主动收起面板时，若面板仍拥有焦点，则尝试回到先前窗口。点击其他窗口后不会重新抢回焦点。
- 位置、屏幕及左右侧保存到 `%LocalAppData%/NPEduTools/ui/`，文件名按本地后台端点散列隔离。此处只保存界面偏好，测试私有端点不覆盖正常使用的位置。
- 按显示器工作区和当前窗口 DPI 定位；显示器移除时回退主屏，面板高度限制在可用区域，长内容可以滚动。

## 主窗口

默认尺寸 900×670 DIP，最小 760×570 DIP。左侧包含常用、设置、快捷面板和明确的完整退出入口。

首页以 PowerPoint 为主要工具卡，展示状态与直接控制；ClassIsland 使用紧凑一行。设置页提供入口左右侧、触摸兼容模式、ClassIsland 路径及可展开的连接详情。尚未开发的自然语言换课和管理员自启动不显示可点击占位。

主窗口关闭或最小化后保留屏幕入口和后台；“快捷面板”按钮隐藏主窗口并展开快捷操作。再次启动程序会唤回同一主窗口。主窗口“退出 NPEduTools”和托盘“停止后台并退出”等待辅助与后台清理，然后关闭所有本程序窗口，不关闭外部软件或文稿。

## 状态与执行

主窗口和快捷面板调用同一套操作、读取同一份 Host 状态，不启动第二套辅助引擎。进行中的请求禁用重复操作；开启失败或后台断开显示实际原因，不能只改变按钮就宣称成功。

| 状态 | 主要操作 | 次要操作 |
| --- | --- | --- |
| 已关闭 | 开启辅助 | 无 |
| 正在开启／停止 | 等待，禁用重复请求 | 无 |
| 已开启，等待放映／正在辅助 | 停止辅助 | 暂停 |
| 已暂停 | 停止辅助 | 继续 |
| 正在书写，暂不辅助 | 停止辅助 | 暂停 |
| 无法启用／已中断 | 后台可用后重试 | 简短原因 |

暂停保留会话，停止释放本功能监听和探测进程。完全退出再打开默认关闭辅助。后台恢复不自动重启已经停止的辅助。ClassIsland 不可用不影响 PowerPoint 辅助；独立辅助版和主程序集成版保留互斥检查。
