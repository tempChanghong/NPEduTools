# NPEduTools 主界面与常驻入口设计

日期：2026-09-06。状态：已实现 WPF 主窗口、触摸辅助后台控制、托盘与单实例唤回。

实施记录：主窗口采用 760×640 DIP，“常用／设置”顶部导航；首页直接开启、暂停、继续和停止触摸辅助。托盘收起与重新唤回保持同一 App 和 Host；完整退出停止辅助和后台。103 项回归测试及真实 WPF 自动化测试通过，覆盖目标软件断连、Host 重启、状态恢复和退出清理。实际窗口截图与记录位于 `.artifacts/app-smoke/70b1d5a2e1af4ff69fd10fabfb643eac/`。目标大屏触摸验证仍按用户要求暂缓。

## 目标

用户已同意将 PowerPoint 触摸翻页整合进主程序，要求先明确主页面形式。目标设备为 Office 2024 教室触摸大屏，现场试用暂缓。现阶段以少量实用操作为中心，功能范围保持参考 PowerPoint-Touch-Assist 的效果。

现有主窗口为 900×820 的“课堂状态”页面，课程、连接信息和程序路径占主要空间。课程展示不是用户当前需要的核心能力，应移入 ClassIsland 详情；路径配置放入设置，主页面留给直接操作。

## 推荐：紧凑主窗口 + 托盘

默认提供普通、可移动和缩放的主窗口，初始目标尺寸约 720×560 DIP。顶部仅有“常用”和“设置”两个入口。首页使用纵向功能区，主要操作不需要滚动。首次打开显示窗口；收起后后台继续辅助。

| 形式 | 适用情况 | 本轮取舍 |
| --- | --- | --- |
| 普通主窗口 | 开关、设置、查看状态；无需长期占据画面 | 作为主要界面，保持紧凑 |
| 桌面边缘常驻侧栏 | 需要在授课过程中频繁操作许多功能 | 当前开关频率低；会占用课件边缘，也可能与 PowerPoint、白板边缘工具冲突，暂不默认提供 |
| 按需展开的桌面快捷面板 | 后续功能增多，需要在授课时快速访问 | 保留为后续入口，不同时开发第二套完整页面 |
| 窗口内部左侧导航 | 页面层级、设置分组明显增多 | 当前只有两个主要入口，先采用顶部导航；不是桌面侧栏 |
| 仅托盘菜单 | 鼠标使用便利，后台存在感低 | 大屏触摸目标太小，不能作为唯一入口 |

桌面侧栏和窗口内导航是两个不同问题。未来可以增加收起式快捷面板，复用相同操作与状态，不改变后台控制模型。当前不提供悬浮球、屏幕边缘手势或自动弹出的放映浮层。

## 首页

1. **PowerPoint 触摸翻页**：置于第一位。简短用途、实际运行状态、开启/停止按钮，以及启用后的暂停/继续按钮。兼容输入设置收进“设置”。无需显示 HWND、补发计数、COM 或日志路径。
2. **ClassIsland**：小型功能区，提供已有的启动入口和简短状态；程序路径与连接详情放到设置。课程名称、课表和事件计数不再占据首页。
3. 底部明确提供“收起到托盘”和“停止后台并退出”。不把普通收起设计成停止辅助。

未开发的管理员自启动和自然语言换课不做可点击占位，不显示虚构状态卡片。以后在相关功能可用时加入对应操作。

## 触摸翻页状态与操作

| 状态 | 主操作 | 辅助操作 | 含义 |
| --- | --- | --- | --- |
| 已关闭 | 开启辅助 | 无 | 没有运行本功能的监听 |
| 开启中 | 禁用重复点击 | 无 | 等待后台启动与确认 |
| 已开启，等待放映 | 停止辅助 | 暂停辅助 | 功能已启用，当前没有可辅助的放映 |
| 正在辅助 | 停止辅助 | 暂停辅助 | 放映及输入条件可用 |
| 已暂停 | 停止辅助 | 继续辅助 | 暂停期间不补发，继续后重新判断当前放映 |
| 正在书写，暂不辅助 | 停止辅助 | 暂停辅助 | 自动避让画笔等状态，不等于用户主动暂停 |
| 无法启用／已中断 | 重试开启 | 查看原因 | 显示简短原因，不能继续显示为可用 |
| 停止中 | 禁用重复点击 | 无 | 等待后台清理完成 |

暂停保留本功能会话与状态；停止释放本功能监听和它创建的探测进程。关闭 PowerPoint 不关闭 NPEduTools；ClassIsland 不可用不影响 PowerPoint 功能。UI 必须以后台回报为准，不能只变更按钮就宣称开启成功。

首版通过用户操作启用，收起窗口保持本次状态。完全退出后重新打开，默认关闭辅助；自动恢复或开机启用不是本轮的隐含行为。

## 入口和退出

- 主程序单实例：再次启动激活已有主窗口，避免多个辅助实例。
- 标题栏 X 和“收起到托盘”都隐藏窗口。首次收起给一次简短提示，说明仍在运行及如何重新打开。
- 托盘菜单：打开 NPEduTools、暂停/继续触摸辅助、停止后台并退出。辅助关闭时不提供误导性的“继续”。
- 桌面快捷方式或用户固定的任务栏入口用于大屏触摸唤回；托盘作为补充入口。不自动修改用户任务栏固定项。
- “停止后台并退出”停止本程序拥有的辅助与后台，等待清理后退出；不关闭 PowerPoint、ClassIsland 或用户文稿。
- 若托盘创建失败，X 保持普通可见退出流程并明确说明停止辅助，不能让窗口隐藏后失去入口。

## 触控和布局

- 常用按钮建议至少 48×48 DIP，主要操作高度 52–56 DIP；清晰文字标签，不依赖悬停提示。
- 操作放在功能区下方和窗口底部，窗口位置可调整，避免默认把所有操作压在大屏顶端。
- 常用页纵向排列；缩窄或放大系统缩放时允许自然换行和滚动，不裁掉退出入口。
- 状态使用文字配合颜色；加载和不可用状态给出明确反馈。
- 延续现有克制的绿色配色与 Windows 窗口操作习惯，不增加大量课程数据或统计面板。

## 实施顺序

1. 主窗口改为“常用／设置”，整理既有 ClassIsland 控件与事件绑定。
2. 将触摸辅助纳入统一后台生命周期与状态协议；复用现有输入、隔离 COM 探测及补发引擎。不要只是从主界面打开另一个独立小工具窗口。
3. 主程序单实例、托盘与收起／完整退出；协调独立辅助程序与集成模式的互斥，避免重复监听与重复补发。
4. 验证开启、暂停、停止、重开窗口、再次启动、后台断开及退出清理；保留现有 ClassIsland 回归和 PowerPoint 自动联调。

独立便携辅助包保留用于单独使用与排查。两种入口不能同时运行同一套辅助。进程拆分与具体协议以实现时的最小改动为准，无需建设早期架构文档中的完整场景引擎。
