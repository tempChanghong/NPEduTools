# NPEduTools 登录启动与触摸辅助自动开启

日期：2026-09-06。

## 使用方式

在“偏好设置 → 启动与就绪”配置三个独立选项：

| 选项 | 首次默认 | 行为 |
| --- | --- | --- |
| 登录 Windows 时启动 | 关闭 | 为当前用户登记 NPEduTools 登录启动项；关闭时移除本程序对应项 |
| 自启动时仅显示贴边入口 | 开启 | Windows 登录启动时不显示主窗口；手动打开仍显示主窗口 |
| 启动时开启触摸翻页 | 关闭 | 每次 NPEduTools 启动，在后台就绪后尝试开启 PowerPoint 辅助 |

后两个选项保存后在下次启动生效，修改偏好不会立即开启或停止当前辅助。暂停、停止及完整退出仍使用原有入口。ClassIsland 自启动由独立管理区负责。

## Windows 启动项

使用当前用户 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `NPEduTools` 字符串值，内容为带引号的当前可执行文件绝对路径及 `--startup` 参数。按 [Microsoft Run/RunOnce 文档](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)限制命令行长度不超过 260 字符。此设置不请求管理员权限，Windows 可自行延迟登录启动。

开关反映本程序的启动项是否已登记，不把登记结果等同于 Windows 已允许运行。如果在任务管理器或 Windows 设置中禁用了该启动项，可通过“Windows 启动应用”入口重新启用；本程序不修改系统的禁用记录。

开启、关闭后回读注册表确认结果，不修改其他值。同名项指向不同命令或程序位置时停止修改并提示用户。移动程序目录前应先关闭自启动，再从新位置重新开启。使用私有 `--pipe` 或自定义 ClassIsland 管道的测试实例不能登记真实登录启动。

## 启动与生命周期

- 新增无值参数 `--startup`，可以和已有测试管道参数组合；未知、重复或缺失值的参数被拒绝。
- 静默登录启动直接初始化贴边窗口与后台，主窗口不执行先显示再隐藏，避免闪现。
- 同一实例已运行时，重复登录启动直接退出；手动重复打开唤回已有主窗口。两种情况都不会重复自动开启辅助。
- 自动开启等待本次启动的第一个可用辅助状态，最多等待 30 秒；现有运行或暂停状态被保留。
- 开启请求发送前即消耗本次机会。失败、结果不明、后台退出或恢复都不会自动重放；用户主动操作优先。
- 自动开启失败在主窗口显示提示，辅助区继续显示实际状态，用户可通过贴边面板手动重试。
- 仍使用已有触摸辅助引擎和默认触摸标记规则，不更改 PowerPoint 文稿、放映设置或鼠标兼容模式。

## 偏好保存

启动偏好单独保存在 `%LocalAppData%\NPEduTools\ui\<端点散列>.startup.json`，不改变已有贴边位置文件。使用版本 1 的 JSON 和临时文件替换；保存失败回退控件显示，不能宣称保存成功。

文件损坏或版本不支持时保留原文件，本次禁用自动开启并显示提示；不静默覆盖。测试端点与日常端点相互隔离。

## 验证

- 全套 .NET 测试：139 项通过，包括启动参数、偏好持久化、损坏文件保留、注册表创建/删除/幂等和冲突保护。注册表单元测试使用隔离的非启动键。
- `scripts/test-app-smoke.ps1` 的真实 WPF 检查通过：静默入口、重复登录不唤醒、手动唤回、自动辅助、保持暂停、后台恢复不重放，以及关闭选项后的下次启动。记录位于 `.artifacts/app-smoke/359ca3c18bfb4429b9e567d065a3a074/`。
- Debug/Release 构建均通过，零警告、零错误。实际 Release 设置页已验证登录启动开关创建和删除正确的 HKCU 启动项，测试后恢复原先未登记的状态。结果与截图位于 `.artifacts/app-preview/startup-validation.json` 和 `startup-settings.png`。
- 实际退出 Windows 再登录和目标 Office 2024 大屏物理触摸仍需对应环境验证；自动化使用 `--startup` 进入同一启动路径，不把它记作真实重新登录。
