# 课堂模式首次配置检查

日期：2026-09-20。

## 使用方式

打开“课堂模式”后，页面自动显示四项检查。点击“重新检查”可刷新；点击切换到日常或考试模式时也会先重新检查，之后仍由后台核实实际配置、进程身份和修订号。

| 项目 | 检查内容 | 配置入口 |
| --- | --- | --- |
| ClassIsland 程序 | 已保存的位置是否存在且可访问；配置读取异常单独提示 | ClassIsland 程序位置 |
| 管理员自启动任务 | 通过现有管理员组件的只读 status 操作，检查任务是否匹配当前程序与用户 | 管理员自启动设置 |
| ExamAware2 程序 | 已保存的位置是否存在且可访问 | 考试看板与桥接 |
| 考试看板桥接 | 连接、受支持版本、正式打包状态、自启动权限、登记读回及操作忙碌状态 | 考试看板与桥接 |

四项分别显示结果。一款软件缺少配置不会掩盖另一款的缺项。点击配置入口会打开已有设置页面；重新打开课堂模式时再次检查。没有增加永久性的“配置已完成”标记，避免更换路径后继续沿用旧结果。

## 判定规则

- 管理员任务已开启或已暂停，均表示任务已配置。暂停通常是考试模式下的正常状态，不能误报缺失。
- 程序位置缺失或不可访问、任务缺失或冲突、读取状态未知、桥接版本或权限不满足要求，会阻止进入新模式的确认步骤，并滚动到检查摘要。
- 桥接未连接显示“待连接”，明确说明尚未核实配对及权限，不显示为已就绪。软件关闭也会导致断开，因此此状态本身不阻止继续；原有切换流程会尝试连接，未就绪时不会修改自启动。
- 检查程序位置只确认文件可访问，不代替后台启动时的程序身份校验。
- 检查不会读取或展示配对密钥，不会自动启动软件，不会修改自启动或请求提升权限。权限不足保留“待核实”，用户可从原设置入口进一步处理。
- 主窗口和侧边栏的常规模式轮询不会执行这份检查。只有打开管理页、手动刷新和开始新模式切换时执行。
- 已有未完成操作仍使用原来的重试和恢复流程；配置检查不会取代其恢复记录。

## 验证

- Release 构建：零警告、零错误。
- 自动测试：350 / 350 通过；其中新增 12 项检查测试覆盖任务已暂停、多个缺项、任务冲突、读取失败隔离、桥接未连接与权限不足、路径失效、取消以及重新检查失效旧结果。
- WPF 配置页面：5 项场景通过，覆盖四项提示、缺配置时拦截考试切换、只读核实、窗口重开、三个设置入口及返回后重新检查。
