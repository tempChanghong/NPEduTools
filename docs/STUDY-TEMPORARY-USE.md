# 自习临时使用电脑

长按“临时使用电脑”两秒收起展示。学校定时自习采用连续十分钟无操作后返回；手动自习也按无操作时间判断，默认十分钟，保留本机自定义时长和“不自动返回”。收起不停止噪音采集或照片策略。

Host 使用 Windows 当前交互会话的最近输入时间判断，操作其他软件也会重新计时。不安装全局键盘／鼠标钩子，不记录按键、鼠标位置或操作内容；其他 Windows 登录会话的活动不作为本会话的操作。接口依据：[GetLastInputInfo](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getlastinputinfo)。触控驱动在目标一体机上的输入时间更新仍须现场确认。

收起后至少等待本次无操作时长，避免收起前的旧闲置时间导致立即弹回。App 重连、重复收起请求或同一时段的排程修订不重新延长计时；实际输入才影响无操作时间。已经返回后再有输入，不会重新收起展示。Windows 时钟、ClassIsland 偏移变化不改变单调计时。输入状态无法读取时保持收起，并在监测页提示等待输入状态恢复，不能把未知状态视为无人操作。

旧学校策略的 `presentation.temporaryHideSeconds` 保留传输兼容；新版原生端不再用该字段的 1–3 分钟值限制临时使用，统一采用十分钟无操作。学校后台撤下旧固定时长选择，保留已有策略数据，不执行数据迁移。旧版原生端仍使用旧固定倒计时，需更新完整 App／Host 包才能采用新行为。

返回仍受有效授权、排程、时钟及考试放映优先规则限制。本规则只控制展示，不续开已结束的采集，不改变手动自习被学校定时接管的优先关系。
