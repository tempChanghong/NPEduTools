# 主页与设置页优化

日期：2026-09-20。

## 组织原则

侧边栏继续负责课堂中的快捷操作，主窗口负责状态查看和配置管理。首页优先回答“当前是什么模式、工具是否可用、下一步在哪里操作”；设置按用户要完成的事情分组。

## 本次调整

| 区域 | 调整 |
| --- | --- |
| 主页 | 移除大幅宣传卡，前置课堂模式；展示触摸翻页、ClassIsland 课程与连接状态、微课录制；补充自动录课计划入口。 |
| 左侧导航 | 区分工作空间与课堂管理，明确管理功能打开独立窗口；设置、展开侧边栏和退出固定在底部，长导航独立滚动。 |
| 设置／常规 | NPEduTools 登录启动、启动时仅显示侧边栏、侧边栏位置、初始配置向导。 |
| 设置／课堂工具 | PowerPoint 自动开启与触摸兼容；录制设置和自动录课计划的管理入口。 |
| 设置／软件连接 | ClassIsland 路径与连接诊断、课堂模式、ExamAware2 连接管理；管理员自启动放入可展开的高级区域。 |
| 反馈与布局 | 分类栏固定，切换分类回到顶部；原有保存反馈保留；细圆角滚动条支持滚轮、拖动与轨道翻页。 |

开关与路径继续使用既有持久化逻辑。切换分类不会重建控件或清空尚未保存的路径。路径明确提示“选择后保存”；侧边栏位置说明即时生效，启动偏好保存后仍提示下次启动生效。

首页日期保留本机日期并添加说明；自动录课继续使用 ClassIsland 时间，本次没有修改调度、排除科目或录制参数。

## 配置入口与状态修复

- 首页“连接设置”直接打开软件连接分类。
- ClassIsland 缺少路径时，启动入口直接定位并聚焦路径框。
- 初始配置向导和课堂模式窗口的 ClassIsland 路径入口使用同一定位方法。
- 课堂模式窗口的管理员设置入口自动切换分类、展开高级区域并滚动定位。
- 收到后台停止通知、连接异常或退出结果无法核实时，主页和侧边栏清除旧模式，显示状态未知；后台停止后迟到的轮询响应不能重新填回旧模式。
- 需要处理的模式状态同时使用文字及浅橙色卡片提示，不仅依赖颜色。
